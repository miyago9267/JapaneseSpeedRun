# 理由・程度表現：ものだから・ほどだ

「因為～嘛」和「到～的地步」。這兩個常一起出現：前半句交代理由，後半句誇張程度。延伸：[條件形](conditional-forms.md)、[句子解析](sentence-parsing.md)。

**這課要花力氣的是 `ものだから` 的限制**：它只拿來說明理由，後句不能接命令・請求。`ほどだ` 接續簡單，難在讀懂後面那個誇張的比喻。

## 原句解析

```
幼稚園の頃から毎日一緒なもんだから、お互いに知らないところが見つけられないほどだ。
```

- 前半（理由）：[幼稚園の頃から毎日一緒] な**もんだから**
- 後半（程度）：[お互いに知らないところが見つけられない] **ほどだ**
- 讀法：「因為從幼稚園起就天天在一起，熟到彼此幾乎找不出對方不知道的地方。」

| 片段 | 規則 | 說明 |
| --- | --- | --- |
| 幼稚園（ようちえん）の頃（ころ）**から** | `名詞 ＋ の頃から` | 從～的時候起 |
| 毎日（まいにち）一緒（いっしょ）**な** | `名詞／な形 ＋ な ＋ ものだから` | 一緒 當 な形用，接 ものだから 要補 **な** |
| **もんだから** | `ものだから → もんだから` | 口語縮約，說明理由 |
| お互（たが）いに | 副詞 | 彼此 |
| 知（し）らない**ところ** | `ない形 ＋ 名詞` | ところ＝部分・方面，不是地點 |
| 見（み）つけ**られない** | `る動詞 → られる` → 否定 | 可能形，對象用 **が** |
| **ほどだ** | `普通形 ＋ ほどだ` | 到了～的地步 |

> [!WARNING]
> 「知らないところが見つけられない」＝找不到不知道的地方＝幾乎什麼都知道。雙重否定，翻譯時要轉成肯定。

## ものだから — 帶辯解味的理由

| 詞類 | 規則 | 例 |
| --- | --- | --- |
| 動詞 | `普通形 ＋ ものだから` | 寝坊（ねぼう）した**ものだから** |
| い形 | `普通形 ＋ ものだから` | 忙（いそが）しい**ものだから** |
| な形 | `語幹 ＋ な ＋ ものだから` | 静（しず）か**な**ものだから |
| 名詞 | `名詞 ＋ な ＋ ものだから` | 子供（こども）**な**ものだから |

口語變體：`もんだから`／`もんで`（更隨便）；禮貌形 `ものですから`。JLPT 選項寫 `ものだから`。

| 表現 | 語感 | 後句可接命令・請求？ |
| --- | --- | --- |
| `から` | 主觀理由，最直接 | ✓ |
| `ので` | 客觀・禮貌 | ✓（較委婉） |
| `ものだから` | 「就是因為這樣嘛」，解釋・辯解 | ✗ |

> [!WARNING]
> ✗ 寒いものだから、窓を閉めてください。
> ✓ 寒い**ので**、窓を閉めてください。
> ✓ 寒い**ものだから**、窓を閉めちゃった。（說明自己做了什麼）

## ほどだ — 程度到某個地步

用一個具體（常是誇張）的情境來量程度。口語常換成 `くらい／ぐらい`。

| 形 | 規則 | 例 |
| --- | --- | --- |
| 句尾 | `普通形 ＋ ほどだ` | 涙（なみだ）が出（で）る**ほどだ** |
| 修飾述語 | `普通形 ＋ ほど ＋ 形容詞／動詞` | 涙が出る**ほど**うれしい |
| 修飾名詞 | `普通形 ＋ ほどの ＋ 名詞` | 信（しん）じられない**ほどの**量（りょう） |
| な形・名詞 | `な形語幹 ＋ な ＋ ほど`／`名詞 ＋ ほど` | 山（やま）**ほど**ある |

> [!WARNING]
> `ほど` 另有「越～越～」（`～ば～ほど`）和「大約」（`3時間ほど`）的用法。前面是一整句情境描述 → 程度。

## 例句

## ものだから

**JLPT 軌道**
電車が事故で止まってしまった**ものだから**、大事な会議に三十分も遅れてしまい、上司に頭を下げることになった。
母が急に入院した**ものですから**、しばらくの間、週末の勉強会は欠席させていただきます。

**日常軌道**
昨日ゲームやりすぎちゃった**もんだから**、今朝ぜんぜん起きられなくてさ、一限サボっちゃった。
あの店のパン、あんまりおいしい**もんで**、つい五個も買っちゃったんだよね。

## ほどだ

**JLPT 軌道**
新しい駅ができてから、この辺りの人口は十年前とは比べものにならない**ほど**増えている。
彼の発表はとても分かりやすく、専門外の私でも内容をすぐに理解できる**ほどだった**。

**日常軌道**
昨日の映画、ラストで泣きすぎて、帰り道で誰にも顔を見られたくない**ほどだった**よ。
最近忙しすぎて、ご飯食べる時間もない**くらい**なんだよね。

## 一起用

**JLPT 軌道**
幼い頃から毎日一緒に過ごしてきた**ものだから**、二人はお互いの考えが言葉にしなくても分かる**ほどだ**。

**日常軌道**
あいつとは小学校からずっと一緒な**もんだから**、周りからもう家族みたいって言われる**くらい**なんだよね。
