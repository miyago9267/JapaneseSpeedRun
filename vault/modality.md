# 推量・様態表現

「看起來」「聽說」「應該」「一定是」——這組語法決定你表達推斷的精度。N2 聽解・讀解每篇都有，日常對話也無處不在。

## 確信度スペクトル

| 確信度 | 表現 | 中文語感 | 推斷根據 |
|--------|------|---------|---------|
| 高 ↑ | `に違いない` | 一定是 | 說話者強烈主觀斷定 |
| | `はずだ` | 應該是（符合預期） | 邏輯推理・已知前提 |
| | `ようだ` | 看起來 | 直接觀察・感官資訊 |
| | `らしい` | 聽說・似乎 | 間接資訊・傳聞佐証 |
| | `でしょう・だろう` | 大概是吧 | 說話者主觀推測 |
| 低 ↓ | `かもしれない` | 也許・有可能 | 可能性低、未確認 |

## そうだ — 同形異義，最高頻陷阱

そうだ 有兩種完全不同的用法，**接続方式不同**，語意也截然不同。

| | 様態そうだ | 伝聞そうだ |
|-|-----------|----------|
| **意思** | 看起來（說話者直接觀察） | 聽說（從他人・媒體得知） |
| **動詞接続** | `ます形` + そうだ | `普通形` + そうだ |
| **例** | 雨が降り**そうだ**。 | 明日は雨だ**そうだ**。 |
| **い形接続** | 語幹（去い）+ そうだ | 普通形 + そうだ |
| **例** | おいし**そうだ**。 | あの店は高い**そうだ**。 |
| **な形接続** | 語幹 + そうだ | 語幹 + **だ** + そうだ |
| **例** | 元気**そうだ**。 | 彼は元気**だそうだ**。 |

> [!WARNING]
> い形兩個特殊形：`いい → よさそうだ`（不是 ~~いそうだ~~）、`ない → なさそうだ`（不是 ~~なそうだ~~）
> ✗ このケーキ、いそうだ。→ ✓ よさ**そうだ**。
> ✗ お金がなそうだ。→ ✓ なさ**そうだ**。

## 様態そうだ

**JLPT 軌道**
彼女の顔色を見ると、今日は体の具合が悪**そうだ**。
このプロジェクトは予算が足り**なさそうだ**が、どうにかなるだろうか。

**日常軌道**
この荷物、重**そうだね**。持とうか？
あ、そのラーメン、めちゃくちゃおいし**そう**！ひと口もらっていい？

## 伝聞そうだ

**JLPT 軌道**
報告書によると、今年の売上は昨年を大幅に上回る**そうです**。
ニュースで、来月から消費税が引き上げられる**そうだ**。

**日常軌道**
田中さんって、来週会社辞める**そうだよ**。知ってた？
あのカフェ、最近すごく混んでる**そうだけど**、行ったことある？

## 各表現詳解

<!-- tabs:start -->

## らしい

**意思**：有間接根據的推測・傳聞（說話者掌握某些佐証資訊）

**接続**：普通形 ＋ らしい（名詞・な形 直接 ＋ らしい，**不加 だ**）

| 類型 | 例 |
|------|----|
| 動詞 | 先生は**もう帰った**らしい。|
| い形 | この薬は副作用が**少ない**らしい。|
| な形 | 彼女は本当に日本語が**上手**らしい。|
| 名詞 | 隣の部屋の人は外国人**らしい**。|

**JLPT 軌道**
調査の結果によると、都市部の若者の多くが孤独を感じている**らしい**。

**日常軌道**
あのカフェ、最近オーナーが変わった**らしい**よ。メニューも全部変わったって。

> [!WARNING]
> らしい には「らしい名詞」（典型・像樣）的用法也存在：「男らしい」（有男子氣概）、「日本らしい景色」——推量 vs 形容用法，閱讀中都會出現。

## ようだ・みたいだ

**意思**：說話者直接觀察（眼見、聽到、感覺）後的推測

**ようだ 接続**：普通形 ＋ ようだ（な形 ＋ **な** ＋ ようだ、名詞 ＋ **の** ＋ ようだ）
**みたいだ 接続**：普通形 ＋ みたいだ（名詞・な形 直接 ＋ みたいだ，**不加だ/な**）

| | ようだ（較正式） | みたいだ（口語） |
|-|----------------|----------------|
| 動詞 | 試験が終わった**ようだ** | 試験終わった**みたいだ** |
| い形 | 彼女は機嫌が悪い**ようだ** | 機嫌悪い**みたいだ** |
| な形 | 彼は体が不自由な**ようだ** | 体不自由**みたいだ** |
| 名詞 | まるで夢の**ようだ** | まるで夢**みたいだ** |

**JLPT 軌道**
外が急に静かになった。子供たちは遊びに飽きて家に帰った**ようだ**。

**日常軌道**
ちょっと待って——彼、私のこと好き**みたいだよ**。さっきずっと見てたし。

## はずだ

**意思**：根據邏輯・已知前提，預期應該如此（含說話者的確信）

**接続**：普通形 ＋ はずだ（な形 ＋ **な** ＋ はずだ、名詞 ＋ **の** ＋ はずだ）

**JLPT 軌道**
彼女は3年間日本に住んでいたのだから、日本語がある程度話せる**はずだ**。
これだけ努力を積み重ねてきたのだから、必ず結果につながる**はずだ**と信じたい。

**日常軌道**
あれ、財布ここに置いた**はずなんだけど**……見てない？

> [!WARNING]
> `はずがない`（不可能）是強烈否定：彼がそんなことをした**はずがない**。
> `はずだった`（本來應該，但沒有）：この薬で治る**はずだったのに**、全然効かない。

## に違いない

**意思**：說話者幾乎可以斷定，確信度最高。比 はずだ 語氣更強、更主觀。

**接続**：普通形 ＋ に違いない（名詞・な形 **不加 だ**）

**JLPT 軌道**
毎日夜中まで練習を続けてきたのだから、今度の大会では優勝できる**に違いない**。
彼女がこんなに急に態度を変えたのは、何か知っている**に違いない**。

**日常軌道**
あの行列、絶対おいしい**に違いないよ**。毎回あんなに並んでるし。

## かもしれない

**意思**：不確定的可能性，不敢斷言。確信度最低。

**接続**：普通形 ＋ かもしれない（名詞・な形 **不加 だ**）

**JLPT 軌道**
このプロジェクトの遅延は、初期段階の計画不足が原因だった**かもしれない**。
環境の変化が、このような生物の絶滅につながった**かもしれない**と研究者は指摘する。

**日常軌道**
彼が怒ってるのって、もしかして私が余計なこと言ったせい**かも**。
明日雨降る**かもしれない**から、傘持っといた方がいいよ。

> [!WARNING]
> 口語常縮略：`かもしれない → かも`。「そうかも」「あるかも」很自然，但正式書面要還原完整形。

## でしょう・だろう

**意思**：說話者的主觀推測，語氣輕。でしょう 是正式，だろう 是口語（男性語居多）。

**接続**：普通形 ＋ でしょう / だろう（名詞・な形 語幹 ＋ でしょう）

**JLPT 軌道**
この調査結果からすると、今後も同じ傾向が続く**でしょう**。
経済の回復には、まだ時間がかかる**でしょう**。

**日常軌道**
そりゃ疲れる**だろう**よ、毎日残業してたら。

**確認用法**（語調上揚 ↑）
もう知ってる**でしょう**？昨日ニュースで言ってたじゃない。

## 接続まとめ

| 表現 | 動詞 | い形 | な形 | 名詞 |
|------|------|------|------|------|
| `そうだ`（様態） | ます形 | 語幹（去い） | 語幹 | — |
| `そうだ`（伝聞） | 普通形 | 普通形 | 語幹＋だ | 名詞＋だ |
| `らしい` | 普通形 | 普通形 | 語幹 | 名詞 |
| `ようだ` | 普通形 | 普通形 | 語幹＋**な** | 名詞＋**の** |
| `みたいだ` | 普通形 | 普通形 | 語幹 | 名詞 |
| `はずだ` | 普通形 | 普通形 | 語幹＋**な** | 名詞＋**の** |
| `に違いない` | 普通形 | 普通形 | 語幹 | 名詞 |
| `かもしれない` | 普通形 | 普通形 | 語幹 | 名詞 |
| `でしょう` | 普通形 | 普通形 | 語幹 | 名詞 |

> [!WARNING]
> **な形・名詞的接続差最大**（以「元気」為例）：
> 元気**な**ようだ／元気**らしい**／元気**そうだ**（様態）／元気**だそうだ**（伝聞）／元気**に違いない**
> 同一語根，五種接法全不同——必須背熟。
