# 生活用語：中文 → 日文怎麼講

Miyago 問「這句日文怎麼講」時，agent 答完會自動記在這裡：**中文原句 → 不同場合的日文 → 語感・對象**。一句一節，句子之間沒有順序。要查文法規則請看 [基礎](../basics/grammar/particles.md)／[比較](../compare/kara-node.md)；自己造句翻錯的點記在 [錯題整理](../mistakes/my-pitfalls.md)，不記在這裡。

## 「我先走了」

| 場合 | 日文 | 語感・對象 |
| --- | --- | --- |
| 職場（比別人早下班） | お先に失礼します。 | 對上司・同事；最標準的禮貌說法 |
| 日常・離開聚會 | じゃ、先に帰るね。 | 對朋友；「我先回去了」 |
| 日常・先出發 | じゃ、先に行くね。 | 對朋友；「我先過去（目的地）了」 |
| 簡短口語 | じゃあ、お先！ | 很熟的朋友・同輩 |

- 文法：`先に` ＝「搶先／先～」；`～ね` 是向對方確認・柔化語氣的終助詞。

> [!WARNING]
> `先に行く` 是「先往目的地去」，不一定是「離開」。要說「我要先回家／先離開」用 `先に帰る`；在職場下班就用固定句 `お先に失礼します`。

## 「辛苦了」

| 場合 | 日文 | 語感・對象 |
| --- | --- | --- |
| 職場（見面・下班都能用） | お疲れ様です／お疲れ様でした。 | 對同事・上司；下班離開、工作結束用 でした |
| 日常・朋友 | お疲れ。／おつかれ。 | 同輩、同事之間 |
| 很隨性 | おつ。 | 網路・遊戲・年輕人 |

> [!WARNING]
> `ご苦労様です` 是**上位者對下位者**說的，對上司或客人說會失禮。對上位者一律用 `お疲れ様です`。

## 「等我一下」

| 場合 | 日文 | 語感・對象 |
| --- | --- | --- |
| 對客人・正式 | 少々お待ちください。 | 服務場合的標準說法 |
| 對同事・一般 | ちょっとお待ちください。／少し待ってください。 | 禮貌但不太拘謹 |
| 日常・朋友 | ちょっと待って。 | 對朋友・家人 |
| 日常・更輕 | ちょっと待ってて。 | 「（稍微）等我一下喔」 |

- 文法：請求的 `～てください` ／ 口語省略 `ください` 變成 `～て`。

## 「請跟我聯絡」

| 說法 | 結構 | 評價 |
| --- | --- | --- |
| ご{連絡\|れんらく}ください。 | 尊敬：`ご＋漢語＋ください` | ✓ 最標準，商務・告示 |
| ご連絡をお{願\|ねが}いします。 | 名詞＋をお願いします | ✓ 客氣，郵件常用 |
| 連絡してください。 | 普通的 `てください` | ✓ 禮貌但不算敬語 |
| ご連絡してください。 | 謙讓 `ご〜する` ＋ てください | △ 常聽到，但規範上算誤用 |

- `ご／お ＋ 動詞 ＋ する` 是**謙讓語**，主語是「我」：私からご連絡します（由我來聯絡您）。
- 拿謙讓的 `ご連絡する` 去叫**對方**做，等於把對方放低，所以規範上不對；但實際上很多人這樣說，聽到不必驚訝，自己寫郵件和考試用 `ご連絡ください`。
- 同理：✓ お待ちください／△ お待ちしてください；✓ ご確認ください／△ ご確認してください。〔N3〕
