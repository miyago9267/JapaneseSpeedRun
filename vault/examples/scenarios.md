# 情境會話：主題式練習

一個情境一節：**對話 → 聽懂對方的固定句 → 自己回 → 即時應答練習**。重點是「聽得懂＋回得出短句」，不是背整段台詞。單句見 [生活用語](daily-phrases.md)。

## コンビニ（便利商店）

### 對話

| 誰 | 日文 | 中文 |
| --- | --- | --- |
| 店員 | いらっしゃいませ。 | 歡迎光臨。 |
| 店員 | お{弁当\|べんとう}、{温\|あたた}めますか？ | 便當要加熱嗎？ |
| 客 | はい、お{願\|ねが}いします。 | 好，麻煩你。 |
| 店員 | お{箸\|はし}はおつけしますか？ | 需要筷子嗎？ |
| 客 | いえ、{大丈夫\|だいじょうぶ}です。 | 不用了。 |
| 店員 | {袋\|ふくろ}はご{利用\|りよう}ですか？ | 需要袋子嗎？ |
| 客 | はい、お{願\|ねが}いします。 | 要，麻煩你。 |
| 店員 | ポイントカードはお{持\|も}ちですか？ | 有集點卡嗎？ |
| 客 | {持\|も}ってないです。 | 沒有。 |
| 店員 | 850{円\|えん}です。お{支払\|しはら}いは？ | 850 圓。怎麼付款？ |
| 客 | PayPayでお{願\|ねが}いします。 | 用 PayPay。 |
| 店員 | レシートはご{利用\|りよう}ですか？ | 收據要嗎？ |
| 客 | {大丈夫\|だいじょうぶ}です。 | 不用了。 |
| 店員 | ありがとうございました。 | 謝謝光臨。 |

### 聽懂店員

| 店員說 | 意思 | 級 |
| --- | --- | --- |
| {温\|あたた}めますか？ | 要加熱嗎 | 〔N4〕 |
| お{箸\|はし}・スプーンはおつけしますか？ | 要附筷子・湯匙嗎 | 〔N4〕 |
| {袋\|ふくろ}はご{利用\|りよう}ですか？ | 要袋子嗎（＝使いますか 的尊敬） | 〔N3〕 |
| ポイントカードはお{持\|も}ちですか？ | 有集點卡嗎（お持ちです＝持っています 的尊敬） | 〔N4〕 |
| こちらでお{召\|め}し{上\|あ}がりですか？ | 內用嗎 | 〔N3〕 |
| {画面\|がめん}のタッチをお{願\|ねが}いします。 | 請按螢幕（買酒菸的年齡確認） | 〔N4〕 |
| 〜{円\|えん}になります。 | ＝〜円です（打工敬語，常聽到） | 〔日常〕 |

### 自己回

| 想說 | 日文 | 級 |
| --- | --- | --- |
| 好・要 | はい、お{願\|ねが}いします。 | 〔N5〕 |
| 不用了 | {大丈夫\|だいじょうぶ}です。 | 〔N4〕 |
| 外帶 | {持\|も}ち{帰\|かえ}りで。 | 〔N4〕 |
| 用～付 | Suicaで・カードで・{現金\|げんきん}で | 〔N5〕 |
| 兩雙筷子 | お{箸\|はし}、{二膳\|にぜん}お{願\|ねが}いします。 | 〔N3〕 |
| 不用加熱 | {温\|あたた}めなくて{大丈夫\|だいじょうぶ}です。 | 〔N4〕 |

> [!WARNING]
> 「不用了」最安全是 `大丈夫です`。`いいです` 可能被聽成「好啊」也可能是「不用」，有歧義；`結構です` 較硬，對店員用會有點冷。

### 即時應答練習

聽一句、馬上回（JLPT 聴解「即時応答」形式）：

1. 店員：{袋|ふくろ}はご{利用|りよう}ですか？（你有帶環保袋）
2. 店員：こちらでお{召|め}し{上|あ}がりですか？（你要外帶）
3. 店員：お{箸|はし}は{何膳|なんぜん}おつけしますか？（兩人份）

<details>
<summary>參考答案</summary>

1. いえ、{大丈夫|だいじょうぶ}です。（{袋|ふくろ}、{持|も}ってます。）
2. いえ、{持|も}ち{帰|かえ}りで。
3. {二膳|にぜん}お{願|ねが}いします。

</details>
