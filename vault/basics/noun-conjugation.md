# 名詞活用（だ／です）

名詞本身不變化，**變的是後面的 `だ`（敬體 `です`）**——「A は B だ」這種判斷句的各種形。N5 就出現，但 `なので`・`じゃん` 這些會一路考到 N2、用到日常口語。延伸：[活用速查表](conjugation-cheatsheet.md)（一表看完）・[形容詞變化型](adjective-conjugation.md)（な形容詞活用幾乎一樣）。

**先記一句：** 名詞和な形容詞活用相同，**唯一差別是接名詞時 名詞用 `の`、な形用 `な`**。

## 基本活用

以 学生（がくせい）為例。

| 形 | 常體（普通形） | 敬體（です形） |
| --- | --- | --- |
| 現在肯定 | 学生**だ** | 学生**です** |
| 現在否定 | 学生**じゃない**／学生**ではない** | 学生**じゃありません**／学生**ではありません**（口語也說 学生じゃないです） |
| 過去肯定 | 学生**だった** | 学生**でした** |
| 過去否定 | 学生**じゃなかった**／学生**ではなかった** | 学生**じゃありませんでした**／学生**ではありませんでした**（口語也說 学生じゃなかったです） |
| て形（連接） | 学生**で**、～ | （同左） |
| 推量 | 学生**だろう** | 学生**でしょう** |

> [!WARNING]
> `だ` 只用在句尾或接 `から`・`けど` 等；**接名詞修飾時要換成 `の`**（✗学生だ人 → ✓学生の人），**接 `ので`・`のに` 時換成 `な`**（✓学生なので）。

## 接名詞・接其他詞

| 用法 | 規則 | 例 |
| --- | --- | --- |
| 連體（修飾名詞） | `名詞 ＋ の ＋ 名詞` | 学生**の**友達（學生的朋友）／日本語**の**先生（日語老師） |
| 過去的連體 | `名詞 ＋ だった ＋ 名詞` | 学生**だった**頃（還是學生的時候） |
| ので・のに | `名詞 ＋ な ＋ ので／のに` | 学生**な**ので・学生**な**のに |
| から・けど | `名詞 ＋ だ ＋ から／けど`（敬體 ですから／ですけど） | 学生**だ**から・学生**だ**けど |
| 條件 | `名詞 ＋ なら`／`名詞 ＋ だったら` | 学生**なら**割引になる／学生**だったら**入れた |
| 並列・連接 | `名詞 ＋ で` | 彼は学生**で**、妹は社会人です |

## JLPT vs 日常

| 場景 | JLPT track（考試・書面・正式） | 日常 track（口語） |
| --- | --- | --- |
| 否定 | `ではない`・`ではありません` | `じゃない`・`じゃん`（縮約） |
| 條件 | `であれば`（書面・正式）・`なら` | `だったら`・`なら` |
| 句尾確認 | `～ではないか`・`～でしょう` | `～でしょ`・`～だよね`・`～じゃん` |
| 回想確認 | —— | `～だっけ`（「是～來著？」） |

> [!WARNING]
> **`じゃん` ＝ `じゃない（か）` 的縮約**，意思是「不就是～嘛／～啊」，帶「這你應該知道／你看吧」的語氣，**只在口語**對熟人用。考試和正式場合不會出現，但聽力和 galgame 對話幾乎天天遇到。

## 例句

**JLPT track**

- 兄は去年まで大学生でしたが、今は小さな会社の会社員です。
- 昨日は休みじゃなかったので、友達と会うことができませんでした。
- 彼はまだ学生なのに、もう自分で家賃を払っているらしい。
- 来週が締め切りなら、今週中にある程度終わらせておかないと間に合わない。

**日常 track**

- あれ、これ田中さんの傘じゃん。なんでここにあるの？
- 今日って、確か休みだっけ？　それとも仕事だった？
- 雨だったら、無理して行かなくてもいいんじゃない？
- 昔は先生だったんだけど、今は全然違う仕事してるんだよね。
