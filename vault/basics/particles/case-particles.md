# 格助詞進階

[常用助詞](../grammar/particles.md)講完 は・が・を・に・で 的基本角色後，這頁補**基本款沒講到、但 N3/N2 一定會碰到**的用法：が／の 交替、を vs が、に vs と、被動・使役的「做的人」、で 的各種「範圍」、から vs で。

> 助詞系列：[常用助詞](../grammar/particles.md)・**格助詞進階**・[副助詞](adverbial-particles.md)・[接続助詞](conjunctive-particles.md)・[終助詞](sentence-final-particles.md)・[複合助詞](compound-particles.md)

**怎麼用這頁：**

- **什麼時候來**：助詞選項裡有 に／と／で／から 搶同一格、或看到 「私**の**作った」 這種 の 不知道是哪個角色時。
- **自我測驗**：先遮住「規則」欄，看「例」自己說出為什麼是這個助詞；陷阱表遮住 ✓／✗ 再選。
- **卡住時**：基本角色 → [常用助詞](../grammar/particles.md)；は vs が → [は vs が](../../compare/wa-ga.md)；使役 → [使役形用法](../grammar/causative.md)。

## 一眼速查

| 項目 | 規則 | 例 | 級 |
| --- | --- | --- | --- |
| が／の 交替 | 連体修飾句裡的主語，`が` 可換成 `の` | 私**の**作ったケーキ | 〔N3〕 |
| 可能形的對象 | `を` 或 `が`；`が` 較標準・考試首選 | 日本語**が**話せる | 〔N4〕 |
| たい 的對象 | `を` 或 `が` 皆可 | 水**が**飲みたい／水**を**飲みたい | 〔N5〕 |
| に vs と | `に`＝單向對象；`と`＝互相・一起 | 友達**に**会う／友達**と**会う | 〔N5〕 |
| 被動的「做的人」 | `に`（人・生物）；`によって`（創作・事件）；`から`（來源） | 先生**に**ほめられた | 〔N4〕 |
| 使役的「被叫的人」 | 自動詞 `を`／`に`；他動詞 `に`（物用 `を`） | 子供**に**野菜**を**食べさせる | 〔N4〕 |
| で（範圍・人數・狀態） | 「在這個範圍內」「以這個狀態」 | 世界**で**一番／三人**で**／一人**で** | 〔N4〕 |
| で（期限・所需時間） | 「到這裡就結束」「花了多久」 | 今日**で**終わり／一時間**で**着く | 〔N4〕 |
| に（頻率・基準） | 「每～」 | 週**に**二回 | 〔N4〕 |
| で vs から（材料） | `で`＝看得出原樣；`から`＝變了質 | 木**で**作る／米**から**作る | 〔N3〕 |
| から（動作的來源） | もらう・聞く・習う 的對象 | 友達**から**もらった | 〔N4〕 |
| から（原因・書面） | 抽象的因由，帶「由此而生」 | 不注意**から**事故が起きた | 〔N2〕 |
| より（起點・書面） | ＝ `から`，用在公告・致詞 | 本日**より**営業開始 | 〔N2・文言〕 |
| 〜より仕方がない | ＝ しか〜ない（只能） | 諦める**より**仕方がない | 〔N3〕 |
| の（同格） | 「名詞 の 名詞」＝同一個人事物 | 医者**の**田中さん | 〔N3〕 |

## が／の 主格交替〔N3〕

**連体修飾句**（修飾名詞的子句）裡的主語，`が` 可以換成 `の`。換成 `の` 比較書面・穩重。

| 原句（が） | 交替（の） | 說明 |
| --- | --- | --- |
| 私**が**作ったケーキ | 私**の**作ったケーキ | 一般他動詞句 |
| 雨**が**降る日 | 雨**の**降る日 | 自然現象最常見 |
| 友達**が**来る前に | 友達**の**来る前に | 「前・後・間・とき」前的子句也行 |
| 背**が**高い人 | 背**の**高い人 | 身體部位＋形容詞，換 の 很自然 |

> [!WARNING]
> **只限連体修飾句／名詞性的子句**，主句不能換：✗私**の**ケーキを作った。另外句中如果還有 `を` 賓語（✗私**の**日本語を勉強した理由），`の` 會讓人誤讀成「私の日本語」，這種情況留 `が` 最安全。主題的 `は` 也不能這樣換。

## を vs が：可能形・たい

| 句型 | `を` | `が` | 重點 |
| --- | --- | --- | --- |
| 可能形〔N4〕 | △ 日本語**を**話せる（口語・可） | ✓ 日本語**が**話せる | 可能形把動作變成「狀態」，標準是 `が`；考試選 `が` |
| 〜ことができる〔N4〕 | ✓ 日本語**を**話すことができる | △ 日本語**が**話すことができる（不自然） | 這裡 `話す` 仍是普通他動詞，賓語照常 `を`；`が` 只出現在**可能形**（話せる） |
| 〜たい〔N5〕 | ✓ 水**を**飲みたい | ✓ 水**が**飲みたい | `が`＝想要的東西（強調慾望）；`を`＝動作的受詞 |
| 好き・ほしい・わかる〔N5〕 | ✗ | ✓ **必須 `が`** | 感情・能力的對象，不能 `を` |

> [!WARNING]
> **動詞離賓語很遠時用 `を`**：コーヒー**を**飲みに行きたい ✓（コーヒー**が**… 會跟「行く」打架）。

## に vs と：會う・話す・結婚する

| 動詞 | `に`（單向・對象） | `と`（互相・一起） | 級 |
| --- | --- | --- | --- |
| 会う | 駅で友達**に**会った（偶遇・去見） | 友達**と**会う約束（約好見面） | 〔N5〕 |
| 話す | 先生**に**話す（跟他說・告知） | 先生**と**話す（對話・談話） | 〔N4〕 |
| 相談する | 先生**に**相談する（請教） | 友達**と**相談する（一起商量） | 〔N4〕 |
| 結婚する | ✗ 彼女**に**結婚する | ✓ 彼女**と**結婚する | 〔N4〕 |
| けんかする・別れる | ✗ | ✓ 彼**と**けんかした／彼女**と**別れた | 〔N4〕 |

> [!WARNING]
> **判斷法**：這個動作「對方也必須一起做」嗎？結婚・けんか・別れる 需要雙方，只能 `と`；請教・告知是我單方面對對方做，用 `に`。會う 和 話す 兩邊都對，但語感不同。

## 被動・使役裡「做的人」的助詞

### 被動：誰做的？〔N4〕

| 助詞 | 用在 | 例 |
| --- | --- | --- |
| `に` | 有生命的人・動物（最基本） | 先生**に**ほめられた／犬**に**かまれた |
| `から` | 動作有「方向」：頼まれる・言われる・注意される・誘われる | 先生**から**注意された |
| `によって`〔N3〕 | 創作・發明・事件（做的人不是重點） | この絵はピカソ**によって**描かれた |

### 使役：被叫去做的人〔N4〕

| 動詞 | 助詞 | 例 |
| --- | --- | --- |
| 自動詞 | `を`（強制）／`に`（允許・隨他去） | 子供**を**行かせた／子供**に**行かせた |
| 他動詞（已有 を） | 被叫的人用 `に` | 子供**に**野菜**を**食べさせる |

> [!WARNING]
> 他動詞使役裡 `を` 不能重複用兩次：✗子供**を**野菜**を**食べさせる。誰被叫 → `に`，吃什麼 → `を`。詳細語感：[使役形用法](../grammar/causative.md)。

## で 的各種「範圍」

| 用法 | 規則 | 例 | 級 |
| --- | --- | --- | --- |
| 範圍（最高級） | 「在這個範圍內」 | 世界**で**一番高い山 | 〔N4〕 |
| 人數・狀態 | 「以～的人數／狀態」 | 三人**で**行く／一人**で**住む／みんな**で**食べる | 〔N5〕 |
| 總額 | 「合計」 | 全部**で**千円 | 〔N5〕 |
| 所需時間 | 「花了多久」 | 一時間**で**着く | 〔N4〕 |
| 期限・結束 | 「到這個時間點就結束」 | 今日**で**終わり／来月**で**二十歳になる | 〔N4〕 |

> [!WARNING]
> 「5 點」有三種：5時**まで**働く（**一直**做到 5 點）・5時**で**終わる（5 點**就此結束**）・5時**までに**帰る（**在 5 點之前**回去，期限）。`まで` 是持續，`で` 是切點，`までに` 是期限。

## に 的頻率・基準〔N4〕

「每～」用 `に`：週**に**二回・一日**に**三回・一年**に**一度。基準點前面的名詞是「單位時間」。

## から vs で：材料・原料・來源

| | `で`（材料） | `から`（原料） |
| --- | --- | --- |
| 判斷 | **看得出原樣**（物理加工） | **性質變了**（化學・發酵・加工後認不出） |
| 例 | 木**で**作った机／石**で**できた橋 | 米**から**作る酒／大豆**から**作る味噌 |
| 被動 | この家は木**で**作られている | 酒は米**から**作られる |

> [!WARNING]
> 「材料」不是 `で` 就是 `から`，不要用 `に`。兩種都對的模糊地帶（紙**で**／から作る 之類）考試不會考；只要抓住「看得出原樣 → `で`」。

| `から`（來源・原因） | 例 | 級 |
| --- | --- | --- |
| 動作來源（もらう・聞く・習う・借りる） | 友達**から**本をもらった（也可用 に） | 〔N4〕 |
| 原因（書面・抽象） | 不注意**から**事故が起きた／ちょっとした誤解**から**けんかになった | 〔N2〕 |

## より：起點與「只能」

| 用法 | 例 | 級 |
| --- | --- | --- |
| 比較基準（基本） | 去年**より**暑い | 〔N5〕 |
| 起點（＝ から，書面・公告） | 午後九時**より**開演いたします | 〔N2・文言〕 |
| 〜より仕方がない／ほかない（＝ しか〜ない） | 諦める**より**仕方がない | 〔N3〕 |

## の：同格〔N3〕

`名詞 の 名詞`＝兩者是**同一個人事物**，不是「誰的」：医者**の**田中さん（醫生田中先生）・友人**の**山田さん。順序是「身分／關係 の 名字」。
