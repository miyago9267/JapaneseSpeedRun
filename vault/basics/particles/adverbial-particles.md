# 副助詞

副助詞接在名詞・動詞後面，**不改變格（誰做什麼）**，只加上語氣：連～都・正是～・輕視・大概・只有・每～・這個啦那個啦。N3 以上一堆都是這類。

> 助詞系列：[常用助詞](../grammar/particles.md)・[格助詞進階](case-particles.md)・**副助詞**・[接続助詞](conjunctive-particles.md)・[終助詞](sentence-final-particles.md)・[複合助詞](compound-particles.md)

**怎麼用這頁：**

- **什麼時候來**：看到 さえ／すら／こそ／なり／やら 這類長得像、意思卻差很多的詞，或造句時想加「連～都」「大約」「每次～」卻不知道選哪個。
- **自我測驗**：遮住「核心」欄，看例句先判斷語感（強調？輕視？概數？）再選助詞。
- **不重複的**：`も`・`しか`・`だけ`・`ばかり` 另有一頁 → [細節助詞](../../compare/focus-particles.md)，這頁不再講。

## 一眼速查

| 助詞 | 核心 | 例 | 級 |
| --- | --- | --- | --- |
| `さえ` | 連～都（極端例示）；`〜さえ〜ば`「只要」 | 大人**でさえ**解けない／時間**さえ**あれば | 〔N3〕 |
| `すら` | ＝ さえ，書面・多搭否定 | 自分の名前**すら**書けない | 〔N1〕 |
| `こそ` | 強調「正是～」；`からこそ`・`てこそ` | 今年**こそ**合格する | 〔N2〕 |
| `など` | 例示「～之類」・輕視「像我這種」 | 私**など**が口を出すことではない | 〔N4〕 |
| `なんか` | `など` 的口語 | 私**なんか**行っても邪魔だ | 〔日常〕 |
| `なんて` | 輕視・意外「竟然／什麼～的」 | 彼が来る**なんて** | 〔N2・日常〕 |
| `くらい`／`ぐらい` | 概數・程度・「至少這點～」 | 三十分**ぐらい**／泣きたい**くらい** | 〔N4〕 |
| `ほど` | 程度・比較否定・`ば〜ほど` | 死ぬ**ほど**疲れた／昨日**ほど**寒くない | 〔N3〕 |
| `まで`（添加） | 連～都（範圍擴及）；`てまで` | 子供に**まで**笑われた／借金して**まで** | 〔N3〕 |
| `きり`／`っきり` | 自從～就沒再～；只有（兩人きり） | 出かけた**きり**帰らない | 〔N2〕 |
| `ずつ` | 各～・一點一點 | 一人**ずつ**／少し**ずつ** | 〔N4〕 |
| `やら` | 這個啦那個啦（說不清） | 仕事**やら**家事**やら** | 〔N2〕 |
| `だの` | 這個那個（抱怨・貶意） | 暑い**だの**寒い**だの** | 〔N2〕 |
| `なり` | 或～或～／一～就～／照自己的方式 | 電話**なり**メール**なり** | 〔N1〕 |

## 極端例示：「連～都」

| 助詞 | 例 | 語感 | 級 |
| --- | --- | --- | --- |
| `でも` | 大人**でも**解けない | 中性，最常用 | 〔N4〕 |
| `さえ` | 大人**でさえ**解けない／大人**さえ**… | 比 でも 強，帶意外 | 〔N3〕 |
| `すら` | 大人**ですら**解けない | 書面・更硬，多用於否定 | 〔N1〕 |
| `まで` | 子供**にまで**笑われた | 連「範圍都擴及到」，常帶「過分」語氣 | 〔N3〕 |

### さえ 的兩個用法〔N3〕

```
大人でさえ解けない問題だ。（連大人都解不出來。）← 極端例示
時間さえあれば、旅行に行きたい。（只要有時間就想去旅行。）← 〜さえ〜ば「只要」
```

> [!WARNING]
> `さえ` ＋ **條件**（`〜さえ〜ば`）＝「只要」，**不是**「連」。後半一定是 ば／たら／なら 之類的條件：あなたさえ来てくれれば…。名詞後面的 `さえ` 如果前面有格助詞，通常放後面：子供**にさえ**分かる（`に＋さえ`）。

### てまで〔N2〕

```
借金してまで高い車を買う必要はない。（沒必要借錢也要買貴車。）
```

「**連做到這種地步都要～**」，前面接動詞て形，後面常是否定・勸阻。

### までもない〔N2〕

言う**までもない**＝不必說，`〜するまでもない`＝沒必要做。

## 強調：こそ〔N2〕

| 用法 | 例 | 說明 |
| --- | --- | --- |
| `Nこそ` | 今年**こそ**合格する | 「這次一定要」；也可接在對方的話後：こちら**こそ**よろしく |
| `〜からこそ`〔N2〕 | 信頼している**からこそ**、厳しいことを言う | 「正因為～才」，理由強調 |
| `〜てこそ`〔N1〕 | 実際に経験して**こそ**分かる | 「只有～才」，後面接肯定的價值判斷 |

> [!WARNING]
> `Nこそ` 的語氣是「**不是別的、就是這個**」，不是「也」。要說「這個也」用 `も`；要說「就只有這個」用 `だけ`（→ [細節助詞](../../compare/focus-particles.md)）。

## 例示・輕視：など・なんか・なんて

| | 用法 | 例 | 書面／口語 | 級 |
| --- | --- | --- | --- | --- |
| `など` | 例示「～之類」 | 本や雑誌**など**を読む | 書面・中性 | 〔N4〕 |
| `など` | 輕視・謙遜 | 私**など**が口を出すことではない | 書面 | 〔N3〕 |
| `なんか` | 同上，口語 | 私**なんか**行っても邪魔だ | 口語 | 〔日常〕 |
| `なんて` | 輕視（名詞後）／意外（句子後） | 勉強**なんて**したくない／彼が来る**なんて** | 口語 | 〔N2・日常〕 |

> [!WARNING]
> `なんて` 接**句子**時是「竟然～」（驚訝或不滿）：彼が一人で来る**なんて**信じられない。別和 `なんて＋形容詞`（なんて**きれいな**空！＝多麼～）搞混，後者是感嘆副詞〔N3〕。

## 程度：くらい（ぐらい）・ほど

| 用法 | `くらい／ぐらい` | `ほど` | 級 |
| --- | --- | --- | --- |
| 概數 | 三十分**ぐらい**（口語・常用） | 三十分**ほど**（稍正式） | 〔N4〕 |
| 程度 | 泣きたい**くらい**嬉しい | 死ぬ**ほど**疲れた | 〔N3〕 |
| 比較否定 | ✗ | 昨日**ほど**寒くない | 〔N4〕 |
| 越～越～ | ✗ | 読めば読む**ほど** | 〔N3〕 |
| 「至少這點」 | これ**くらい**自分でやれ | ✗ | 〔N3〕 |
| 最高級 | 彼**くらい**親切な人はいない | 彼**ほど**親切な人はいない | 〔N2〕 |

> [!WARNING]
> **比較否定與 〜ば〜ほど 只能用 `ほど`**。`くらい` 另有「輕描淡寫・低標」的語感：挨拶**ぐらい**しなさい＝「至少打個招呼吧」。`くらい` 和 `ぐらい` 意思一樣，`ぐらい` 比較口語。

## 限定・分配：きり・ずつ

### きり／っきり〔N2〕

| 用法 | 例 | 說明 |
| --- | --- | --- |
| `〜たきり〜ない` | 出かけた**きり**帰ってこない | 「自從～就再也沒～」，後面必須是否定或停滯 |
| `二人きり` | 部屋に二人**きり**になった | 「只有／獨自」（＝ だけ，帶親密感） |
| `それっきり`（`っきり` 強調） | あれ**っきり**会っていない | 口語 |

### ずつ〔N4〕

「**各～・每次～**」，接在**數量詞**後：一人**ずつ**・二つ**ずつ**・少し**ずつ**。

> [!WARNING]
> `ずつ` 只能接數量詞（多少），不能直接接名詞：✗りんご**ずつ**。「一點一點」用 少し**ずつ**；「只有一點」才是 少し**だけ**。

## 列舉：やら・だの・なり

| 助詞 | 用法 | 例 | 級 |
| --- | --- | --- | --- |
| `〜やら〜やら` | 事情太多、說不清，帶「亂成一團」 | 仕事**やら**家事**やら**で忙しい | 〔N2〕 |
| `疑問詞＋やら` | 不確定「不知道是什麼／誰」 | 何**やら**騒がしい | 〔N1〕 |
| `〜だの〜だの` | 這個那個，帶抱怨・貶意 | 暑い**だの**寒い**だの**文句ばかり言う | 〔N2〕 |
| `〜なり〜なり` | **二選一**（或～或～），可自己挑 | 電話**なり**メール**なり**で連絡して | 〔N1〕 |
| `〜なり` | 一～就～ | 家に着く**なり**寝てしまった | 〔N1〕 |
| `Nなりに` | 以自己的程度・方式 | 私**なりに**頑張った | 〔N2〕 |

> [!WARNING]
> `なり` 有**三個完全不同**的用法，靠前後分辨：①兩個名詞 or 動詞並列＝二選一；②動詞原形＋なり＝「一～就」（後面是已發生的事，不能是意志・命令）；③名詞＋なりに＝「依自己的立場」。`やら`／`だの` 是「列舉很多、感覺亂」；`なり` 是「選一個就好」。

## 陷阱：長得像的對照

| 比較 | 差別 |
| --- | --- |
| `さえ` vs `も` | `も`＝單純追加「也」；`さえ`＝極端例子「連～都」，暗示其他更不用說 |
| `こそ` vs `さえ` | `さえ`＝連最不可能的都；`こそ`＝**就是這個**（重點選定） |
| `など` vs `なんか` vs `なんて` | 書面 → `など`；口語 → `なんか`；帶情緒 → `なんて` |
| `ぐらい` vs `ほど` | 概數兩者皆可；比較否定・越～越～只能 `ほど` |
| `きり` vs `だけ` | `〜たきり` 後面要否定；`二人きり` 可換成 `二人だけ` |
| `やら` vs `だの` vs `なり` | 雜亂說不清／抱怨／選一個 |
