# 接続助詞

接續助詞接在**句子（子句）後面**，把兩個句子接起來。這頁重點放在最容易混的**逆接（「但是」）**，再加上並列・同時。

> 助詞系列：[常用助詞](../grammar/particles.md)・[格助詞進階](case-particles.md)・[副助詞](adverbial-particles.md)・**接続助詞**・[終助詞](sentence-final-particles.md)・[複合助詞](compound-particles.md)

**怎麼用這頁：**

- **什麼時候來**：兩句想接「但是」卻不知道 が／けど／のに／ても／ものの 差在哪；或看到 ところで／ところが／つつ 這類 N3/N2 的接續。
- **自我測驗**：遮住「語感」欄，看例句判斷：是事實還是假定？後句能不能接意志・命令？
- **不重複的**：`から`・`ので`（因為）→ [から vs ので](../../compare/kara-node.md)；`と`・`ば`・`たら`・`なら`（條件）→ [條件形](../../compare/conditional-forms.md)。

## 一眼速查

| 助詞 | 語感 | 例 | 級 |
| --- | --- | --- | --- |
| `が` | 逆接（中性・書面）／前置き | 行きたい**が**、時間がない。 | 〔N5〕 |
| `けれど`・`けど`・`けれども` | 逆接（`けど` 口語最常用）；也能收在句尾 | 行きたい**けど**、時間がない。 | 〔N5〕 |
| `のに` | 逆接＋**不滿・意外**；另有「用途」 | 寝た**のに**疲れが取れない。 | 〔N4〕 |
| `ても`／`でも` | 假定逆接「即使～也」 | 雨が降っ**ても**行く。 | 〔N4〕 |
| `ながら` | 同時「一邊～一邊」 | 音楽を聞き**ながら**勉強する。 | 〔N4〕 |
| `ながら(も)` | 逆接「明明～卻」 | 知っ**ていながら**教えなかった。 | 〔N2〕 |
| `し` | 並列理由「又～又～」 | 安い**し**、近い**し**。 | 〔N4〕 |
| `たり` | 並列動作・狀態例示 | 見**たり**読ん**だり**する。 | 〔N4〕 |
| `ものの` | 逆接（承認前者，但實際不然；書面） | 資格を取った**ものの**、活かせていない。 | 〔N2〕 |
| `ところで` | 假定逆接「就算～也沒用」／換話題 | 謝った**ところで**許されない。 | 〔N3〕 |
| `ところが` | 意外的轉折「沒想到～」 | 着いた**ところが**、閉まっていた。 | 〔N3〕 |
| `つつ` | 同時（書面）／逆接 | 悪いと知り**つつ**やってしまう。 | 〔N2〕 |

## 逆接 5 兄弟：語感排序

| 助詞 | 感覺 | 後句能接意志・命令・勸誘嗎？ |
| --- | --- | --- |
| `が`〔N5〕 | 中性・正式 | ✓ |
| `けど`〔N5〕 | 口語・柔和（常用在委婉開頭） | ✓ |
| `のに`〔N4〕 | 不滿・意外・惋惜 | ✗ **不能**接意志・命令・勸誘 |
| `ものの`〔N2〕 | 先承認再轉折，書面 | △ 以陳述為主 |
| `ところが`〔N3〕 | 結果出乎意料 | ✗ 後句是已發生的事實 |

> [!WARNING]
> **`のに` 後面不能接說話者的意志・命令・請求**：✗雨なのに、行きましょう／✗疲れているのに、手伝ってください。要說這種話用 `けど`・`が`：雨だ**けど**行きましょう。`のに` 後面通常是「事實」，帶著不滿。

### のに（用途）〔N3〕

另一個 `のに`＝「**為了～**」，接在動詞原形後：このはさみは紙を切る**のに**使う。這個 `のに` 是 `の`（名詞化）＋`に`（目的），跟逆接的 `のに` 無關，看後面有沒有「使う・必要・便利・かかる」之類。

### けど（句尾）〔日常〕

`けど` 收在句尾＝話沒說完、委婉：「ちょっと難しいんだけど…」。→ [終助詞](sentence-final-particles.md)。

## 假定逆接：ても vs ところで vs のに

| | `ても`〔N4〕 | `ところで`〔N3〕 | `のに`〔N4〕 |
| --- | --- | --- | --- |
| 前句 | 假定・未然（或慣例） | 假定・已完成的動作 | 已發生的**事實** |
| 後句 | 自由 | **多為否定・無效**（もう遅い・許されない） | 不滿・意外 |
| 例 | 雨が降っ**ても**行く | 今謝った**ところで**、もう遅い | 雨が降った**のに**行った |

`ても` 的形式：動詞 `て形＋も`（食べても）・否定 `〜なくても`・い形 `〜くても`・な形／名詞 `〜でも`。搭配疑問詞：何度言っ**ても**・どんなに頑張っ**ても**・誰に聞い**ても**。

> [!WARNING]
> `ところで` 句首單獨用（＝**ところで**、明日の会議は…）是**換話題**〔N4〕，跟這裡的逆接不同；句中接在動詞た形後（〜た**ところで**）才是「就算～」。

## 轉折：ところが・ものの

| 助詞 | 重點 | 例 |
| --- | --- | --- |
| `ところが`〔N3〕 | 「我預期 A，**結果 B**」，B 是客觀事實，不能是意志 | 試験は簡単だと聞いていた。**ところが**、全然解けなかった。 |
| `ものの`〔N2〕 | 「雖然做了 A，但 B 不理想」，書面・帶自嘲 | 買った**ものの**、使っていない |

## 同時：ながら・つつ

| | `ながら`〔N4〕 | `つつ`〔N2〕 |
| --- | --- | --- |
| 同時 | 日常最常用 | 書面・硬，進行中（`〜つつある`＝漸漸～） |
| 逆接 | `ながらも`〔N2〕 | `つつ(も)`〔N2〕 |
| 限制 | **前後主語要相同** | 同左 |

> [!WARNING]
> ✗私が歌い**ながら**、彼が踊った。（主語不同，要改成「私が歌って、彼が踊った」）。同時做的兩件事必須是**同一個人**。

## 並列：し・たり

| | `し`〔N4〕 | `たり`〔N4〕 |
| --- | --- | --- |
| 並列什麼 | **理由・評價**（還有別的理由） | **動作・狀態**（舉例） |
| 句型 | 安い**し**、近い**し**、いい部屋だ | 休日は映画を見**たり**、本を読ん**だり**する |
| 結尾 | 用 普通形；最後的 `し` 後可省略 | 一定要 `〜たりする`（有時省略 する） |

> [!WARNING]
> `し` 是「**還有其他理由沒說完**」，`から` 是「這就是**唯一的理由**」。講完整的唯一理由用 `から`；想表達「不只這樣」用 `し`。→ [から vs ので](../../compare/kara-node.md)
