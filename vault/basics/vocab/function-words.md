# 基本單字

N5/N4 一定要「反射」會的單字。**這頁收「功能詞」**（こそあど・疑問詞・時間詞…，不太變化、用來組句的詞）；新的功能詞類別會往下補成新的節。**一般單字（動詞・形容詞・名詞）記在單字本**：[動詞單字本](verbs.md)・[形容詞單字本](adjectives.md)・[名詞單字本](nouns.md)。文法對照：[常用助詞](../grammar/particles.md)・[名詞活用](../grammar/noun-conjugation.md)。

**怎麼用這頁：**

- **什麼時候來**：こそあど・疑問詞・時間詞這類「組句用的小詞」忘了、或聽力裡漏接時。
- **自我測驗**：一次只看一節；遮住日文，看中文說得出來才算過；再遮中文，看日文說得出意思。
- **卡住時**：句子裡的角色 → [常用助詞](../grammar/particles.md)；動詞形容詞單字 → [動詞單字本](verbs.md)・[形容詞單字本](adjectives.md)。

## こそあど（指示詞）

「こ・そ・あ・ど」四個系列，後面接的詞尾決定詞性。

| | こ（近我） | そ（近對方／剛提到的） | あ（雙方都遠／共知） | ど（疑問） |
| --- | --- | --- | --- | --- |
| 事物 | これ | それ | あれ | どれ |
| 連體（＋名詞） | この | その | あの | どの |
| 場所 | ここ | そこ | あそこ | どこ |
| 方向・場所（禮貌） | こちら | そちら | あちら | どちら |
| 方向・場所（口語） | こっち | そっち | あっち | どっち |
| 種類・樣子 | こんな | そんな | あんな | どんな |
| 方式 | こう | そう | ああ | どう |

> [!WARNING]
> `これ・それ・あれ・どれ` 是**代名詞**，不能直接接名詞（✗これ本）；要接名詞用 `この・その・あの・どの`（✓この本）。
> `そ` 系列還可以指「對方剛說的內容」（そうですね＝「是啊」）；`あ` 系列指**雙方都知道**的人事物（あの店、あの人）。

## 疑問詞

| 詞 | 意思 | 例 |
| --- | --- | --- |
| なに／なん（何） | 什麼 | 何を食べますか。／これは何ですか。 |
| だれ（誰）／どなた（敬） | 誰 | 誰が来ましたか。 |
| いつ | 何時（不精確的時間） | いつ日本に来ましたか。 |
| どこ | 哪裡 | トイレはどこですか。 |
| どう | 怎麼樣 | 日本の生活はどうですか。 |
| どれ・どの | 哪個・哪一個 | どの本がいいですか。 |
| なぜ・どうして | 為什麼（なぜ較正式；どうして 通用；口語 なんで） | どうして遅れたんですか。 |
| いくら | 多少錢 | これはいくらですか。 |
| いくつ | 幾個／幾歲（禮貌問年齡 おいくつ） | りんごはいくつありますか。 |

> [!WARNING]
> 「何」有兩種唸法：**`なに`** 單獨或後接 を・が 等（何を食べる）；**`なん`** 後接 `だ・です・の・で・と` 或 た行・な行音（何ですか・何の本）。疑問詞後接 `か` 變成「某～」（誰か・何か・どこか）。

## 時間詞

| | 前々 | 前 | 今 | 次 | 次々 |
| --- | --- | --- | --- | --- | --- |
| 日 | おととい（一昨日） | きのう（昨日） | きょう（今日） | あした（明日） | あさって（明後日） |
| 週 | {先々週\|せんせんしゅう} | {先週\|せんしゅう} | {今週\|こんしゅう} | {来週\|らいしゅう} | {再来週\|さらいしゅう} |
| 月 | {先々月\|せんせんげつ} | {先月\|せんげつ} | {今月\|こんげつ} | {来月\|らいげつ} | {再来月\|さらいげつ} |
| 年 | おととし（一昨年） | きょねん（去年） | ことし（今年） | らいねん（来年） | さらいねん（再来年） |

| 「每～」 | 例 |
|---|---|
| {毎日\|まいにち}・{毎週\|まいしゅう}・{毎月\|まいつき}・毎年（まいとし／まいねん） | {毎朝\|まいあさ}・{毎晩\|まいばん} |

| 一天之中 | 讀法 |
| --- | --- |
| 朝・昼・夜 | あさ・ひる・よる |
| 今朝・今晩 | けさ・こんばん |
| 午前・午後 | ごぜん・ごご |

| 曜日 | 讀法 |
| --- | --- |
| 月・火・水・木 | げつようび・かようび・すいようび・もくようび |
| 金・土・日 | きんようび・どようび・にちようび |

> [!WARNING]
> `今日・昨日・明日・毎日・今週・来週` 這類詞**通常不加 `に`**（昨日映画を見た）；具體時間點才加（7時**に**起きる）。見 [常用助詞](../grammar/particles.md)。

## 副詞（程度・頻度）

| 單字（讀音） | 級 | 意思 | 備註 |
| --- | --- | --- | --- |
| {必\|かなら}ず | 〔N4〕 | 一定・必定 | 頻率 100%，語氣最絕對 |
| いつも | 〔N5〕 | 總是 | 頻率接近 100% |
| {専\|もっぱ}ら | 〔N2〕 | 幾乎都・主要 | ≒ {主\|おも}に；見 [錯題](../../mistakes/my-pitfalls.md) |
| {主\|おも}に | 〔N3〕 | 主要・大多 | 比 もっぱら 口語 |
| よく | 〔N5〕 | 常常 | |
| ときどき | 〔N5〕 | 有時候 | |
| たまに | 〔N4〕 | 偶爾 | |
| めったに〜ない | 〔N3〕 | 很少・幾乎不 | 後面一定接否定 |

頻率由高到低：`かならず・いつも ＞ もっぱら・おもに ＞ よく ＞ ときどき ＞ たまに ＞ めったに〜ない`
