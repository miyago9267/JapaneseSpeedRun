# 形容詞變化型

日文形容詞分兩類：**い形容詞**（字尾是い，直接改字尾）和 **な形容詞**（字根不動，靠だ屈折、接名詞時加な）。延伸：[動詞變化型](verb-conjugation.md)。

**怎麼用這頁：**

- **什麼時候來**：形容詞該怎麼否定・過去・接名詞・接動詞（副詞化）拿不準時；い形和な形分不清時（「陷阱」那節）。
- **自我測驗**：遮住右欄，看到「高い」「静か」先說出否定・過去・て形・副詞形；反過來，看到變形（高くなかった・静かに）倒推原型和類型。
- **卡住時**：只想查表 → [活用速查表](conjugation-cheatsheet.md)；條件形（たら・ば）混 → [條件形](../../compare/conditional-forms.md)；形容詞單字 → [形容詞單字本](../vocab/adjectives.md)。

**速查：** [活用速查表](conjugation-cheatsheet.md)——所有變化型一張表看完（本頁是語感教學）。

**同樣是查表用的。** 唯一要特別記的是「看起來像い形、其實是な形」那張陷阱表——`きれい`・`嫌い` 這種，考試專挑這些出。

## 按變化型

### 否定形「不～」

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `い → くない` | 高い→高く**ない**／寒い→寒くない／{難\|むずか}しい→難しくない |
| な形 | `字根 ＋ じゃない` | {暇\|ひま}→暇じゃ**ない**／{静\|しず}か→静かじゃない／{便利\|べんり}→便利じゃない |

### 過去形「曾經是～」

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `い → かった` | 高い→高**かった**／寒い→寒かった／{楽\|たの}しい→楽しかった |
| な形 | `字根 ＋ だった` | 暇→暇**だった**／静か→静かだった／{好\|す}き→好きだった |

### 過去否定形「以前不是～」

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `い → くなかった` | 高い→高く**なかった**／{忙\|いそが}しい→忙しくなかった |
| な形 | `字根 ＋ じゃなかった` | 暇→暇じゃ**なかった**／{有名\|ゆうめい}→有名じゃなかった |

### て形（連接）「～而且～」／串接多個描述

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `い → くて` | {安\|やす}い→安く**て**うまい／小さい→小さくて／寒い→寒くて |
| な形 | `字根 ＋ で` | 静か→静か**で**きれいな{部屋\|へや}／便利→便利で／{親切\|しんせつ}→親切で |

### 副詞化（修飾動詞・程度）

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `い → く` | {早\|はや}い→早**く**起きる／{強\|つよ}く押す／{上手\|うま}くやる |
| な形 | `字根 ＋ に` | 静か→静か**に**してください／{丁寧\|ていねい}に書く／親切に教える |

### 接名詞（直接修飾名詞）

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `原形 ＋ 名詞` | 高い{山\|やま}／寒い{日\|ひ}／うるさい人／{眠\|ねむ}い{授業\|じゅぎょう} |
| な形 | `字根 ＋ な ＋ 名詞` | 静か**な**{場所\|ばしょ}／有名**な**人／便利**な**アプリ／好き**な**{曲\|きょく} |

### たら形（假定）「如果～的話」（具體情境假設）

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `い → かったら` | 高い→高**かったら**買わない／安かったら買う／暑かったらエアコンつけて |
| な形 | `字根 ＋ だったら` | 暇→暇**だったら**来て／便利だったら使う／嫌いだったら残していい |

### ば形（條件）「如果～就～」（一般條件／假設）

| 類型 | 規則 | 例 |
|---|---|---|
| い形 | `い → ければ` | 高い→高**ければ**買わない／安ければ買う／寒ければ{窓\|まど}を閉めて |
| な形 | `字根 ＋ なら（ば）` | 暇→暇**なら**来て／便利なら使う／静かなら{集中\|しゅうちゅう}できる |

> [!WARNING]
> いい（好い）は例外：よ**ければ**。な形的 ば 一般用「なら」，正式可説「字根 ＋ であれば」（暇であれば）。

### 條件形比較：たら／ば／なら／と

| 條件形 | い形（高い） | な形（暇） |
|---|---|---|
| たら | 高かったら | 暇だったら |
| ば | 高ければ | 暇なら（ば） |
| なら | 高いなら | 暇なら |
| と | 高いと | 暇だと |

> [!WARNING]
> 語感：たら＝具體情境，最口語通用；ば＝一般條件／假設；なら＝「如果是～的話」帶前提或主題；と＝必然結果「一～就～」。な形的 ば 形其實就用「なら」。

### 陷阱：看起來像い形、其實是な形

字尾碰巧是い音，但行為像な形容詞。

| 詞 | 錯誤變法 | 正確變法 |
|---|---|---|
| きれい | きれいくない ✗ | きれいじゃない ✓／きれいな部屋 ✓ |
| {嫌\|きら}い | 嫌いくない ✗ | 嫌いじゃない ✓／嫌いな食べ物 ✓ |
| {真面目\|まじめ} | 真面目くない ✗ | 真面目じゃない ✓／真面目な人 ✓ |
| {素直\|すなお} | 素直くない ✗ | 素直じゃない ✓／素直な子 ✓ |
| {有名\|ゆうめい} | 有名くない ✗ | 有名じゃない ✓／有名な人 ✓ |
| {丁寧\|ていねい} | 丁寧くない ✗ | 丁寧じゃない ✓／丁寧に ✓ |

> [!WARNING]
> 判斷方式：試著在後面加「な＋名詞」。可以的就是な形容詞。きれいな部屋 → OK → な形。

## 按詞類

### い形容詞（高い・寒い・楽しい）

| 變化型 | 規則 | 例 |
|---|---|---|
| 原形（現在肯定） | `字典形（不變）` | 高い／寒い／楽しい |
| 否定 | `い → くない` | 高くない／寒くない／楽しくない |
| 過去 | `い → かった` | 高かった／寒かった／楽しかった |
| 過去否定 | `い → くなかった` | 高くなかった／寒くなかった／楽しくなかった |
| て形 | `い → くて` | 高くて／寒くて／楽しくて |
| 副詞化 | `い → く` | 高く／寒く／楽しく |
| 接名詞 | `原形＋名詞` | 高い山／寒い{夜\|よる}／楽しい{時間\|じかん} |
| たら形 | `い → かったら` | 高かったら／寒かったら／楽しかったら |
| ば形 | `い → ければ` | 高ければ／寒ければ／楽しければ |

> [!WARNING]
> いい（好い）は例外：否定→よくない　過去→よかった　副詞→よく　條件→よければ。「いくない」は存在しない。

### な形容詞（暇・静か・便利）

| 變化型 | 規則 | 例 |
|---|---|---|
| 原形（現在肯定） | `字根 ＋ だ` | 暇だ／静かだ／便利だ |
| 否定 | `字根 ＋ じゃない` | 暇じゃない／静かじゃない／便利じゃない |
| 過去 | `字根 ＋ だった` | 暇だった／静かだった／便利だった |
| 過去否定 | `字根 ＋ じゃなかった` | 暇じゃなかった／静かじゃなかった／便利じゃなかった |
| て形 | `字根 ＋ で` | 暇で／静かで／便利で |
| 副詞化 | `字根 ＋ に` | 暇に（較少用）／静かに／便利に |
| 接名詞 | `字根 ＋ な ＋ 名詞` | 暇な時間／静かな場所／便利なアプリ |
| たら形 | `字根 ＋ だったら` | 暇だったら／静かだったら／便利だったら |
| ば形 | `字根 ＋ なら（ば）` | 暇なら／静かなら／便利なら |

### 陷阱詞一覧（看起來像い形、其實是な形）

用「な＋名詞」測試。

| 詞 | 接名詞 | 否定 | て形 |
|---|---|---|---|
| きれい | きれいな部屋 ✓ | きれいじゃない | きれいで |
| {嫌\|きら}い | 嫌いな食べ物 ✓ | 嫌いじゃない | 嫌いで |
| {真面目\|まじめ} | 真面目な人 ✓ | 真面目じゃない | 真面目で |
| {素直\|すなお} | 素直な子 ✓ | 素直じゃない | 素直で |
| {有名\|ゆうめい} | 有名な人 ✓ | 有名じゃない | 有名で |
| {丁寧\|ていねい} | 丁寧な人 ✓ | 丁寧じゃない | 丁寧で |

## 例句

粗體是變化的部分；〔 〕是該文法點的級別。

**JLPT track**

- {駅|えき}から{遠|とお}**くなかった**ので、{荷物|にもつ}が{重|おも}くても{歩|ある}いて{帰|かえ}ることができた。〔N4〕い形的過去否定
- この{町|まち}は{静|しず}か**で**、{物価|ぶっか}も高**くない**ので、{一人暮|ひとりぐ}らしにはとても{住|す}みやすい。〔N4〕な形的て形＋い形的否定
- もう{少|すこ}し{安|やす}**ければ**{買|か}うのだが、この{値段|ねだん}では{予算|よさん}を{超|こ}えてしまう。〔N3〕い形的ば形→[條件形](../../compare/conditional-forms.md)
- {彼女|かのじょ}は{真面目|まじめ}**な**{人|ひと}で、{約束|やくそく}の{時間|じかん}に{遅|おく}れたことは{一度|いちど}もない。〔N4〕な形接名詞

**日常 track**

- あのラーメン{屋|や}、{思|おも}ったほど**おいしくなかった**んだけど、{量|りょう}だけはやたら{多|おお}かったよね。〔N4〕
- この{部屋|へや}、**きれいだし**、{駅|えき}からも{近|ちか}いし、**悪くない**んじゃない？〔N4・日常〕
- {昨日|きのう}の{映画|えいが}、**つまらなくて**{途中|とちゅう}で{寝|ね}ちゃった。〔N4・日常〕→[て形複合](te-compound.md)
- もっと**安かったら**買ったのになあ。〔N3〕→[條件形](../../compare/conditional-forms.md)
