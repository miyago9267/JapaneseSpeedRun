# 常用助詞

日文靠助詞標出「這個詞在句子裡扮演什麼角色」。這頁是 N5/N4 的**底層速查**：每個助詞的核心用法＋一句例子，最後列最常踩的陷阱。深入辨析：[は vs が](../../compare/wa-ga.md)・[細節助詞（も・しか・だけ・ばかり）](../../compare/focus-particles.md)・[句子解析](../parsing/sentence-parsing.md)。

**怎麼用這頁：**

- **什麼時候來**：助詞選不出來（に vs で、に vs へ、は vs が）、或讀長句要確認每個詞的角色時。
- **自我測驗**：先背「核心用法」欄的一個關鍵字，例句自己遮住再讀；陷阱表是考試和日常最常錯的地方，遮住答案自己選。
- **卡住時**：は vs が → [は vs が](../../compare/wa-ga.md)；も・しか・だけ 這類 → [細節助詞](../../compare/focus-particles.md)；拆句 → [句子解析](../parsing/sentence-parsing.md)。

## 核心用法速查

| 助詞 | 核心用法 | 例 |
| --- | --- | --- |
| `は` | 主題（「說到～」）・對比 | 私**は**学生です。／コーヒー**は**飲みますが、紅茶は飲みません。 |
| `が` | 主語（新資訊・焦點）；好き・わかる・できる・ほしい 的對象 | 誰**が**来ましたか。／私は犬**が**好きです。 |
| `を` | 他動詞的目的語；經過的場所；離開的起點 | 水**を**飲む。／公園**を**散歩する。／家**を**出る。 |
| `に` | 時間點・存在場所・到達點・對象・目的・變化結果 | 7時**に**起きる／教室**に**いる／学校**に**着く／友達**に**会う／買い物**に**行く／医者**に**なる |
| `で` | 動作場所・手段道具・原因・材料・範圍 | 図書館**で**勉強する／バス**で**行く／風邪**で**休む／木**で**作る |
| `へ` | 方向（朝著～） | 駅**へ**向かう。／東京**へ**行く。 |
| `と` | 一起（對象）・引用・完整列舉 | 友達**と**映画を見る。／「ありがとう」**と**言う。／りんご**と**バナナ |
| `から` | 起點（時間・場所）；理由（→ [から vs ので](../../compare/kara-node.md)） | 9時**から**始まる。／台湾**から**来ました。 |
| `まで` | 終點（時間・場所） | 5時**まで**働く。／駅**まで**歩く。 |
| `より` | 比較的基準（「比～」） | 今年は去年**より**暑い。 |
| `の` | 所有・修飾名詞；名詞化（→ [の 接續](no-nominalization.md)） | 私**の**本／日本語**の**先生 |
| `も` | 「也」「都」；疑問詞＋も＋否定 ＝「完全沒有」 | 私**も**行く。／何**も**食べなかった。 |
| `や` | 不完整列舉（「～啦～啦」，常搭 など） | 机の上に本**や**ペン**など**がある。 |
| `か` | 疑問；二選一 | 行きます**か**。／コーヒー**か**紅茶、どちらにしますか。 |

## 陷阱 1：に vs で（場所）

`に`＝**存在・到達**（東西「在」那裡），`で`＝**動作發生的場所**。

| 句型 | 助詞 | 例 |
| --- | --- | --- |
| 存在（ある・いる・住む・座る・泊まる） | `に` | 教室**に**学生がいる／日本**に**住んでいる／ここ**に**座ってください |
| 動作（勉強する・働く・食べる・買う） | `で` | 教室**で**勉強する／東京**で**働いている／駅前**で**買った |
| 舉行（会議・パーティー・試合） | `で` | 会議は三階**で**あります。 |

> [!WARNING]
> 同一個地點，動詞決定助詞：公園**に**いる（存在）／公園**で**遊ぶ（動作）。**判斷法：把動詞換成「在」還是「做」**——東西在那裡用 `に`，在那裡做事用 `で`。

## 陷阱 2：に vs へ

| | `に` | `へ` |
| --- | --- | --- |
| 到達點（「去到那裡」） | ✓ 学校**に**行く | ✓ 学校**へ**行く（多數情況可互換） |
| 強調方向／過程 | △ | ✓ 南**へ**向かう |
| 時間・對象・目的 | ✓ 3時**に**・友達**に**・買い物**に** | ✗ 不能用 |
| 接 `の`（名詞修飾） | ✗ | ✓ 東京**への**電車（`へ` ＋ `の`） |

> [!WARNING]
> 「去」「來」「回」的移動動詞，`に`／`へ` 通常都對。真的不能換的是**時間**（✗7時へ）和**對象**（✗友達へ会う）。

## 陷阱 3：を 不只接目的語

`を` 也標「**移動動詞經過的場所**」和「**離開的起點**」：

| 用法 | 例 |
| --- | --- |
| 經過・移動的空間 | 公園**を**散歩する／道**を**歩く／橋**を**渡る／空**を**飛ぶ |
| 離開的起點 | 家**を**出る／バス**を**降りる／大学**を**卒業する |

> [!WARNING]
> 「公園**で**散歩する」也能說（在公園裡散步，強調地點）；「公園**を**散歩する」強調**走過整個空間**。兩者都對，但 ✗公園に散歩する 是錯的。

## 陷阱 4：が 的「對象」

感情・能力・可能的對象用 `が`，不是 `を`：

| 句型 | 例 |
| --- | --- |
| 好き・嫌い・上手・下手 | 私は猫**が**好きです。 |
| わかる・できる・見える・聞こえる | 日本語**が**わかります／車の運転**が**できます |
| ほしい | 新しいパソコン**が**ほしい。 |

## 陷阱 5：時間詞要不要加 に

| 要加 `に`（具體時間點） | 通常不加 `に`（相對・習慣性的詞） |
|---|---|
| 7時**に**・3月**に**・日曜日**に** | 今日・昨日・明日・毎日・毎週・今週・来週・いつ |

> [!WARNING]
> ✗昨日**に**映画を見た → ✓昨日映画を見た。`に` 只接「時鐘上能指出的一個點」。

## 陷阱 6：から vs より／と vs や／も

| 比較 | 差別 | 例 |
| --- | --- | --- |
| `から` vs `より` | `から`＝「從」（起點）；`より`＝「比」 | 駅**から**近い（離車站近）／電車**より**バスのほうが安い |
| `と` vs `や` | `と`＝全部列完；`や`＝只舉例（後面常有 など） | 本**と**ペン（只有這兩樣）／本**や**ペン（書啦筆啦…） |
| `も` 取代什麼 | `も` 取代 `は`・`が`・`を`；**`に`・`で`・`と`・`から` 保留，再加 `も`** | 私**も**行く／京都**にも**行った／友達**とも**話した |

## 日常 track：助詞省略

口語常**省略 `は`・`が`・`を`**（語氣自然、不是錯）：

| 書面 | 口語 |
| --- | --- |
| ご飯を食べた？ | ご飯食べた？ |
| それはいいね。 | それ、いいね。 |
| 誰が来たの？ | 誰来たの？ |

> `に`・`で`・`へ`・`と`・`から`・`まで` 通常不省略，因為省掉就不知道角色了。日文請 Miyago 確認。
