# 使役形用法：誰讓誰做

變化規則在 [動詞變化型](verb-conjugation.md)，這課只管**讀懂**：助詞怎麼標、三種意思怎麼分。延伸：[自他動詞](jidoushi-tadoushi.md)、[讀解筆記](../../examples/reading-notes.md)。

**怎麼用這頁：**

- **什麼時候來**：讀到 〜せる／〜させる 分不清是強迫・許可・誘發，或助詞 を／に 該選哪個時。
- **自我測驗**：遮住中文，看例句先補出「誰讓誰做」三個角色，再判斷是強制・許可還是誘發；自己把 食べる／来る／する 變成使役形。
- **卡住時**：變化規則 → [動詞變化型](verb-conjugation.md)；自動詞他動詞的對應 → [自他動詞](jidoushi-tadoushi.md)。

**這課真正花力氣的是「誘發」那一類**——心配させる・その気にさせる 這種不是強迫誰做事，而是把對方的心弄成某個狀態。讀小說・對話最常遇到，也最容易只靠語感帶過。

## 看到 せる／させる：先補三個角色

| 角色 | 標記 | 問法 |
| --- | --- | --- |
| 使役者 | `が／は` | 誰讓的？ |
| 被使役者 | `を／に` | 讓誰？ |
| 動作 | 動詞本體 | 讓他做什麼／變成什麼？ |

> [!WARNING]
> 使役形本身是**一段動詞**：させる → させ**て**・させ**た**・させ**ない**，跟 食べる 同樣變。

## 助詞：を 還是 に

| 情況 | 規則 | 例 |
| --- | --- | --- |
| 自動詞（強制） | `人 を ＋ 使役` | 子供**を**買い物に行か**せる** |
| 自動詞（尊重意願・許可） | `人 に ＋ 使役` | 子供**に**好きなだけ遊ば**せる** |
| 他動詞 | `人 に ＋ N を ＋ 使役` | 子供**に**野菜**を**食べ**させる** |
| 情緒動詞 | `人 を ＋ 使役` | 母**を**心配**させる**／友達**を**笑わ**せる** |

> [!WARNING]
> 他動詞句已經有 `を`（受語），被使役者只能用 `に`，避免兩個 を。✗ 子供**を**野菜**を**食べさせる

## 三種意思

| 意思 | 判斷 | 例 |
| --- | --- | --- |
| 強制：叫～做 | 被使役者不想做 | 部下に残業**させる** |
| 許可：讓～做 | 被使役者想做 | 息子に留学**させる** |
| 誘發：讓人（心裡）～ | 動作是情緒・狀態變化 | 待た**せる**・驚か**せる**・その気に**させる** |

> [!WARNING]
> `Nになる` 的使役用 `Nにさせる`，✗ ならせる。その気になる → その気に**させる**。

## 口語縮約：せる → す

五段動詞的使役常縮成 `あ段 ＋ す`，看到要想到使役：

| 正式 | 口語 |
| --- | --- |
| 待た**せる** | 待た**す** |
| ちらつか**せる** | ちらつか**す** |
| 泣か**せる** | 泣か**す** |

## 使役受身：被逼著做〔N3〕

`使役 ＋ 受身`＝「被（某人）逼著做」。使役形本身是一段動詞，所以受身一律接 `られる`，て形也一律是 `〜られて`（不加 っ）。

| 動詞類 | 組法 | 正式 | 縮短（口語・也常見於考題） |
| --- | --- | --- | --- |
| 五段 | `あ段 ＋ せられる` | {飲\|の}ま**せられる**・{歌\|うた}わ**せられる**・{待\|ま}た**せられる** | `あ段 ＋ される`：{飲\|の}ま**される**・{歌\|うた}わ**される**・{待\|ま}た**される** |
| 五段（す 結尾） | `さ ＋ せられる` | {話\|はな}さ**せられる** | ✗ 不縮（{話\|はな}さ**さ**れる 唸起來兩個 さ 撞在一起） |
| 一段 | `語幹 ＋ させられる` | {食\|た}べ**させられる** | ✗ 不縮 |
| する | `させられる` | {残業\|ざんぎょう}**させられる** | ✗ 不縮 |
| 来る | `{来\|こ}させられる` | {来\|こ}**させられる** | ✗ 不縮 |

> [!WARNING]
> 縮短只是把 `せら` 換成 `さ`：{歌\|うた}わ**せら**れる → {歌\|うた}わ**さ**れる。✗ {歌\|うた}わ**さ**せられる（多了一個 さ）。五段的 あ段 跟 ない形一樣：う 結尾變 **わ**（{歌\|うた}わない → {歌\|うた}わせる），不是 あ。

| 例句 | 中文 |
| --- | --- |
| {子\|こ}どものころ、{毎日\|まいにち}ピアノを{練習\|れんしゅう}**させられた**。 | 小時候每天被逼著練琴。 |
| {飲\|の}み{会\|かい}で{先輩\|せんぱい}にお{酒\|さけ}をたくさん{飲\|の}ま**されて**、{今日\|きょう}は{頭\|あたま}が{痛\|いた}い。 | 聚餐被前輩灌了很多酒，今天頭好痛。 |
| {先生\|せんせい}にレポートを{書\|か}き{直\|なお}**させられた**。 | 被老師要求重寫報告。 |

## 強制・許可

**JLPT 軌道**
部長は新人に毎朝会議の資料を準備**させて**いるが、本人はあまり納得していないようだ。
両親は私がやりたいと言ったことは、たいてい最後まで自由にやら**せて**くれた。

**日常軌道**
弟に部屋の掃除やら**せた**ら、逆に散らかっててマジで意味なかった。
ちょっとだけでいいから、そのゲーム俺にもやら**せて**よ。

## 誘發

**JLPT 軌道**
連絡もせずに夜遅くまで帰らなかったので、母をずいぶん心配**させて**しまった。
彼のスピーチは会場の全員を笑わ**せた**だけでなく、最後には何人かを泣か**せた**。

**日常軌道**
ごめん、また待た**せ**ちゃったね。電車が急に止まっちゃってさ。
そうやって期待持た**せる**ようなこと言うの、ほんとやめてくれない？
