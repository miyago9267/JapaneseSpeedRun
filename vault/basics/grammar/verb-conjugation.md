# 動詞變化型

日文動詞分三類：**五段（う動詞）**、**一段（る動詞）**、**不規則（する・くる）**。先學會分類，才套得了各變化型的規則。延伸：[形容詞變化型](adjective-conjugation.md)。

**怎麼用這頁：**

- **什麼時候來**：看到變形的動詞認不出原型（食べさせられた・書かせて）；或要自己變出某個形時，先分類（五段・一段・不規則）再套規則。
- **自我測驗**：隨便挑一個動詞，遮住右欄，依序默寫 ない・ます・て・た・ば・可能・意向・受身・使役；反過來，看到變形倒推原型。
- **卡住時**：只要答案 → [活用速查表](conjugation-cheatsheet.md)；動詞黏動詞的複合型 → [複合動詞](compound-verbs.md)；背動詞 → [動詞單字本](../vocab/verbs.md)。

**速查：** [活用速查表](conjugation-cheatsheet.md)——所有變化型一張表看完（本頁是語感教學）。

**這課是查表用的，不用從頭背。** 需要練到反射的只有て形和ない形——它們後面掛著一大串文法（てしまう・ておく・なければならない…）。其餘變化型邊查邊用就會了。

## 先辨認動詞屬於哪一類

| 類型 | 怎麼認 | 例 |
| --- | --- | --- |
| 一段（る動詞） | `字尾る，且る前是い段／え段音` | 見る・食べる・起きる・{寝\|ね}る・{教\|おし}える |
| 五段（う動詞） | `字尾是う段：く・ぐ・す・つ・ぬ・ぶ・む・る・う` | 書く・泳ぐ・話す・待つ・飲む・買う・帰る（る前是え段，仍是五段） |
| 不規則 | `只有兩個，整組背` | する・くる（来る） |

> [!WARNING]
> 陷阱：字尾る＋前面是い／え段音「看起來像一段」，但這些其實是五段 → 帰る・{入|はい}る・{走|はし}る・{要|い}る・{知|し}る・{切|き}る。同音不同類：切る（きる・五段）vs 着る（きる・一段）。分不出來就查字典。

### 一段・五段怎麼分 〔N4〕

看 る 前面那個音：

| る前面的音 | 結果 | 例 |
| --- | --- | --- |
| あ・う・お段＋る | 一定是五段 | {分|わ}かる、{作|つく}る、{取|と}る |
| い・え段＋る | 大多是一段 | {見|み}る、{着|き}る、{起|お}きる、{食|た}べる |
| い・え段＋る，但是五段 | 硬背 | {帰|かえ}る、{切|き}る、{知|し}る、{入|はい}る、{走|はし}る、{要|い}る、{減|へ}る、{限|かぎ}る、{喋|しゃべ}る、{滑|すべ}る |

> [!WARNING]
> 同音不同類，讀音一樣但變法不同：
>
> - {着|き}る（一段）→ {着|き}て ／ {切|き}る（五段）→ {切|き}**って**
> - {変|か}える（一段）→ {変|か}えて ／ {帰|かえ}る（五段）→ {帰|かえ}**って**
> - {居|い}る（一段）→ {居|い}て ／ {要|い}る（五段）→ {要|い}**って**

拿不準就想ます形：{切|き}**り**ます（有り → 五段）；{着|き}ます（沒有り → 一段）。

## 五段的段位原理

五段動詞變化時，字尾在「自己那一行」的あ→お之間移動。以 **書く（か行：か・き・く・け・こ）** 為例：

| 五十音段 | 書く 變成 | 接哪些變化型 |
| --- | --- | --- |
| あ段 | 書**か** | ない形・受身・使役（書かない／書かれる／書かせる） |
| い段 | 書**き** | ます形（書きます） |
| う段 | 書**く** | 辞書形（原形，不變） |
| え段 | 書**け** | ば形・可能形（書けば／書ける） |
| お段 | 書**こ** | 意向形（書こう） |

> [!WARNING]
> 換動詞就換它自己那一行：待つ→た行（た・ち・つ・て・と）、飲む→ま行（ま・み・む・め・も）。**う 結尾的動詞 a段 用「わ」**：買う → 買わない（不是買あない）。て形／た形另外走音便（見下）。

**段位口訣**（一個段管一類意思）：

| 段 | 口訣 | 接什麼 |
| --- | --- | --- |
| あ段 | 「啊——不要／被／叫人」 | 否定 ない・受身 れる・使役 せる・ず・なければ |
| い段 | 「一連串」：接上別的東西 | ます・たい・ながら・やすい・方・複合動詞前半 |
| う段 | 「原」 | 辞書形本身・こと・つもり・ために |
| え段 | 「能、如果、給我」 | 可能 る・ば・命令 |
| お段 | 「喔！來吧」 | 意向 う（書こう） |

### 五段的特例 〔N4〕

| 特例 | 正確 | ✗ 常見錯 | 備註 |
| --- | --- | --- | --- |
| う 結尾的 あ段 用 わ | {買\|か}わない・{言\|い}われる | 買あない | 會う・使う・思う 全部適用 |
| {行\|い}く 的 て形・た形 | 行って・行った | 行いて | 其他形照規則：行かない・行けば |
| ある 的否定 | ない | あらない | 過去否定 なかった |
| 敬語五段：い段 不用 り | なさいます・くださいます・いらっしゃいます・おっしゃいます・ございます | なさります | 原形是 なさる・くださる・いらっしゃる・おっしゃる・ござる；命令形 なさい・ください・いらっしゃい |
| 長得像一段的五段 | {帰\|かえ}らない・{入\|はい}って・{知\|し}らない | 帰ない | 帰る・入る・走る・切る・知る・要る・減る・限る・喋る・蹴る |
| 問う・請う 的 て形〔N1・文言〕 | {問\|と}うて・{請\|こ}うて | 問って | 只在硬文章出現；口語改用 聞いて |

## 按變化型

每個變化型都分五段／一段／不規則三種變法。

### ない形（否定）「不做～」

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段 | `あ段 ＋ ない` | 書く→書か**ない**／飲む→飲まない／待つ→待たない／買う→買わない（わ） |
| 一段 | `去る ＋ ない` | 食べる→食べ**ない**／起きる→起きない |
| 不規則 | `單獨記` | する→し**ない**／くる→こ**ない** |

#### ない形接出來的「非做不可」一家

| 形式 | 級 | 規則 | 例 |
| --- | --- | --- | --- |
| なければならない | 〔N4〕 | `ない → なければ ＋ ならない` | {行\|い}か**なければならない** |
| なきゃ（いけない） | 〔日常〕 | `なければ → なきゃ` | {行\|い}か**なきゃ** |
| なくちゃ（いけない） | 〔日常〕 | `なくては → なくちゃ`（`ては → ちゃ`） | {行\|い}か**なくちゃ** |
| ないと（いけない） | 〔N4・日常〕 | `後半省略` | {行\|い}か**ないと** |

`ないと` 本身就是「不～的話」：接一般結果是條件，接 いけない 是「不～的話不行」＝義務。結尾的語感：`いけない` 偏主觀（自己的情況）・`ならない` 偏客觀（規定・義務，書面常見）・`だめ` 最隨便（對朋友家人）。

> [!WARNING]
> `ないと` 有兩個意思，看**後面還有沒有接句子**：
>
> - 有接 → 條件「不～的話就…」：{急|いそ}が**ないと**、{電車|でんしゃ}に{遅|おく}れるよ。
> - 句子在這裡斷掉 → 義務「得～了」：そろそろ{行|い}か**ないと**。
>
> 聽力的即時応答很愛考後者，例：A「もう{八時|はちじ}だよ。」→ B「じゃ、そろそろ{出|で}**ないと**。」

### ます形（禮貌肯定）「做～（禮貌）」；ません＝禮貌否定

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段 | `い段 ＋ ます` | 書く→書き**ます**／飲む→飲みます／待つ→待ちます |
| 一段 | `去る ＋ ます` | 食べる→食べ**ます**／起きる→起きます |
| 不規則 | `單獨記` | する→し**ます**／くる→き**ます** |

### て形（連接／請求／進行）

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段（く） | `く → いて` | 書く→書い**て** |
| 五段（ぐ） | `ぐ → いで` | 泳ぐ→泳い**で** |
| 五段（す） | `す → して` | 話す→話し**て** |
| 五段（む・ぬ・ぶ） | `→ んで` | 飲む→飲ん**で**／遊ぶ→遊ん**で** |
| 五段（る・う・つ） | `→ って` | 帰る→帰っ**て**／買う→買っ**て**／待つ→待っ**て** |
| 一段 | `去る ＋ て` | 食べる→食べ**て**／起きる→起き**て** |
| 不規則 | `單獨記` | する→し**て**／くる→き**て** |

**て形口訣**〔N5〕：う・つ・る → って、む・ぶ・ぬ → んで、く → いて、ぐ → いで、す → して；一段 → 去る ＋ て。

口訣：「うつる って、むぶぬ んで、く いて、ぐ いで、す して」

- 「有 ん 就是 で」：ん 後面一定接 で（んて ✗）。
- 「只有五段會出現 っ；一段只是把る換成て」：一段沒有 っ，去る ＋ て（起きって ✗）。

> [!WARNING]
> 行く 是 く 結尾的例外 → {行|い}**って**（{行|い}いて ✗）。問う・請う 的 て形見上方「五段的特例」表。
>
> 「ます形去ます＋て」只對一段和す結尾有效：{食|た}べ**て** ✓、{話|はな}し**て** ✓；{習|なら}います → {習|なら}いて ✗ → {習|なら}**って** ✓。

### た形（過去式）「做了～」；規則同て形，て換成た

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段（く） | `く → いた` | 書く→書い**た** |
| 五段（ぐ） | `ぐ → いだ` | 泳ぐ→泳い**だ** |
| 五段（す） | `す → した` | 話す→話し**た** |
| 五段（む・ぬ・ぶ） | `→ んだ` | 飲む→飲ん**だ**／遊ぶ→遊ん**だ** |
| 五段（る・う・つ） | `→ った` | 帰る→帰っ**た**／買う→買っ**た**／待つ→待っ**た** |
| 一段 | `去る ＋ た` | 食べる→食べ**た**／起きる→起き**た** |
| 不規則 | `單獨記` | する→し**た**／くる→き**た** |

> [!WARNING]
> 例外：行く → 行った（不是行いた）

### ば形（條件）「如果做～的話」

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段 | `え段 ＋ ば` | 書く→書け**ば**／飲む→飲めば／待つ→待てば |
| 一段 | `去る ＋ れば` | 食べる→食べれ**ば**／起きる→起きれ**ば** |
| 不規則 | `單獨記` | する→すれ**ば**／くる→くれ**ば** |

### 可能形（能力）「做得到～／能做～」

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段 | `え段 ＋ る` | 書く→書け**る**／飲む→飲める／待つ→待てる |
| 一段 | `去る ＋ られる` | 食べる→食べ**られる**／起きる→起き**られる** |
| 不規則 | `單獨記` | する→**できる**／くる→こ**られる** |

> [!WARNING]
> する 的可能形是 できる，不是しられる。

### 意向形（意志／邀請）「（我）要做～吧／一起做～吧」

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段 | `お段 ＋ う` | 書く→書こ**う**／飲む→飲もう／待つ→待とう |
| 一段 | `去る ＋ よう` | 食べる→食べ**よう**／起きる→起き**よう** |
| 不規則 | `單獨記` | する→し**よう**／くる→こ**よう** |

### 受身形（被動）「被～／受到～」

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段 | `あ段 ＋ れる` | 書く→書か**れる**／飲む→飲まれる／待つ→待たれる |
| 一段 | `去る ＋ られる` | 食べる→食べ**られる**／起きる→起き**られる** |
| 不規則 | `單獨記` | する→さ**れる**／くる→こ**られる** |

> [!WARNING]
> 一段的可能形和受身形都是られる，靠語境判斷。

### 使役形（使役）「讓～做／叫～做」

| 類型 | 規則 | 例 |
| --- | --- | --- |
| 五段 | `あ段 ＋ せる` | 書く→書か**せる**／飲む→飲ませる／待つ→待たせる |
| 一段 | `去る ＋ させる` | 食べる→食べ**させる**／起きる→起き**させる** |
| 不規則 | `單獨記` | する→さ**せる**／くる→こ**させる** |

## 按詞類

### 五段（書く・泳ぐ・話す・飲む・待つ・買う）

| 變化型（用途） | 字尾落點 | 例 |
| --- | --- | --- |
| 辞書形（原形） | `う段（不變）` | 書く／泳ぐ／話す／飲む／待つ／買う |
| ない形（否定） | `あ段 ＋ ない` | 書かない／泳がない／話さない／飲まない／待たない／買わない（わ） |
| ます形（禮貌） | `い段 ＋ ます` | 書きます／泳ぎます／話します／飲みます／待ちます／買います |
| て形（連接） | `音便` | 書いて／泳いで／話して／飲んで／待って／買って |
| た形（過去） | `音便（て→た）` | 書いた／泳いだ／話した／飲んだ／待った／買った |
| ば形（條件） | `え段 ＋ ば` | 書けば／泳げば／話せば／飲めば／待てば／買えば |
| 可能形（能力） | `え段 ＋ る` | 書ける／泳げる／話せる／飲める／待てる／買える |
| 意向形（意志） | `お段 ＋ う` | 書こう／泳ごう／話そう／飲もう／待とう／買おう |
| 受身形（被動） | `あ段 ＋ れる` | 書かれる／泳がれる／話される／飲まれる／待たれる／買われる |
| 使役形（使役） | `あ段 ＋ せる` | 書かせる／泳がせる／話させる／飲ませる／待たせる／買わせる |

> [!WARNING]
> て形／た形音便：く→いて／いた・ぐ→いで／いだ・す→して／した・む/ぬ/ぶ→んで／んだ・る/う/つ→って／った。例外 行く → 行って／行った。

### 一段（食べる・見る・起きる）

| 變化型（用途） | 規則 | 例 |
| --- | --- | --- |
| 辞書形（原形） | `原形（不變）` | 食べる／見る／起きる |
| ない形（否定） | `去る ＋ ない` | 食べない／見ない／起きない |
| ます形（禮貌） | `去る ＋ ます` | 食べます／見ます／起きます |
| て形（連接） | `去る ＋ て` | 食べて／見て／起きて |
| た形（過去） | `去る ＋ た` | 食べた／見た／起きた |
| ば形（條件） | `去る ＋ れば` | 食べれば／見れば／起きれば |
| 可能形（能力） | `去る ＋ られる` | 食べられる／見られる／起きられる |
| 意向形（意志） | `去る ＋ よう` | 食べよう／見よう／起きよう |
| 受身形（被動） | `去る ＋ られる` | 食べられる／見られる／起きられる |
| 使役形（使役） | `去る ＋ させる` | 食べさせる／見させる／起きさせる |

> [!WARNING]
> 可能形和受身形同形（られる），靠語境判斷。口語可能形常「ら抜き」：食べれる・見れる。

### 不規則（する／くる）

| 變化型（用途） | する | くる（来る） |
| --- | --- | --- |
| 辞書形（原形） | する | くる |
| ない形（否定） | しない | こない |
| ます形（禮貌） | します | きます |
| て形（連接） | して | きて |
| た形（過去） | した | きた |
| ば形（條件） | すれば | くれば |
| 可能形（能力） | できる | こられる |
| 意向形（意志） | しよう | こよう |
| 受身形（被動） | される | こられる |
| 使役形（使役） | させる | こさせる |

> [!WARNING]
> する 的可能形是 できる，不是しられる。くる 的讀音整組在變（こ／き／く），不是只換字尾。

## 肯定／否定

普通形＝常體（朋友・家人・日記）；丁寧形＝です・ます體（對外・正式）。否定的「過去」是 ない→なかった、ません→ませんでした。

### 五段（書く）

| 時制・文體 | 肯定 | 否定 |
| --- | --- | --- |
| 現在・普通 | 書く | 書か**ない** |
| 現在・丁寧 | 書き**ます** | 書き**ません** |
| 過去・普通 | 書い**た** | 書か**なかった** |
| 過去・丁寧 | 書き**ました** | 書き**ませんでした** |

### 一段（食べる）

| 時制・文體 | 肯定 | 否定 |
| --- | --- | --- |
| 現在・普通 | 食べる | 食べ**ない** |
| 現在・丁寧 | 食べ**ます** | 食べ**ません** |
| 過去・普通 | 食べ**た** | 食べ**なかった** |
| 過去・丁寧 | 食べ**ました** | 食べ**ませんでした** |

### 不規則（する）

| 時制・文體 | 肯定 | 否定 |
| --- | --- | --- |
| 現在・普通 | する | し**ない** |
| 現在・丁寧 | し**ます** | し**ません** |
| 過去・普通 | し**た** | し**なかった** |
| 過去・丁寧 | し**ました** | し**ませんでした** |

### 不規則（くる・来る）

| 時制・文體 | 肯定 | 否定 |
| --- | --- | --- |
| 現在・普通 | くる | **こ**ない |
| 現在・丁寧 | **き**ます | **き**ません |
| 過去・普通 | **き**た | **こ**なかった |
| 過去・丁寧 | **き**ました | **き**ませんでした |

### 其他變化型怎麼變否定（以 書く 為例）

| 變化型 | 肯定 | 否定 |
| --- | --- | --- |
| て形 | 書いて | 書か**なくて**／書か**ないで** |
| ば形 | 書けば | 書か**なければ** |
| 可能形 | 書ける | 書け**ない** |
| 受身形 | 書かれる | 書かれ**ない** |
| 使役形 | 書かせる | 書かせ**ない** |

> [!WARNING]
> て形否定有兩種：〜なくて＝原因／狀態（書かなくて困る）；〜ないで＝請求／不做某事（書かないでください）。可能・受身・使役本身是一段型，否定一律「去る ＋ ない」。
