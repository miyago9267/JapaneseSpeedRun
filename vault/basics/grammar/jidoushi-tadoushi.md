# 自他動詞

日文動詞分兩種性格：**他動詞**（我對東西做某事・有對象）、**自動詞**（東西自己發生了某事・無主動施者）。助詞選錯・ている 意思就完全跑掉。延伸：[動詞變化型](verb-conjugation.md)。

**怎麼用這頁：**

- **什麼時候來**：を 和 が 選不出來、〜ている 意思翻面（是「正在做」還是「做完的狀態」）時。
- **自我測驗**：遮住右欄的自動詞，看他動詞先說出配對的自動詞；再造「ドアが開いている」「ドアを開けている」各一句，說出差別。
- **卡住時**：背配對 → [動詞單字本](../vocab/verbs.md)；ている 的細節 → [て形複合](te-compound.md)；使役形 → [使役形用法](causative.md)。

**這課真正要吃下去的是「ている 的意思」那一節**——自他選錯會讓句子意思整個翻面。前面的配對規律認得就好，臨時想不起來可以查字典。

## 核心差異

| | {他動詞\|たどうし} | {自動詞\|じどうし} |
|---|---|---|
| 是什麼 | 施者「對某物」做的動作 | 某事「自行」發生的狀態 |
| 搭配助詞 | `を`（直接賓語） | `が`（主語自行發生） |
| 典型例 | 窓**を**開ける（我開窗） | 窓**が**開く（窗開了） |

> [!WARNING]
> 助詞就是關鍵：を → 他動詞；が → 自動詞。寫を但用了自動詞（窓を開く）、或寫が但用了他動詞（窓が開ける）都算錯。

## 形狀辨認：常見配對規律

大部分自他動詞是成對的，字形有規律可循。

| 規律 | 他動詞（を） | 自動詞（が） |
|---|---|---|
| `〜ける ／ 〜く` | 開**ける**・続**ける** | 開**く**・続**く** |
| `〜す ／ 〜る` | 出**す**・起こ**す**・落と**す**・消**す** | 出**る**・起き**る**・落ち**る**・消え**る** |
| `〜える ／ 〜わる` | 変**える**・終**える**・伝**える**・集め**る** | 変**わる**・終**わる**・伝**わる**・集**まる** |
| `〜れる ／ 〜る` | 入れ**る**・乗せ**る** | 入**る**・乗**る** |
| 不規則 | 見**せる**・着**る**（自他判斷靠語境） | 見**える**・聞こえ**る** |

> [!WARNING]
> 消す（他）vs 消える（自）看起來不像一對，但就是同義對：「我消掉它」vs「它消失了」。す結尾 = 幾乎都是他動詞。

## ている 的意思：自他決定一切

接 ている 時，自・他的選擇直接改變語義：

| 句型 | 例句 | 意思 |
|---|---|---|
| **他動詞** + ている | ドア**を**開け**ている** | 「正在開門」（動作進行中） |
| **自動詞** + ている | ドア**が**開い**ている** | 「門是開著的」（結果狀態） |
| 他動詞 + ている | 電気**を**消し**ている** | 「正在關燈」 |
| 自動詞 + ている | 電気**が**消え**ている** | 「燈是熄的」（已熄滅狀態） |

> [!WARNING]
> 「窓が開いている」≠「有人現在正在開窗」，是「窗子處於打開的狀態」。要說「有人在開窗」必須用 窓を開けている。N2 作文最常見的語義混淆就在這。

## 沒有配對的動詞（只有其中一個）

少數動詞只存在自動詞形或只存在他動詞形：

- **只有他動詞**：食べる・飲む・読む・書く（本來就是對外做的事）
- **只有自動詞**：ある・いる・来る（存在狀態）
- 要強制「讓它發生」→ 用使役形 食べさせる・飲ませる

## 快速判斷法

1. 有施者對某物做事 → 他動詞 ＋ を
2. 東西自行發生／狀態改變 → 自動詞 ＋ が
3. 看字尾：**す** 結尾幾乎都他動詞；**〜わる・〜まる・〜ける（→く)・〜る** 結尾多自動詞
4. 不確定 → 查字典找「他」「自」標記

## 動詞的方向：自・他・受身・使役

同一件事，主角換人，動詞就換形。先問「誰做」「對誰做」「誰被影響」。

| 形態 | 主角 | 例（開門） | 中文 |
| --- | --- | --- | --- |
| 自動詞 | 事物自己動 | ドア**が**{開\|あ}く | 門開了 |
| 他動詞 | 有人動手 | {私\|わたし}**が**ドア**を**{開\|あ}ける | 我開門 |
| 受身（被動） | 被影響的人 | （私は）{誰\|だれ}か**に**ドア**を**{開\|あ}けられた | （我的）門被人打開了 |
| 使役 | 下命令的人 | {母\|はは}**が**{弟\|おとうと}**に**ドア**を**{開\|あ}けさせる | 媽媽叫弟弟開門 |
| 使役受身 | 被逼的人 | {弟\|おとうと}**が**{母\|はは}**に**ドア**を**{開\|あ}けさせられる | 弟弟被媽媽逼著開門 |

### 變化公式

| 類型 | 受身 | 使役 | 使役受身 |
| --- | --- | --- | --- |
| 五段（{書\|か}く） | あ段＋れる：書**かれる** | あ段＋せる：書**かせる** | 書**かせられる**（口語 書**かされる**） |
| 一段（{食\|た}べる） | る→られる：食べ**られる** | る→させる：食べ**させる** | 食べ**させられる** |
| する | **される** | **させる** | **させられる** |
| {来\|く}る | **{来\|こ}られる** | **{来\|こ}させる** | **{来\|こ}させられる** |

- 五段字尾 `う` 的あ段是 `わ`：{言\|い}う → 言**わ**れる・言**わ**せる；{行\|おこな}う → 行**わ**れる。
- 疊加順序固定：**使役 → 受身 → て／た／ない**。例：{待\|ま}つ → 待た**せ**る → 待たせ**られ**る → 待たせられ**た**（被迫等了）。
- 變完的使役・受身都變成**一段動詞**，之後照一段接：させる→させ**て**／させ**た**／させ**ない**。

> [!WARNING]
> 一段動詞的**受身＝可能**（{食\|た}べられる 可以是「被吃」或「能吃」），看前面助詞：`に` 帶出動作者 → 受身；`が／を` 接對象、沒有動作者 → 可能。
> 自動詞沒有 を：✗ 宿題を終わる → ✓ 宿題**が**終わる／宿題**を**終わら**せる**。

## 例句

**JLPT track**

- {窓|まど}が**{開|あ}いて**いるので、{冷|つめ}たい{風|かぜ}が{入|はい}ってきて{寒|さむ}い。〔N4〕自動詞＋ている＝結果的狀態→[て形複合](te-compound.md)
- {誰|だれ}かが{窓|まど}を**{開|あ}けた**まま{帰|かえ}ったらしい。〔N4〕他動詞（有人做的）
- {部屋|へや}の{電気|でんき}が**ついて**いるから、まだ{誰|だれ}か{残|のこ}っているのだろう。〔N4〕
- {会議|かいぎ}の{時間|じかん}が**{変|か}わった**ので、スケジュールを**{変|か}えなければ**ならなくなった。〔N4〕自動詞（変わる）↔ 他動詞（変える）

**日常 track**

- あれ、ドア**開いてる**。{誰|だれ}か{閉|し}め{忘|わす}れたのかな？〔日常〕→[複合動詞](compound-verbs.md)
- ごめん、ケータイの{電池|でんち}が**切れちゃった**んだけど、{充電器|じゅうでんき}{貸|か}してくれない？〔日常〕
- ごめん、うっかりコップ**割っちゃった**。……あ、**割れてる**から{触|さわ}らないでね。〔日常〕他（割る）↔ 自（割れる）
- {財布|さいふ}が**見つからない**んだけど、さっきまでカバンに**入ってた**はずなんだよね。〔日常〕
