# 學習方法：怎麼用這個 vault 做筆記

這個 vault 是**教材**，不是你的筆記本。真正讓日文進腦袋的，是你**自己動手寫、自己默寫、隔幾天再回來**。這頁教沒學過怎麼做筆記的人：怎麼搭配 agent、怎麼手寫、怎麼複習、一週怎麼排。

## 1. 先搞清楚分工

| 誰 | 做什麼 |
| --- | --- |
| **agent** | 整理、查表、出題、把你問過的東西自動記進 vault、build、推上網站 |
| **你** | 看、問、遮住默寫、自己造句、判斷日文對不對 |

**原則：筆記越漂亮越不代表你會。** 看得懂表格和自己能寫出來是兩件事；考試和對話都在考後者。

## 2. vault 的四個資料夾怎麼用

| 資料夾 | 它是什麼 | 你怎麼用它 |
| --- | --- | --- |
| `basics/` 基礎 | `vocab/` 文字・語彙、`grammar/` 文法、`parsing/` 解析（活用・助詞・單字・複合動詞・拆句） | **補底**。弱的地方整頁慢慢讀，用速查表當字典 |
| `compare/` 比較 | 近義詞的差別（から vs ので…） | **有混淆時才看**。問 agent「A 和 B 差在哪」，它會補進來 |
| `examples/` 實例 | 你貼的 galgame・書・新聞的拆解、生活用語 | **讀原文時的字典**。貼截圖問，答完自動記錄 |
| `mistakes/` 我的錯題 | 你答錯・翻錯的點 | **最重要的複習來源**。越常看越有效 |

**怎麼問 agent 最有效：**

1. 貼不會的句子或截圖 →「幫我拆解」（它會記進 `examples/`）
2. 覺得兩個東西很像 →「A 和 B 差在哪？」（記進 `compare/`）
3. 想知道怎麼說 →「『我先走了』日文怎麼講？」（記進 `examples/daily-phrases.md`）
4. 想確認自己會不會 →「出題考我」，之後答錯的會挑進 `mistakes/`
5. 自己造句或翻譯 → 請它批改，錯的會記進 `mistakes/`

## 3. 手寫筆記：怎麼寫

**大原則：看著 vault 學，但不要抄表格。** 抄的時候腦子是關的。

### 3.1 先遮住再默寫

1. 看一遍某個表格（約 1–2 分鐘）。
2. **遮住表格**（用紙或手），在你的筆記本上憑記憶寫出來。
3. 打開對答案，**用另一種顏色**把錯的、漏的補上。

寫不出來的那些才是真正需要記的。

### 3.2 Cornell 筆記（適合文法課）

一頁分三塊：

| 區塊 | 位置 | 寫什麼 |
| --- | --- | --- |
| 提問欄 | 左邊窄欄 | 關鍵問題：「五段動詞的て形怎麼變？」「から 和 ので 差在哪？」 |
| 內容欄 | 右邊寬欄 | 規則、例句（自己寫的，不是抄 vault 的） |
| 摘要 | 頁面下方 | 用**一兩句話**總結這頁 |

複習時**遮住右邊，只看左邊的問題**，回答出來再對答案。

一個文法點固定寫四格，左欄是問題、右欄是答案：

| 左欄（問題） | 右欄（自己寫） |
| --- | --- |
| 這是什麼？ | 規則：一行公式，用自己的話 |
| 怎麼念？ | 讀音：漢字全部標假名，**邊寫邊念出聲** |
| 怎麼用？ | 例句：考試一句、口語一句 |
| 會錯在哪？ | 陷阱：自己錯過的那一句 |

「怎麼念」這格不能省：只靠中文字義看懂漢字，讀音就永遠記不住，文字題和聽力會一起倒。

### 3.3 錯題本：三欄格式

| 原句 ✗ | 正解 ✓ | 錯因 |
| --- | --- | --- |
| 昨日に映画を見た | 昨日映画を見た | 昨日 這類詞不加 に |
| ✗学生だので | 学生なので | ので 前面名詞要加 な |

寫完錯因後，在旁邊註記 vault 的對應頁（例：`basics/grammar/particles.md`）。**錯題本是三本裡最值錢的一本。**

### 3.4 一頁一主題・顏色分工

- **一頁只寫一個主題**（例：「て形」、「から vs ので」）。寫不下就拆成兩頁。
- 顏色固定（三種就夠）：

| 顏色 | 用來標 |
| --- | --- |
| 藍 | 規則・公式（`あ段 ＋ ない`） |
| 黑 | 例句 |
| 紅 | 陷阱・例外・自己會錯的地方 |

這和網站上的樣式（rule chip／警告框）是同一套邏輯，視覺上就能對應。

## 4. 單字怎麼手寫

很多人背單字卡在「看到變形認不出原型」。對策：**每個字都寫成同一種排版**，把原型和變形綁在一起。

**單字本一行一個字（對應 vault 的 `basics/vocab/`）：**

| 左 | 中 | 右 | 最右 |
|---|---|---|---|
| 辭書形＋讀音（帰る／かえる） | 詞類標記（動：五／一／不・自／他；形：い／な） | 2–3 個關鍵變形（帰ります・帰って・帰らない） | 意思 |

**單字卡（正反面）：**

- **正面只寫變形**（例：帰って），背面寫**原型＋類型＋意思**（帰る・五・自・回家）——練「看到變形能還原」。
- 再做一張**反向卡**：正面寫原型和意思，背面默寫變形——練「看到原型能變出來」。

**自測：** 遮住右半部（變形和意思），只看左邊的原型和詞類，說得出來才算過；錯的在旁邊畫紅點。

**累積次數：** 同一個字在 `examples/`（讀原文）又遇到時，在本子上那個字旁邊**打一個勾**。勾越多代表越常見、越值得優先背；一個勾都沒有的字可以晚點再背。

## 5. 複習：主動回想 ＋ 間隔

**主動回想（active recall）**＝不看答案，先硬想。**間隔複習（spaced review）**＝隔幾天再想一次。這兩個加起來是最有效率的記憶方法。

**複習節點：新學完後的第 1・3・7・14・30 天各複習一次**，每次只要 5–10 分鐘。

| 資料夾 | 怎麼複習 | 節奏 |
| --- | --- | --- |
| `basics/` | 遮住表格默寫活用・助詞；用 `basics/grammar/conjugation-cheatsheet.md` 自測 | 學完後第 1・3・7・14・30 天 |
| `compare/` | 不看筆記，自己造兩個句子分別用 A 和 B | 第 3・7・14 天 |
| `examples/` | 遮住翻譯和結構，自己讀原文、念出意思；生活用語則看中文說日文 | 第 7・14・30 天 |
| `mistakes/` | **只看左欄的原句**，自己改正並說出錯因 | 第 1・3・7・14・30 天；錯第二次就重新排 |

> [!WARNING]
> 複習不要「再看一遍」。**看＝熟悉感，不是記得。** 一定要先遮住、先回想、卡住了才看答案。

## 6. 每週節奏（弱 N5／N4 底子、重考 JLPT）

底子弱的時候，**先補基礎，再練 N3–N2 的讀解和文法**，不要直接硬做 N2。

| 日 | 內容（每天 30–60 分鐘） |
| --- | --- |
| 一 | `basics/`：新的一課（活用・助詞・單字擇一），遮住默寫 |
| 二 | 複習昨天（第 1 天）＋ 新單字 10–20 個 |
| 三 | `compare/`：一組混淆點；請 agent 出 5 題 |
| 四 | 複習週一內容（第 3 天）＋ 讀一段原文（`examples/`），貼不懂的給 agent |
| 五 | 做一組練習題（JLPT track）；答錯的請 agent 收進 `mistakes/` |
| 六 | 整理本週錯題本：每一題遮住原句改寫，不會的標紅 |
| 日 | 休息或輕鬆複習：看一遍 `mistakes/` 左欄；其餘不要硬塞新東西 |

**每週固定檢查：** 這週 `mistakes/` 新增了幾題？重複錯的那幾題，是哪一個 `basics/` 或 `compare/` 的缺口？回去補那一頁。

### 考前一個月（衝刺版）

離考試只剩一個月時，上面的週表先停，改成衝分數：聴解有單科門檻，先保證跨過；言語知識靠背就能回收；読解不另外練。

| 週 | 主軸 |
| --- | --- |
| 第 1 週 | 聽力即時応答 ＋ 漢字讀音陷阱 ＋ N2 文型接續 |
| 第 2 週 | 同上，文型改成按意思分群比較 |
| 第 3 週 | 做一份完整模考，錯題全部回收 |
| 第 4 週 | 只修錯題，不加新東西 |

每天：`/listen` 5 題（約七成時間）＋ `/quiz` 讀音 10 題、文型 5 題。週末做 jlpt.jp 官方「問題例」的聽力，聽真人錄音。

N2 聴解 32 題的打法：

| 大題 | 題數 | 打法 |
| --- | --- | --- |
| 問題4 即時応答 | 12 | 主力：敬語、慣用回應、口語縮約（なきゃ・ちゃう・とく） |
| 問題1 課題理解 | 5 | 先看選項，專心聽開頭的提問（まず何をしますか） |
| 問題2 ポイント理解 | 6 | 同上，抓「なぜ／どうして」後面的理由 |
| 問題3・5 概要／統合 | 9 | 時間不夠先不精練，靠前面的技巧撿分 |

**讀長句的習慣：** 句子不要只看懂就過，把長句斷成片段（助詞標角色），再整句念一遍——這樣對讀解的忍耐力才會一路長。

## 7. 遠端工作流

整個流程是**一台常開的 Windows 桌機當「主機」**，其他裝置只是遙控：

1. 主機（這台 Windows 桌機）跑 Claude Code，並開著 `/remote-control`。
2. 你在手機或其他地方對 agent 提問、貼截圖、要求出題。
3. agent 在主機上把內容寫進 `vault/`，`bun run docs:build` 通過後 commit 並 push `main`。
4. GitHub Actions 自動 build 並部署，過一小段時間 `jp.miyago9267.com` 就更新。
5. 其他裝置的 Obsidian 用 `git pull` 同步 vault（想看最新內容時 pull 一下）。

| 你在… | 做什麼 |
| --- | --- |
| 手機（外出） | 問問題、貼截圖；回家前網站已更新，可直接瀏覽 |
| 其他電腦的 Obsidian | `git pull` 後看最新筆記；**不要在兩邊同時改同一檔**，避免衝突 |
| 上班的 Mac | 直接在 repo 跑 Claude Code，用 `/quiz`、`/listen` 練；agent 開頭會先 `git pull`，結束會 push |
| 手寫筆記本 | 對著網站或 Obsidian 做 3.1 的默寫練習 |

> [!WARNING]
> 日文最後一定要你自己確認。agent 會把整理好的日文交回給你看；覺得怪就直接說，它會改——這是整個流程裡唯一不能省的人工步驟。

## 8. 起手式（今天就能開始）

1. 打開 `basics/grammar/conjugation-cheatsheet.md`，選**動詞**那張表，遮住右邊默寫て形和ない形（只做這兩個）。
2. 對答案，錯的用紅筆寫進錯題本。
3. 明天（第 1 天）再默寫一次；後天不用，第 3 天再來。
4. 對 agent 說：「出 5 題て形和ない形，考我。」答錯的請它收進 `mistakes/`。

## 9. Obsidian 顯示振假名（Markdown Furigana 外掛）

筆記裡的讀音用 ruby 語法寫，例如 `{難|むずか}しい`、`{帰|かえ}る`（送假名寫在大括號外面）。網站 build 時會自動變成漢字上方的小假名；在 Obsidian 要**裝一個社群外掛**才看得到同樣的效果：

1. Obsidian → **Settings**（設定）→ **Community plugins**（社群外掛）。第一次用要先關掉「受限模式」（Turn on community plugins）。
2. 點 **Browse**，搜尋 **Markdown Furigana**（作者 steven-kraft）。
3. **Install** → **Enable**。

| 狀態 | 你會看到什麼 |
| --- | --- |
| 已安裝並啟用 | 漢字上方有小假名（閱讀模式與 Live Preview 都會渲染；游標移到該處時顯示原始碼） |
| 沒裝／沒啟用 | 看到原始碼 `{難\|むずか}しい` 這種 `{…\|…}`；內容沒壞，只是沒有渲染 |

語法備忘：

- 一般寫法 `{漢字|かんじ}`；一字一音可寫 `{漢字|かん|じ}`（段數要等於字數）。
- 表格裡的 `|` 要跳脫成 `\|`（`{漢字\|かんじ}`），否則表格欄位會被切開；網站與外掛都吃這個寫法。
- 程式碼區塊與行內 `` `code` `` 裡不會渲染。
