# 使役形用法：誰讓誰做

變化規則在 [動詞變化型](verb-conjugation.md)，這課只管**讀懂**：助詞怎麼標、三種意思怎麼分。延伸：[自他動詞](jidoushi-tadoushi.md)、[讀解筆記](reading-notes.md)。

**這課真正花力氣的是「誘發」那一類**——心配させる・その気にさせる 這種不是強迫誰做事，而是把對方的心弄成某個狀態。讀小說・對話最常遇到，也最容易只靠語感帶過。

## 看到 せる／させる：先補三個角色

| 角色 | 標記 | 問法 |
| --- | --- | --- |
| 使役者 | `が／は` | 誰讓的？ |
| 被使役者 | `を／に` | 讓誰？ |
| 動作 | 動詞本體 | 讓他做什麼／變成什麼？ |

> [!WARNING]
> 使役形本身是**一段動詞**：させる → させ**て**・させ**た**・させ**ない**，跟 食べる 同樣變。

## 助詞：を 還是 に

| 情況 | 規則 | 例 |
| --- | --- | --- |
| 自動詞（強制） | `人 を ＋ 使役` | 子供**を**買い物に行か**せる** |
| 自動詞（尊重意願・許可） | `人 に ＋ 使役` | 子供**に**好きなだけ遊ば**せる** |
| 他動詞 | `人 に ＋ N を ＋ 使役` | 子供**に**野菜**を**食べ**させる** |
| 情緒動詞 | `人 を ＋ 使役` | 母**を**心配**させる**／友達**を**笑わ**せる** |

> [!WARNING]
> 他動詞句已經有 `を`（受語），被使役者只能用 `に`，避免兩個 を。✗ 子供**を**野菜**を**食べさせる

## 三種意思

| 意思 | 判斷 | 例 |
| --- | --- | --- |
| 強制：叫～做 | 被使役者不想做 | 部下に残業**させる** |
| 許可：讓～做 | 被使役者想做 | 息子に留学**させる** |
| 誘發：讓人（心裡）～ | 動作是情緒・狀態變化 | 待た**せる**・驚か**せる**・その気に**させる** |

> [!WARNING]
> `Nになる` 的使役用 `Nにさせる`，✗ ならせる。その気になる → その気に**させる**。

## 口語縮約：せる → す

五段動詞的使役常縮成 `あ段 ＋ す`，看到要想到使役：

| 正式 | 口語 |
| --- | --- |
| 待た**せる** | 待た**す** |
| ちらつか**せる** | ちらつか**す** |
| 泣か**せる** | 泣か**す** |

## 強制・許可

**JLPT 軌道**
部長は新人に毎朝会議の資料を準備**させて**いるが、本人はあまり納得していないようだ。
両親は私がやりたいと言ったことは、たいてい最後まで自由にやら**せて**くれた。

**日常軌道**
弟に部屋の掃除やら**せた**ら、逆に散らかっててマジで意味なかった。
ちょっとだけでいいから、そのゲーム俺にもやら**せて**よ。

## 誘發

**JLPT 軌道**
連絡もせずに夜遅くまで帰らなかったので、母をずいぶん心配**させて**しまった。
彼のスピーチは会場の全員を笑わ**せた**だけでなく、最後には何人かを泣か**せた**。

**日常軌道**
ごめん、また待た**せ**ちゃったね。電車が急に止まっちゃってさ。
そうやって期待持た**せる**ようなこと言うの、ほんとやめてくれない？
