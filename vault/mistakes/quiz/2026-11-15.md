# 測驗詳解 2026-11-15

## 第2題｜日→中拆解｜格助詞〔N3〕

**題目**：{先月|せんげつ}、{姉|あね}が{京都|きょうと}の{古|ふる}い{旅館|りょかん}で{撮|と}った{写真|しゃしん}を、{祖母|そぼ}に{手紙|てがみ}と{一緒|いっしょ}に{送|おく}った。

| 項目 | 我的答案 | 正解 | 說明 |
| --- | --- | --- | --- |
| 句末動詞 | 送る | **{送\|おく}った** | 方向對，句末是過去形 |
| 格助詞角色 | 不知道格助詞是什麼 | 姉**が**＝主（只管 {撮\|と}った）・旅館**で**＝場・写真**を**＝受・祖母**に**＝對・手紙**と**＝伴 | 格助詞＝標出名詞在句中扮演什麼角色的助詞 |
| 修飾子句 | 前面整段到 を | **[姉が京都の古い旅館で撮った] → 写真** | 先月 在子句外；を 是整塊名詞「…撮った写真」的受語標記，不在子句內 |
| 翻譯 | 姊姊把…照片和信一起寄給奶奶 | （我）上個月把姊姊在京都老旅館拍的照片，和信一起寄給了奶奶 | 寄的人不是姊姊 |

- **判斷線索**：姉が 後面先碰到的述語是 {撮|と}った，が 只管它；{撮|と}った 緊接名詞 {写真|しゃしん}，所以「姉が…撮った」整段是修飾 写真 的子句。主句 {送|おく}った 的主語被省略，預設是說話者。
- **先月 掛哪裡**：先月 後面有逗號，傾向跳過子句、掛到主句 {送|おく}った（上個月寄的）；寫成「先月姉が撮った写真」（無逗號）則傾向「上個月拍的照片」。這是傾向不是鐵律，文脈優先。
- **記憶點**：修飾子句裡的 が 只管子句自己的動詞，不會變成整句的主語。見 [句子解析](../../basics/parsing/sentence-parsing.md)・[助詞拆句課程 › 第2堂](../../basics/parsing/particle-course.md)

## 第4題｜中→日翻譯｜修飾子句・他動詞〔N3〕

**題目**：我昨天被部長罵了，因為我把他上週給我的資料弄丟了。

**我的答案**：{先週|せんしゅう}{部長|ぶちょう}からもらったの{資料|しりょう}がなくしていたから、{昨日|きのう}{部長|ぶちょう}に{怒|おこ}られました

**正解**：{先週|せんしゅう}{部長|ぶちょう}からもらった{資料|しりょう}を**なくしてしまった**から、{昨日|きのう}{部長|ぶちょう}に{怒|おこ}られました。

| 我寫的 ✗ | 正確 ✓ | 為什麼 |
| --- | --- | --- |
| もらったの資料 | もらった資料 | 動詞直接修飾名詞，不加 の；只有 名詞＋の＋名詞 才要 の（再犯 2026-11-14） |
| 資料がなくして | 資料**を**なくして | なくす 是他動詞，受詞用 を；用 が 要換自動詞 {資料\|しりょう}がなくなって（再犯自他動詞） |
| なくしていた | なくしてしまった／なくした | ていた＝當時處在弄丟的狀態；懊惱「搞砸了」用 てしまった 最自然 |

- **做對的**：{部長|ぶちょう}に{怒|おこ}られました（受身 に＋一段接 た，2026-11-13 的錯已修正）・部長からもらった（に 也可）・理由在前結果在後。
- **自我檢查兩問**：① 動詞後直接接名詞，有沒有多塞 の？② 這個動詞是他動詞嗎？是的話前面要 を。
- **記憶點**：見 [名詞化の](../../basics/grammar/no-nominalization.md)・[自他動詞](../../basics/grammar/jidoushi-tadoushi.md)・[錯題整理](../my-pitfalls.md)

## 第5題｜日→中拆解｜接続助詞 のに〔N3〕

**題目**：{友達|ともだち}に{紹介|しょうかい}してもらったレストランは、{値段|ねだん}が{安|やす}いのに、{料理|りょうり}がとてもおいしかった。

| 項目 | 我的答案 | 正解 |
| --- | --- | --- |
| 切段 | 沒明確切開 | 在 のに 切兩段：〔値段が安い〕／〔料理がおいしかった〕，話題 レストランは 管兩段 |
| 配對 | 値段が→安い・料理が→おいしい ✓ | 同左 |
| 修飾子句 | 餐廳←給我←介紹←朋友 ✓ | [友達に紹介してもらった] → レストラン |
| に 的角色 | （箭頭隱含正確） | てもらう 的「幫我做動作的人」＝朋友 |
| 翻譯 | 不僅便宜，又非常好吃 ✗ | 朋友介紹給我的餐廳，價格明明很便宜，菜卻非常好吃 |

- **判斷線索**：のに＝逆接「明明～卻～」，後句和預期相反（便宜的店通常不好吃 → 卻很好吃，帶意外）。
- **對照**：反預期 → のに・ものの・けど；追加「不僅～還～」→ うえに・し・ばかりか。
- **記憶點**：看到 のに・ものの 先在旁邊寫「但」。見 [接続助詞](../../basics/particles/conjunctive-particles.md)・[錯題整理](../my-pitfalls.md)
