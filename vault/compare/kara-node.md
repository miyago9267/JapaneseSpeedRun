# から vs ので

兩個都是「因為～所以～」，N5/N4 就會學到，但**主觀 vs 客觀、後句能接什麼、禮貌度**不同，混用會讓句子怪或失禮。延伸：[理由・程度（ものだから・ほどだ）](reason-degree.md)・[常用助詞](../basics/particles.md)（`から` 的「起點」用法）。

**一句話：** `から` ＝ 我的理由（主觀・直接，後句想怎麼說都行）；`ので` ＝ 事情的因果（客觀・委婉，後句不強加於人）。

## 差別一覽

| | `から` | `ので` |
| --- | --- | --- |
| 語感 | 說話者**主觀**的理由・判斷，語氣直接 | **客觀**的因果關係，語氣柔和、有交代原委的感覺 |
| 後句能接 | 命令・請求・意志・勸誘・推測，都 OK | 陳述・請求（`てください`）・勸誘（`ましょう`）都可以，語氣較軟；**直接命令・禁止**（`～なさい`・`～するな`）較不自然 |
| 禮貌度 | 普通；多用在熟人之間 | 較禮貌・委婉；工作・道歉・請假的場合首選 |
| 前句接續 | 普通形／丁寧形都可（`高いですから`） | 普通形為主（`高いので`；正式 `高いですので`） |
| 名詞・な形 | 名詞／な形 ＋ **だ** ＋ から（雨**だ**から） | 名詞／な形 ＋ **な** ＋ ので（雨**な**ので） |
| 口語 | `から`（可以單獨放句尾：危ないから！） | `んで`（雨なんで・時間ないんで） |
| 句尾回答 | ✓ 〜**からです**（遅れたのは電車が止まったからです） | ✗ 〜のでです |

> [!WARNING]
>
> 1. **後句是直接命令 → 用 `から` 較自然**：寒いから、早く入りなさい（✓）／寒いので、早く入りなさい（△ 不自然）。
> 2. **回答「為什麼？」的句尾，用 `からです`**：✓電車が止まったからです／✗止まったのでです。（要用 `ので` 就得把答案放前面再接後句。）
> 3. 名詞・な形容詞前接 `ので` 要加 `な`：✓学生なので／✗学生だので。`から` 則是 だ：学生だから。

## JLPT track

考試和正式場合的寫法：**交代原因用 `ので`，表達自己的判斷或要對方行動用 `から`。**

| 場景 | 例（長句） | 重點 |
| --- | --- | --- |
| 客觀事實 | 台風が接近しているので、明日の遠足は中止になりました。 | 事實導致結果，用 `ので` |
| 正式請求・道歉 | 申し訳ございませんが、体調が優れませんので、本日は早退させていただきます。 | `ので` ＋ 敬語，委婉 |
| 說明遲到 | 事故で電車が遅れたので、会議に間に合いませんでした。 | 客觀因果 |
| 命令・勸告 | 明日は朝が早いから、今夜は早く寝なさい。 | 後句是命令 → `から` |
| 自己的推測・意志 | 彼はもう来ないだろうから、先に始めましょう。 | 推測＋勸誘 → `から` |
| 回答原因 | 遅れたのは、電車が止まったからです。 | 句尾 `からです` |

> 考題常見的陷阱：後句出現 `～なさい`・`～ろ` 這類直接命令時，選 `から` 而非 `ので`；問「為什麼」的回答句尾，選 `からです`。

## 日常 track

口語裡兩個都常用，差別在**語氣**：`から` 直接、帶「所以你要…」的意味；`ので`（口語 `んで`）比較客氣、像在交代原因。

| 場景 | 例（口語長句） | 語感 |
| --- | --- | --- |
| 提醒朋友 | 今日、雨降ってるから、傘持ってったほうがいいよ。 | `から` 直接、親近 |
| 拒絕邀約 | ごめん、今日はバイトあるんで、先に帰るね。 | `んで` 客氣、有交代 |
| 催促 | 時間ないから、急いで！ | `から` 帶命令 |
| 對前輩 | もう遅いんで、そろそろ帰りますね。 | `んで` 避免強加 |
| 說明理由 | 今日は友達と飲みに行く約束があるから、ご飯は要らないよ。 | 自己的狀況，用 `から` |
| 單獨放句尾 | いいから、早く来て！ | `〜から` 當作「別囉嗦」的口氣 |

> `んで` ＝ `ので` 的口語縮約（の → ん）。對熟人也能說，但寫文章要寫 `ので`。

## 快速判斷

1. 後面是**直接命令**（～なさい・～ろ）或強烈的個人判斷 → `から`
2. 想**委婉交代原因**（請假・道歉・拒絕・對上位者）→ `ので`
3. 句尾直接回答「為什麼」→ `からです`
4. 兩個都通、只差語氣時 → 熟人用 `から`、對外用 `ので`
