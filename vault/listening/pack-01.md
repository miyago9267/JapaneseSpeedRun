# 聽力練習 pack-01

10 題（即時応答 7・課題理解 2・ポイント理解 1）。重點：口語縮約（ちゃう・とく・なきゃ）・敬語回應・否定與條件・數字時間。

戴耳機，每題只聽一次（真的聽不清楚才重播），先選答案再展開「答案與原文」。錯的題號回報給 Claude，例如「聽力 pack-01 錯 3、7」。用法見[聽力練習總覽](index.md)。

**答案**：2

**原文**

- 題幹：ごめん、ちょっと{電話|でんわ}かかってきちゃった。
- 選項 1：えっ、{誰|だれ}に{電話|でんわ}したの？
- 選項 2：いいよ。ここで{待|ま}ってるね。 ✓
- 選項 3：じゃあ、{私|わたし}が{電話|でんわ}しとくね。

**全假名**

- 題幹：ごめん、ちょっとでんわかかってきちゃった。
- 選項 1：えっ、だれにでんわしたの？
- 選項 2：いいよ。ここでまってるね。 ✓
- 選項 3：じゃあ、わたしがでんわしとくね。

**中文**

- 題幹：抱歉，剛好有電話打進來了。
- 選項 1：咦，你打給誰了？
- 選項 2：沒關係，我在這裡等你。 ✓
- 選項 3：那我先幫你打電話吧。

**重點**：`〜てしまう → ちゃう`：かかってきちゃった ＝ 電話打進來了（有點無奈）。選項 1 把 かかってくる（接到）聽成 かける（打出去）；選項 3 的 しとく 是 しておく 的縮約，意思是「先做好」，跟情境不搭。→ [て形複合](../basics/grammar/te-compound.md)

</details>

**全假名**

- 題幹：あしたのかいぎ、しりょうはよういしといたほうがいいですか。
- 選項 1：ありがとうございます。よういしてくださってたすかりました。
- 選項 2：はい、かいぎはさんがいのかいぎしつです。
- 選項 3：ええ、よういしておいていただけるとたすかります。 ✓

**中文**

- 選項 2：是的，會議在三樓的會議室。
- 選項 3：是的，如果您能先準備好就幫了大忙了。 ✓

- 選項 2：ええ、{飲|の}んだのに{治|なお}りませんでした。
- 選項 3：ええ、{食後|しょくご}に{必|かなら}ず{飲|の}んでください。 ✓

**全假名**

- 題幹：このくすり、のまないとなおらないんでしょうか。
- 選項 1：いいえ、もうなおりました。
- 選項 2：ええ、のんだのになおりませんでした。

**中文**

- 題幹：這個藥，不吃的話就好不了嗎？
- 選項 1：不，已經好了。

- 選項 3：是的，請務必在飯後服用。 ✓

**全假名**

- 題幹：かさ、もってきてよかったね。きゅうにふってきたよ。

## 第8題　課題理解〔N2〕　JLPT track

<audio controls preload="none"><source src="./audio/pack-01/q08.mp3" type="audio/mpeg"></audio>

**情境**：公司裡，女同事跟男同事討論下週的出差安排。

**提問**：男的接下來要先做什麼？

1. {新幹線|しんかんせん}を{予約|よやく}する
2. ホテルに{電話|でんわ}する
3. {予約|よやく}サイトでホテルを{探|さが}す
4. {駅|えき}の{近|ちか}くのホテルへ{行|い}く

<details>
<summary>答案與原文</summary>

**答案**：3

**原文**

- 開場：{会社|かいしゃ}で{女|おんな}の{人|ひと}と{男|おとこ}の{人|ひと}が{話|はな}しています。{男|おとこ}の{人|ひと}はこのあと、まず{何|なに}をしますか。
- A：{田中|たなか}さん、{来週|らいしゅう}の{出張|しゅっちょう}のことなんですが、{新幹線|しんかんせん}はもう{予約|よやく}しましたか。
- B：いえ、まだです。{先|さき}にホテルを{押|お}さえなきゃと{思|おも}って、さっき{電話|でんわ}してみたんですが、{満室|まんしつ}でした。
- A：そうですか。それなら、{駅|えき}の{近|ちか}くじゃなくてもいいので、{探|さが}してみてください。
- B：わかりました。{予約|よやく}サイトで{探|さが}してみます。
- A：{新幹線|しんかんせん}の{方|ほう}は{私|わたし}が{取|と}っておきますから。
- 提問：{男|おとこ}の{人|ひと}はこのあと、まず{何|なに}をしますか。
- 選項 1：{新幹線|しんかんせん}を{予約|よやく}する
- 選項 2：ホテルに{電話|でんわ}する
- 選項 3：{予約|よやく}サイトでホテルを{探|さが}す ✓
- 選項 4：{駅|えき}の{近|ちか}くのホテルへ{行|い}く

**全假名**

- 開場：かいしゃでおんなのひととおとこのひとがはなしています。おとこのひとはこのあと、まずなにをしますか。
- A：たなかさん、らいしゅうのしゅっちょうのことなんですが、しんかんせんはもうよやくしましたか。
- B：いえ、まだです。さきにホテルをおさえなきゃとおもって、さっきでんわしてみたんですが、まんしつでした。
- A：そうですか。それなら、えきのちかくじゃなくてもいいので、さがしてみてください。
- B：わかりました。よやくサイトでさがしてみます。
- A：しんかんせんのほうはわたしがとっておきますから。
- 提問：おとこのひとはこのあと、まずなにをしますか。
- 選項 1：しんかんせんをよやくする
- 選項 2：ホテルにでんわする
- 選項 3：よやくサイトでホテルをさがす ✓
- 選項 4：えきのちかくのホテルへいく

**中文**

- 開場：公司裡女的和男的在說話。男的接下來要先做什麼？
- A：田中先生，關於下週出差的事，新幹線已經訂了嗎？
- B：還沒。我想說得先訂好飯店，剛剛打電話問了，已經客滿了。
- A：這樣啊。那不在車站附近也沒關係，請找找看。
- B：好的，我在訂房網站上找找看。
- A：新幹線的部分我來訂。
- 提問：男的接下來要先做什麼？
- 選項 1：訂新幹線
- 選項 2：打電話給飯店
- 選項 3：在訂房網站找飯店 ✓
- 選項 4：去車站附近的飯店

**重點**：電話已經打過了（`電話してみたんですが満室でした`），新幹線由對方訂（`取っておきます`），所以剩下的是上網找。`押さえなきゃ`（＝ 押さえなければ）是口語縮約。→ [動詞變化型 › ない形](../basics/grammar/verb-conjugation.md)

</details>

**提問**：男的為什麼沒去昨天的聚餐？

1. {部長|ぶちょう}に{行|い}かなくてもいいと{言|い}われたから
2. {部長|ぶちょう}に{頼|たの}まれた{仕事|しごと}をしていたから
3. {資料|しりょう}を{作|つく}るのを{忘|わす}れていたから
4. {断|ことわ}るのが{面倒|めんどう}だったから

<details>
<summary>答案與原文</summary>

**答案**：2

**原文**

- 開場：{会社|かいしゃ}で{女|おんな}の{人|ひと}と{男|おとこ}の{人|ひと}が{話|はな}しています。{男|おとこ}の{人|ひと}は、どうして{昨日|きのう}の{飲|の}み{会|かい}に{行|い}けませんでしたか。
- A：{昨日|きのう}の{飲|の}み{会|かい}、どうして{来|こ}なかったの？みんな{待|ま}ってたんだよ。
- B：ごめん。{行|い}こうと{思|おも}ってたんだけど、{部長|ぶちょう}に{急|きゅう}に{資料|しりょう}を{頼|たの}まれちゃってさ。
- A：{断|ことわ}ればよかったのに。
- B：{断|ことわ}れないよ。{朝|あさ}までに{必要|ひつよう}だって{言|い}われたんだから。{結局|けっきょく}、{終|お}わったの、{十一時|じゅういちじ}{過|す}ぎだったよ。
- A：そっか。{大変|たいへん}だったね。
- 提問：{男|おとこ}の{人|ひと}は、どうして{昨日|きのう}の{飲|の}み{会|かい}に{行|い}けませんでしたか。
- 選項 1：{部長|ぶちょう}に{行|い}かなくてもいいと{言|い}われたから
- 選項 2：{部長|ぶちょう}に{頼|たの}まれた{仕事|しごと}をしていたから ✓
- 選項 3：{資料|しりょう}を{作|つく}るのを{忘|わす}れていたから
- 選項 4：{断|ことわ}るのが{面倒|めんどう}だったから

**全假名**

- 開場：かいしゃでおんなのひととおとこのひとがはなしています。おとこのひとは、どうしてきのうののみかいにいけませんでしたか。
- A：きのうののみかい、どうしてこなかったの？みんなまってたんだよ。
- B：ごめん。いこうとおもってたんだけど、ぶちょうにきゅうにしりょうをたのまれちゃってさ。
- A：ことわればよかったのに。
- B：ことわれないよ。あさまでにひつようだっていわれたんだから。けっきょく、おわったの、じゅういちじすぎだったよ。
- A：そっか。たいへんだったね。
- 提問：おとこのひとは、どうしてきのうののみかいにいけませんでしたか。
- 選項 1：ぶちょうにいかなくてもいいといわれたから
- 選項 2：ぶちょうにたのまれたしごとをしていたから ✓
- 選項 3：しりょうをつくるのをわすれていたから
- 選項 4：ことわるのがめんどうだったから

**中文**

- 開場：公司裡女的和男的在說話。男的為什麼沒能去昨天的聚餐？
- A：昨天的聚餐你怎麼沒來？大家都在等你耶。
- B：抱歉。我本來打算去的，但部長臨時要我做資料。
- A：拒絕就好了啊。
- B：怎麼可能拒絕，人家說早上之前就要。結果做完已經過十一點了。
- A：這樣啊，辛苦你了。
- 提問：男的為什麼沒能去昨天的聚餐？
- 選項 1：因為部長說不用去
- 選項 2：因為在做部長拜託的工作 ✓
- 選項 3：因為忘了做資料
- 選項 4：因為嫌拒絕很麻煩

**重點**：`頼まれちゃって` ＝ 頼まれてしまって（被拜託了，無奈）；`〜んだから` 是強調理由。選項 4 是反向陷阱：他是「断れない」不是「面倒」。→ [て形複合 › てしまう](../basics/grammar/te-compound.md)
