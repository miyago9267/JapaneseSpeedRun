# 聽力練習 pack-02

10 題（即時応答 7・課題理解 2・ポイント理解 1）。重點：授受・敬語（謙讓／尊敬）・條件（ば）・わけがない・しか＋否定・數字。

戴耳機，每題只聽一次（真的聽不清楚才重播），先選答案再展開「答案與原文」。錯的題號回報給 Claude，例如「聽力 pack-02 錯 3、7」。用法見[聽力練習總覽](index.md)。

## 第8題　課題理解〔N2〕　JLPT track

**情境**：大學研究室，女學生把下週發表用的資料拿給老師看。

**提問**：女學生接下來要先做什麼？

1. {発表|はっぴょう}の{内容|ないよう}を{変|か}える
2. {図|ず}を{大|おお}きくする
3. まとめの{文字|もじ}を{減|へ}らす
4. {資料|しりょう}を{先生|せんせい}に{送|おく}る

<details>
<summary>答案與原文</summary>

**答案**：2

**原文**

- 開場：{大学|だいがく}の{研究室|けんきゅうしつ}で{女|おんな}の{学生|がくせい}と{男|おとこ}の{先生|せんせい}が{話|はな}しています。{女|おんな}の{学生|がくせい}はこのあと、まず{何|なに}をしますか。
- A：{先生|せんせい}、{来週|らいしゅう}の{発表|はっぴょう}の{資料|しりょう}ができましたので、ご{覧|らん}いただけますか。
- B：ああ、{見|み}てみよう。……うん、{内容|ないよう}はいいけど、{図|ず}が{小|ちい}さくて、{後|うし}ろの{人|ひと}には{見|み}えないかもしれないね。
- A：あ、そうですね。{大|おお}きくします。
- B：それと、{最後|さいご}のまとめのスライドは{文字|もじ}が{多|おお}すぎるから、{三|みっ}つぐらいにまとめたらどう？
- A：わかりました。{図|ず}はこのあとすぐ{直|なお}して、まとめは{明日|あした}までに{直|なお}します。
- B：うん、{直|なお}ったらメールで{送|おく}ってね。
- 提問：{女|おんな}の{学生|がくせい}はこのあと、まず{何|なに}をしますか。
- 選項 1：{発表|はっぴょう}の{内容|ないよう}を{変|か}える
- 選項 2：{図|ず}を{大|おお}きくする ✓
- 選項 3：まとめの{文字|もじ}を{減|へ}らす
- 選項 4：{資料|しりょう}を{先生|せんせい}に{送|おく}る

**全假名**

- 開場：だいがくのけんきゅうしつでおんなのがくせいとおとこのせんせいがはなしています。おんなのがくせいはこのあと、まずなにをしますか。
- A：せんせい、らいしゅうのはっぴょうのしりょうができましたので、ごらんいただけますか。
- B：ああ、みてみよう。……うん、ないようはいいけど、ずがちいさくて、うしろのひとにはみえないかもしれないね。
- A：あ、そうですね。おおきくします。
- B：それと、さいごのまとめのスライドはもじがおおすぎるから、みっつぐらいにまとめたらどう？
- A：わかりました。ずはこのあとすぐなおして、まとめはあしたまでになおします。
- B：うん、なおったらメールでおくってね。
- 提問：おんなのがくせいはこのあと、まずなにをしますか。
- 選項 1：はっぴょうのないようをかえる
- 選項 2：ずをおおきくする ✓
- 選項 3：まとめのもじをへらす
- 選項 4：しりょうをせんせいにおくる

**中文**

- 開場：大學研究室裡女學生和男老師在說話。女學生接下來要先做什麼？
- A：老師，下週發表的資料做好了，可以請您過目嗎？
- B：啊，我看看。……嗯，內容不錯，不過圖太小，後面的人可能看不見。
- A：啊，說得也是，我把它放大。
- B：還有，最後總結的投影片字太多了，整理成三點左右如何？
- A：我知道了。圖我等一下馬上改，總結明天以前改好。
- B：嗯，改好了就用 email 寄給我。
- 提問：女學生接下來要先做什麼？
- 選項 1：更改發表內容
- 選項 2：把圖放大 ✓
- 選項 3：減少總結的文字
- 選項 4：把資料寄給老師

**重點**：`ご覧いただけますか` ＝ 請您過目（敬語）。順序題抓「時間詞」：圖 ＝ `このあとすぐ`，總結 ＝ `明日までに`，寄信 ＝ 改好之後。內容沒有被要求改。→ [授受動詞 › 敬語形](../basics/grammar/juju-doushi.md)

</details>

- 選項 2：かんりにんさんにおこられたから
- 選項 3：よるおそくまでともだちとあそんでいたから
- 選項 4：となりのへやのおとでねむれなかったから ✓

**中文**

- 開場：男的和女的在說話。男的為什麼沒精神？
- A：怎麼了？你好沒精神。
- B：昨天隔壁房間很吵，完全睡不著。
- A：才剛搬家就這樣，真辛苦。有跟管理員說嗎？

- 選項 3：因為跟朋友玩到很晚
- 選項 4：因為隔壁房間的噪音睡不著 ✓
