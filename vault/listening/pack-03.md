# 聽力練習 pack-03

10 題（即時応答 7・課題理解 2・ポイント理解 1）。重點：じゃん・たばかり・おかげで／せいで・わけにはいかない・敬語（店員與客人）・金額與日期。

戴耳機，每題只聽一次（真的聽不清楚才重播），先選答案再展開「答案與原文」。錯的題號回報給 Claude，例如「聽力 pack-03 錯 3、7」。用法見[聽力練習總覽](index.md)。

- 選項 2：{田中|たなか}{様|さま}ですね。ただいま{呼|よ}んでまいりますので、{少々|しょうしょう}お{待|ま}ちください。 ✓

- 選項 2：たなかさまですね。ただいまよんでまいりますので、しょうしょうおまちください。 ✓

**中文**

- 題幹：不好意思，我是前幾天收到您聯絡的田中。負責的人在嗎？

- 選項 3：我就是田中，請問您是哪位？

1. {今週|こんしゅう}の{金曜日|きんようび}まで、{九千円|きゅうせんえん}
2. {来週|らいしゅう}の{金曜日|きんようび}まで、{一万二千円|いちまんにせんえん}

<details>
<summary>答案與原文</summary>

**答案**：3

**原文**

- 開場：{大学|だいがく}で{女|おんな}の{学生|がくせい}と{男|おとこ}の{学生|がくせい}が{話|はな}しています。{女|おんな}の{学生|がくせい}は、いつまでにいくら{払|はら}いますか。
- A：{先輩|せんぱい}、ゼミ{合宿|がっしゅく}の{参加費|さんかひ}は、いつまでに{払|はら}えばいいですか。
- B：{来週|らいしゅう}の{金曜日|きんようび}までに、{幹事|かんじ}の{山本|やまもと}さんに{渡|わた}してくれればいいよ。{全部|ぜんぶ}で{一万二千円|いちまんにせんえん}だけど、{先月|せんげつ}{払|はら}った{予約金|よやくきん}の{三千円|さんぜんえん}は{引|ひ}いてあるから、{九千円|きゅうせんえん}でいいはず。
- A：{九千円|きゅうせんえん}ですね。{振|ふ}り{込|こ}みじゃなくて、{現金|げんきん}でいいんですか。
- B：うん、{現金|げんきん}で。おつりが{出|で}ないように{用意|ようい}しておいてね。
- 提問：{女|おんな}の{学生|がくせい}は、いつまでにいくら{払|はら}いますか。
- 選項 1：{今週|こんしゅう}の{金曜日|きんようび}まで、{九千円|きゅうせんえん}
- 選項 2：{来週|らいしゅう}の{金曜日|きんようび}まで、{一万二千円|いちまんにせんえん}
- 選項 3：{来週|らいしゅう}の{金曜日|きんようび}まで、{九千円|きゅうせんえん} ✓
- 選項 4：{来週|らいしゅう}の{金曜日|きんようび}まで、{三千円|さんぜんえん}

**全假名**

- 開場：だいがくでおんなのがくせいとおとこのがくせいがはなしています。おんなのがくせいは、いつまでにいくらはらいますか。
- A：せんぱい、ゼミがっしゅくのさんかひは、いつまでにはらえばいいですか。
- B：らいしゅうのきんようびまでに、かんじのやまもとさんにわたしてくれればいいよ。ぜんぶでいちまんにせんえんだけど、せんげつはらったよやくきんのさんぜんえんはひいてあるから、きゅうせんえんでいいはず。
- A：きゅうせんえんですね。ふりこみじゃなくて、げんきんでいいんですか。
- B：うん、げんきんで。おつりがでないようによういしておいてね。
- 提問：おんなのがくせいは、いつまでにいくらはらいますか。
- 選項 1：こんしゅうのきんようびまで、きゅうせんえん
- 選項 2：らいしゅうのきんようびまで、いちまんにせんえん
- 選項 3：らいしゅうのきんようびまで、きゅうせんえん ✓
- 選項 4：らいしゅうのきんようびまで、さんぜんえん

**中文**

- 開場：大學裡女學生和男學生在說話。女學生要在什麼時候之前、付多少錢？
- A：學長，研究班集訓的參加費，要在什麼時候之前付才好？
- B：下週五之前交給負責的山本同學就行。全部是一萬二千圓，不過上個月付的訂金三千圓已經扣掉了，所以應該付九千圓就好。
- A：九千圓對吧。不是匯款，用現金可以嗎？
- B：嗯，付現金。記得準備好剛好的金額，免得要找零。
- 提問：女學生要在什麼時候之前、付多少錢？
- 選項 1：本週五前，九千圓
- 選項 2：下週五前，一萬二千圓
- 選項 3：下週五前，九千圓 ✓
- 選項 4：下週五前，三千圓

**重點**：把「期限」和「金額」分開算：一萬二千 − 已付訂金三千 ＝ 九千；期限 ＝ 下週五。`〜てくれればいい` ＝ …就可以了；`用意しておいてね` ＝ 先準備好。→ [て形複合 › ておく](../basics/grammar/te-compound.md)

</details>

**提問**：女的對這家義大利餐廳的評價是什麼？

1. {値段|ねだん}が{高|たか}くて、{味|あじ}もよくない
2. {値段|ねだん}は{安|やす}いが、{昼|ひる}は{待|ま}ち{時間|じかん}が{長|なが}い
3. {十一時|じゅういちじ}から{三十分|さんじゅっぷん}{待|ま}たなければならない
4. いつでも{待|ま}たずに{入|はい}れる

<details>
<summary>答案與原文</summary>

**答案**：2

**原文**

- 開場：{男|おとこ}の{人|ひと}と{女|おんな}の{人|ひと}が{話|はな}しています。{女|おんな}の{人|ひと}は、{駅前|えきまえ}のイタリアンについて、どう{言|い}っていますか。
- B：{駅前|えきまえ}の{新|あたら}しいイタリアン、{行|い}ってみた？{高|たか}かった？

- B：へえ、じゃあ{今度|こんど}は{早|はや}めに{行|い}ってみようかな。
- A：うん、{十一時|じゅういちじ}に{開|あ}くから、その{頃|ころ}に{行|い}けば{待|ま}たずに{入|はい}れると{思|おも}うよ。
- 提問：{女|おんな}の{人|ひと}は、{駅前|えきまえ}のイタリアンについて、どう{言|い}っていますか。
- 選項 1：{値段|ねだん}が{高|たか}くて、{味|あじ}もよくない
- 選項 2：{値段|ねだん}は{安|やす}いが、{昼|ひる}は{待|ま}ち{時間|じかん}が{長|なが}い ✓
- 選項 3：{十一時|じゅういちじ}から{三十分|さんじゅっぷん}{待|ま}たなければならない
- 選項 4：いつでも{待|ま}たずに{入|はい}れる

**全假名**

- 開場：おとこのひととおんなのひとがはなしています。おんなのひとは、えきまえのイタリアンについて、どういっていますか。
- B：えきまえのあたらしいイタリアン、いってみた？たかかった？
- A：ううん、ランチはせんえんぐらいでね、やすいのにあじもわるくなかったよ。ただ、おひるどきはならぶから、さんじゅっぷんぐらいまたされた。
- B：へえ、じゃあこんどははやめにいってみようかな。
- A：うん、じゅういちじにあくから、そのころにいけばまたずにはいれるとおもうよ。
- 提問：おんなのひとは、えきまえのイタリアンについて、どういっていますか。
- 選項 1：ねだんがたかくて、あじもよくない
- 選項 2：ねだんはやすいが、ひるはまちじかんがながい ✓
- 選項 3：じゅういちじからさんじゅっぷんまたなければならない
- 選項 4：いつでもまたずにはいれる

**中文**

- 開場：男的和女的在說話。女的對車站前的義大利餐廳是怎麼說的？
- B：車站前新開的義大利餐廳，你去過了嗎？貴嗎？
- A：不會，午餐大概一千圓，便宜味道也不差。只是中午時段要排隊，我被迫等了三十分鐘左右。
- B：咦，那我下次提早去看看好了。
- A：嗯，十一點開門，那時候去的話應該不用等就能進去。
- 提問：女的對車站前的義大利餐廳是怎麼說的？
- 選項 1：價格貴，味道也不好
- 選項 2：價格便宜，但中午等候時間長 ✓
- 選項 3：從十一點起一定要等三十分鐘
- 選項 4：隨時都不用等就能進去

**重點**：`安いのに〜` ＝ 明明便宜卻…（逆接，這裡是「便宜而且味道不差」）；`待たされた` ＝ 被迫等了（使役受身）；`〜ずに` ＝ 不…地。重點是：價格便宜，但午餐時段要排隊。→ [使役形用法](../basics/grammar/causative.md)

</details>

**中文**

- 開場：家裡男的和女的在說話。男的接下來要先做什麼？
- A：欸，搬家的東西，已經全部裝箱了嗎？
- B：書和餐具裝好了，衣服還沒。
- A：衣服今晚再弄，那大型垃圾怎麼辦？床不能帶走吧。
- B：啊，對喔。得打電話給市公所。不過今天已經關門了吧。
- A：網路上應該也能申請喔，我剛剛看過了。
- B：那我晚餐前上網查查看。
- 提問：男的接下來要先做什麼？
- 選項 1：把衣服裝箱
- 選項 2：打電話給市公所
- 選項 3：搬床
- 選項 4：上網查大型垃圾的申請方式 ✓

**重點**：順序題抓時間詞：衣服 ＝ `今夜`、上網查 ＝ `夕飯の前`，所以先查。`電話しなきゃ`（＝ しなければ）被「今日はもう閉まってる」否定掉；`〜はずだ` ＝ 應該可以。→ [動詞變化型 › ない形](../basics/grammar/verb-conjugation.md)
