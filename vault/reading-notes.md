# 讀解筆記：原文逐句拆解

讀原文時卡住的句子，一句一拆：原文 → 翻譯 → 結構 → 片段表。有專課的文法直接連過去。延伸：[句子解析](sentence-parsing.md)、[理由・程度表現](reason-degree.md)。

**用法：** 先遮住翻譯自己讀一次，卡在哪個片段就看那一列。新文法點集中在最後的速查。

## 青梅竹馬篇

### 01

```
幼稚園の頃から毎日一緒なもんだから、お互いに知らないところが見つけられないほどだ。
```

- 翻譯：「因為從幼稚園起就天天在一起，熟到彼此幾乎找不出對方不知道的地方。」
- 文法：`ものだから`・`ほどだ` → 完整拆解在 [理由・程度表現](reason-degree.md)

### 02

```
しいて挙げるとするなら恋愛事情は聞いたことがないかもな。
```

- 翻譯：「硬要舉一個的話，大概就是沒聽對方聊過感情的事吧。」
- 結構：`[しいて挙げるとするなら]`（假設）＋ `恋愛事情は`（對比話題）＋ `[聞いたことがない] かもな`（推測）

| 片段 | 規則 | 說明 |
| --- | --- | --- |
| 強（し）いて | 副詞 | 硬要、勉強。通常寫假名 しいて |
| 挙（あ）げる | 他動詞 | 舉出（例子） |
| **とするなら** | `普通形 ＋ とするなら` | 假如要～的話。同 `とすれば`・`としたら` |
| 恋愛事情（れんあいじじょう） | 名詞 | 感情狀況、戀愛方面的事 |
| **は** | 對比の は | 別的都知道，**唯獨這個** |
| 聞（き）いた**ことがない** | `た形 ＋ ことがない` | 從來沒～過 |
| **かもな** | `かもしれない → かもな` | 口語縮約，な 帶自言自語語氣 |

> [!WARNING]
> `しいて挙げるなら`／`しいて言えば` 是固定套話：「其實沒什麼，但硬要說的話…」，後面接勉強擠出來的例子。
> 這裡的 は 是把受語拉出來當對比話題：`恋愛事情を聞いた → 恋愛事情は聞いたことがない`。✗ 恋愛事情**が**聞いたことがない

### 03

```
中学に入ったあたりから少しだけ関係が変わって——というより、アイツの様子が変わった。
```

- 翻譯：「大概從上了國中起，關係就有點變了——與其說是關係，不如說是那傢伙的樣子變了。」
- 結構：`[中学に入ったあたりから]`（時間起點）＋ `関係が変わって——`（講到一半）＋ `というより`（改口）＋ `アイツの様子が変わった`

| 片段 | 規則 | 說明 |
| --- | --- | --- |
| 中学（ちゅうがく）に入（はい）った**あたりから** | `た形 ＋ あたりから` | 大概從～的時候起。あたり＝大約、前後 |
| 少（すこ）し**だけ** | `副詞 ＋ だけ` | 只有一點點 |
| 関係（かんけい）が変（か）わって—— | `て形` 中斷 | 句子沒說完，破折號是自己打斷改口 |
| **というより** | `A というより B` | 與其說 A，不如說 B。修正前面的說法 |
| アイツ | 代名詞 | あいつ（那傢伙），寫片假名帶強調 |
| 様子（ようす） | 名詞 | 樣子・態度・狀態 |

> [!WARNING]
> 様子 念 **ようす**，✗ ようこ。子 念 す 的固定讀法：様子（ようす）・扇子（せんす）・椅子（いす）。

### 04

```
今まで気にしてなかったくせして、会うたびやたらと準備に時間がかかるようになったり——
```

- 翻譯：「明明以前都不在意的，現在每次見面卻莫名花一大堆時間準備……」
- 結構：`[今まで気にしてなかった] くせして`（明明～）＋ `会うたび`（每次）＋ `やたらと`（修飾 時間がかかる）＋ `[準備に時間がかかる] ようになったり`（變化＋舉例）

| 片段 | 規則 | 說明 |
| --- | --- | --- |
| 気（き）にして**な**かった | `ていなかった → てなかった` | 口語省略 い：之前沒在意 |
| **くせして** | `普通形 ＋ くせに／くせして` | 明明～卻，帶不滿・吐槽。くせして 更口語 |
| 会（あ）う**たび** | `辞書形 ＋ たび（に）` | 每次見面，に 被省略 |
| **やたらと** | 副詞 | 過度地、莫名地很～（多到不太正常） |
| 準備（じゅんび）に時間（じかん）がかかる | `N に時間がかかる` | 花時間在～上 |
| かかる**ようになった** | `辞書形 ＋ ようになる` | 變得會～（以前不會） |
| なった**り**—— | `た形 ＋ り` 單用 | 舉例：「像是～之類的」，後面還有話 |

> [!WARNING]
> 斷句是 `会うたび／やたらと`，不是「たびやたら」。たび 後面的 に 在口語常省略。

### 05

```
些細なことで噛みついてきたり——
```

- 翻譯：「或是為了一點小事就衝著我來、跟我嗆……」
- 結構：`[些細なことで]`（原因）＋ `噛みついてきたり——`（承接 04 的 `～たり`，繼續列舉）

| 片段 | 規則 | 說明 |
| --- | --- | --- |
| 些細（ささい）な | な形 | 細微的、雞毛蒜皮的 |
| こと**で** | `名詞 ＋ で`（原因） | 因為～、為了～ |
| 噛（か）みつく | 自動詞 | 本義咬住，引申為頂嘴・嗆人・激烈反駁 |
| 噛みつい**てくる** | `て形 ＋ くる` | 動作朝說話者而來：衝著「我」來 |
| ～**たり**—— | `た形 ＋ り` | 和 04 的「かかるようになった**り**」成對 |

> [!WARNING]
> 04＋05 是被拆成兩行的 `～たり、～たり` 並列：「一下變得很會打扮，一下又為小事嗆我……」。單看一句像沒講完，其實是在列清單。
> `てくる` 這裡是方向不是「回來」：噛みついた（咬了）vs 噛みつい**てきた**（衝著我咬過來）。

### 06

```
昔はもっと笑って流してたくせに、変にムキになったり、焦ったり……。
```

- 翻譯：「明明以前都會笑笑帶過的，現在卻莫名其妙較起真來、一下又慌了手腳……」
- 結構：`昔は`（對比：以前）＋ `[もっと笑って流してた] くせに`（明明～）＋ `変にムキになったり、焦ったり`（`～たり` 列舉收尾）

| 片段 | 規則 | 說明 |
| --- | --- | --- |
| 昔（むかし）**は** | 對比の は | 以前是這樣，暗示現在不同 |
| もっと | 副詞 | 更（常常）～ |
| 笑（わら）って流（なが）す | `て形 ＋ 動詞` | 一笑置之、笑笑帶過。流す＝不放在心上 |
| 流して**た** | `ていた → てた` | 口語省略 い，過去的習慣 |
| **くせに** | `普通形 ＋ くせに` | 明明～卻。04 用 くせして，這裡用原形 |
| 変（へん）**に** | `な形 → に`（副詞化） | 莫名地、怪怪地 |
| ムキになる | 慣用 | 為小事較真・動氣。漢字 向きになる，通常寫片假名 |
| 焦（あせ）る | 自動詞 | 慌張、著急 |
| ～**たり**、～**たり**…… | `た形 ＋ り` 並列 | 列舉到這裡收尾 |

> [!WARNING]
> 04→05→06 是同一串 `～たり` 清單：打扮變久・為小事嗆我・較真・慌張——一條條數「那傢伙變了的地方」。
> 對比の は ＋ くせに 一起用，把「以前 vs 現在」的落差拉大。
> 日常用法：冗談なのに、なんでそんな**ムキになる**の？（只是開玩笑，幹嘛那麼認真？）

## 文法速查

| 文法 | 接續 | 意思 | 語感 |
| --- | --- | --- | --- |
| `とするなら` | `普通形 ＋ とするなら` | 假如～的話 | 假設前提，同 `とすれば`・`としたら` |
| `A というより B` | `普通形／名詞 ＋ というより` | 與其說 A 不如說 B | 修正說法 |
| `くせに／くせして` | `普通形 ＋ くせに`（な形 ＋ な、名詞 ＋ の） | 明明～卻 | 責備・不滿，通常說別人 |
| `たびに` | `辞書形／名詞の ＋ たび（に）` | 每次～ | 每次都發生同樣的事 |
| `ようになる` | `辞書形／ない形 ＋ ようになる` | 變得（會）～ | 習慣・能力的變化 |
| `～たり` 單用 | `た形 ＋ り` | 舉個例 | 句尾留白，暗示還有別的 |
| `てくる`（方向） | `て形 ＋ くる` | 動作朝我而來 | 對方的動作落到說話者身上 |
| `な形 → に` | `な形語幹 ＋ に` | 副詞化 | 変に・静かに・急に，修飾後面的動詞 |

> [!WARNING]
> `くせに` 前後主語要是同一人，而且帶責備，說自己的事改用 `のに`。
> ✗ 私は知っているくせに、言わなかった。→ ✓ 知っている**のに**、言わなかった。

## くせに

**JLPT 軌道**
彼は自分では何もしない**くせに**、他人の仕事にはいつも文句ばかり言っている。

**日常軌道**
自分から誘った**くせして**、当日になってドタキャンするとかありえないでしょ。

## たびに

**JLPT 軌道**
この写真を見る**たびに**、学生時代に友人たちと過ごした夏休みのことを思い出す。

**日常軌道**
実家に帰る**たび**、母さんに「ちゃんと食べてるの？」って聞かれるんだよね。

## ようになる

**JLPT 軌道**
毎日練習を続けた結果、半年後には辞書を使わずに新聞が読める**ようになった**。

**日常軌道**
最近、朝ごはんちゃんと食べる**ようになって**さ、なんか調子いいんだよね。

## というより

**JLPT 軌道**
彼の態度は冷たい**というより**、どう接していいか分からずに戸惑っているように見えた。

**日常軌道**
あれは喧嘩**というより**、ただのじゃれ合いだったよ。
