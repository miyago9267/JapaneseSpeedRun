# 初級 I（第1課〜第25課）

邊讀邊勾：`[x]` = 會用、`[ ]` = 還不熟。每點一句規則＋一句自編例句；細節去連結的專課看。回[總覽](index.md)。

> [!NOTE]
> 課次與文型依記憶整理，尚未對照課本目次；標 `⚠待對照` 的是我不確定落在哪一課。例句全是自編，不是課本原文。

## 第1課

- [ ] `N1 は N2 です` — 「A 是 B」，は 讀 wa ／ 私**は**学生（がくせい）**です**。→ [專課](../basics/particles.md)
- [ ] `N1 は N2 じゃ ありません` — 否定「不是」 ／ 兄（あに）は医者（いしゃ）**じゃ ありません**。→ [專課](../basics/noun-conjugation.md)
- [ ] `～ですか` — 句尾加 か 變疑問 ／ あの人（ひと）は先生（せんせい）**ですか**。
- [ ] `N も` — 「也是」，取代 は ／ 田中（たなか）さん**も**会社員（かいしゃいん）です。→ [專課](../basics/particles.md)
- [ ] `N1 の N2` — 所屬・所有 ／ 私**の**友達（ともだち）は大阪（おおさか）**の**大学（だいがく）の学生です。→ [專課](../basics/particles.md)

## 第2課

- [ ] `これ／それ／あれ` — 指示物（近・中・遠） ／ **これ**は私（わたし）の傘（かさ）です。→ [專課](../basics/vocabulary.md)
- [ ] `この／その／あの N` — 後面一定接名詞 ／ **その**かばんは誰（だれ）のですか。→ [專課](../basics/vocabulary.md)
- [ ] `そうです／そうじゃ ありません` — 回答是非問句 ／ 「これは辞書（じしょ）ですか。」「いいえ、**そうじゃ ありません**。」
- [ ] `N1 ですか、N2 ですか` — 二選一問句 ／ 紅茶（こうちゃ）ですか、コーヒーですか。
- [ ] `N1 の N2（種類）` — 「～的～」表類別・內容 ／ これは日本語（にほんご）**の**本です。→ [專課](../basics/particles.md)

## 第3課

- [ ] `ここ／そこ／あそこ／こちら…` — 場所指示（こちら 較禮貌） ／ トイレは**あそこ**です。→ [專課](../basics/vocabulary.md)
- [ ] `N1 は N2（場所）です` — 「A 在 B」 ／ 駅（えき）は**あの建物（たてもの）の隣（となり）**です。→ [專課](../basics/particles.md)
- [ ] `どこ／どちら／なん／だれ` — 疑問詞當 N 用 ／ お手洗（てあら）いは**どこ**ですか。→ [專課](../basics/vocabulary.md)
- [ ] `N1 の N2（產地・製造商）` — 「哪裡的～」 ／ このカメラは日本（にほん）**の**です。

## 第4課

- [ ] `今 ～時～分です` — 說時刻 ／ 今（いま）は九時（くじ）十五分（じゅうごふん）です。→ [專課](../basics/vocabulary.md)
- [ ] `V ます／ません／ました／ませんでした` — 動詞丁寧形四型 ／ 昨日（きのう）は早（はや）く**寝（ね）ました**。→ [專課](../basics/verb-conjugation.md)
- [ ] `N（時間）に V` — 具體時刻加 に ／ 毎朝（まいあさ）六時（ろくじ）**に**起（お）きます。→ [專課](../basics/particles.md)
- [ ] `N1 から N2 まで` — 起點到終點 ／ 授業（じゅぎょう）は九時（くじ）**から**十二時（じゅうにじ）**まで**です。→ [專課](../basics/particles.md)
- [ ] `N1 と N2` — 並列名詞 ／ 土曜日（どようび）**と**日曜日（にちようび）は休（やす）みです。→ [專課](../basics/particles.md)

## 第5課

- [ ] `N（場所）へ 行きます／来ます／帰ります` — 移動動詞＋方向 へ（讀 e） ／ 来週（らいしゅう）、京都（きょうと）**へ**行（い）きます。→ [專課](../basics/particles.md)
- [ ] `N（交通工具）で 行きます` — 手段用 で ／ 駅（えき）まで自転車（じてんしゃ）**で**行（い）きます。→ [專課](../basics/particles.md)
- [ ] `N（人）と V` — 「和誰一起」 ／ 週末（しゅうまつ）は家族（かぞく）**と**買（か）い物（もの）に行（い）きました。→ [專課](../basics/particles.md)
- [ ] `いつ` — 問時間；`～ですよ` 加強告知語氣 ／ 試験（しけん）は**いつ**ですか。来月（らいげつ）**ですよ**。

## 第6課

- [ ] `N を V` — 他動詞的受詞 ／ 毎晩（まいばん）、ニュース**を**見（み）ます。→ [專課](../basics/particles.md)
- [ ] `N を します` — 「做～」（運動・活動） ／ 日曜日（にちようび）にテニス**を**します。
- [ ] `V ませんか` — 邀請「要不要～」 ／ 一緒（いっしょ）に昼（ひる）ご飯（はん）を食（た）べ**ませんか**。
- [ ] `V ましょう` — 提議・回應邀請「～吧」 ／ ちょっと休（やす）み**ましょう**。→ [專課](../basics/verb-conjugation.md)
- [ ] `N（場所）で V` — 動作發生的地點 ／ 駅前（えきまえ）**で**友達（ともだち）に会（あ）いました。→ [專課](../basics/particles.md)

## 第7課

- [ ] `N（道具・手段）で V` — 用什麼做 ／ はし**で**ご飯（はん）を食（た）べます。→ [專課](../basics/particles.md)
- [ ] `「～」は ～語で 何ですか` — 問某詞的說法 ／ 「ありがとう」は中国語（ちゅうごくご）で何（なん）ですか。
- [ ] `N（人）に あげます／もらいます` — 給予・接受，「に」標出對象 ／ 母（はは）**に**花（はな）を**あげました**。→ [專課](../basics/juju-doushi.md)
- [ ] `もう V ました／まだです` — 「已經～了」「還沒」 ／ 宿題（しゅくだい）は**もう**終（お）わりましたか。いいえ、**まだです**。

## 第8課

- [ ] `N は な形容詞（な）です／い形容詞（～い）です` — 形容詞句 ／ この町（まち）は**静（しず）かです**。部屋（へや）は**広（ひろ）いです**。→ [專課](../basics/adjective-conjugation.md)
- [ ] `形容詞の否定` — な：`～じゃ ありません`、い：`い → くないです` ／ この本（ほん）は**おもしろくないです**。→ [專課](../basics/adjective-conjugation.md)
- [ ] `形容詞 ＋ N` — 修飾名詞（な 要留著） ／ **きれいな**花（はな）、**高（たか）い**山（やま）。→ [專課](../basics/adjective-conjugation.md)
- [ ] `とても／あまり ～ません` — 程度副詞（あまり 搭否定） ／ この店（みせ）は**あまり**安（やす）くないです。
- [ ] `～が、～` — 「但是」連接兩句 ／ 料理（りょうり）は**おいしいですが**、ちょっと高（たか）いです。

## 第9課

- [ ] `N が 好きです／きらいです／上手です／下手です` — 喜好・能力的對象用 が ／ 私（わたし）は料理（りょうり）**が**好（す）きです。→ [專課](../compare/wa-ga.md)
- [ ] `N が あります／わかります` — 擁有・理解的對象用 が ／ 日本語（にほんご）**が**少（すこ）し**わかります**。→ [專課](../basics/particles.md)
- [ ] `どんな N／どれ` — 問種類・從三個以上選 ／ **どんな**音楽（おんがく）が好（す）きですか。
- [ ] `よく／だいたい／たくさん／少し／全然` — 頻度・分量副詞（全然 搭否定） ／ 日曜日（にちようび）は**全然**勉強（べんきょう）しません。
- [ ] `～から、～` — 說明理由「因為～所以～」 ／ 時間（じかん）がありません**から**、行（い）きません。→ [專課](../compare/kara-node.md)
- [ ] `どうして` — 問理由「為什麼」 ／ **どうして**休（やす）みましたか。

## 第10課

- [ ] `N1（場所）に N2 が あります／います` — 存在句，物用 あります、人／動物用 います ／ 机（つくえ）の上（うえ）に本（ほん）**が あります**。庭（にわ）に猫（ねこ）**が います**。→ [專課](../basics/particles.md)
- [ ] `N1 は N2（位置）に あります／います` — 以特定的物當主題，說它在哪 ／ 私（わたし）の鍵（かぎ）は**かばんの中（なか）に**あります。
- [ ] `上・下・前・後ろ・隣・間・中…` — 位置名詞用 `N の ＋位置` ／ 銀行（ぎんこう）は郵便局（ゆうびんきょく）の**隣（となり）**です。→ [專課](../basics/vocabulary.md)
- [ ] `N1 や N2（など）` — 列舉部分項目 ／ かばんの中（なか）に財布（さいふ）**や**鍵（かぎ）**など**があります。→ [專課](../basics/particles.md)

## 第11課

- [ ] `数量詞（いくつ・ひとつ・一人（ひとり）…）` — 物的數量接在動詞前，不加助詞 ／ りんごを**三（みっ）つ**買（か）いました。→ [專課](../basics/vocabulary.md)
- [ ] `期間（一時間（いちじかん）・三日（みっか）…）` — 花多久時間 ／ 毎日（まいにち）**二時間（にじかん）**勉強（べんきょう）します。→ [專課](../basics/vocabulary.md)
- [ ] `期間 に ～回 V` — 頻率「每～幾次」 ／ 一週間（いっしゅうかん）**に**二回（にかい）、プールへ行（い）きます。
- [ ] `N だけ` — 「只有～」 ／ 今日（きょう）は午前（ごぜん）**だけ**働（はたら）きます。→ [專課](../compare/focus-particles.md)

## 第12課

- [ ] `名詞文・な形容詞文の過去` — `です → でした`、`じゃ ありません → じゃ ありませんでした` ／ 昨日（きのう）は**雨（あめ）でした**。→ [專課](../basics/noun-conjugation.md)
- [ ] `い形容詞の過去` — `い → かったです`、`くないです → くなかったです` ／ 旅行（りょこう）は**楽（たの）しかったです**。→ [專課](../basics/adjective-conjugation.md)
- [ ] `N1 は N2 より Adj` — 比較「A 比 B 更～」 ／ 電車（でんしゃ）はバス**より**速（はや）いです。
- [ ] `N1 と N2 と どちらが Adj` — 二者比較問句 ／ 紅茶（こうちゃ）とコーヒーと**どちらが**好（す）きですか。
- [ ] `N1［の 中（なか）］で 何（なに）が いちばん Adj` — 三者以上比最高級 ／ 果物（くだもの）の中（なか）で**何（なに）が いちばん**好（す）きですか。

## 第13課

- [ ] `N が ほしいです` — 想要某物（對象用 が） ／ 新（あたら）しいパソコン**が ほしいです**。→ [專課](../basics/adjective-conjugation.md)
- [ ] `V たいです` — 想做某事，`ます → たい`（活用同い形容詞） ／ 夏休（なつやす）みに沖縄（おきなわ）へ行（い）き**たいです**。→ [專課](../basics/verb-conjugation.md)
- [ ] `N（場所）へ V ます形 に 行きます／来ます／帰ります` — 為了～去／來／回 ／ 図書館（としょかん）へ本（ほん）を借（か）り**に**行（い）きます。
- [ ] `V ます形／N に 行きます`（N 為動作性名詞） — 「去做～」 ／ 友達（ともだち）と食事（しょくじ）**に**行（い）きました。

## 第14課

- [ ] `動詞の グループ（I・II・III）` — 五段／一段／不規則三類，變化的基礎 ／ 飲（の）む（I）・食（た）べる（II）・来（く）る（III）→ [專課](../basics/verb-conjugation.md)
- [ ] `て形` — 各類變法與音便 ／ 書（か）く → 書（か）**いて**、読（よ）む → 読（よ）**んで**。→ [專課](../basics/conjugation-cheatsheet.md)
- [ ] `V て ください` — 請求「請～」 ／ ここに名前（なまえ）を書（か）**いて ください**。
- [ ] `V て います（進行）` — 正在做～ ／ 今（いま）、母（はは）は料理（りょうり）をして**います**。→ [專課](../basics/te-compound.md)
- [ ] `V ましょうか` — 主動提議「我來～好嗎」 ／ 荷物（にもつ）を持（も）ち**ましょうか**。

## 第15課

- [ ] `V ても いいです` — 許可「可以～」 ／ ここで写真（しゃしん）を撮（と）**っても いいですか**。
- [ ] `V ては いけません` — 禁止「不可以～」 ／ 教室（きょうしつ）で食（た）べ**ては いけません**。
- [ ] `V て います（結果の状態）` — 動作完成後的狀態（結婚・住・持・知道…） ／ 兄（あに）は東京（とうきょう）に住（す）ん**でいます**。→ [專課](../basics/jidoushi-tadoushi.md)
- [ ] `V て います（職業・習慣）` — 持續的工作或習慣 ／ 姉（あね）は銀行（ぎんこう）で働（はたら）い**ています**。
- [ ] `知（し）りません` — 「知っています」的否定是 知りません，不是 知っていません ⚠待對照 ／ その人（ひと）のことは**知（し）りません**。

## 第16課

- [ ] `V て、V て、V ます` — 連續動作用て形串接（時態只在最後） ／ 朝（あさ）起（お）き**て**、顔（かお）を洗（あら）っ**て**、ご飯（はん）を食（た）べます。→ [專課](../basics/te-compound.md)
- [ ] `い形容詞 くて／な形容詞・N で` — 形容詞串接 ／ この部屋（へや）は明（あか）る**くて**、**きれいで**、広（ひろ）いです。→ [專課](../basics/adjective-conjugation.md)
- [ ] `V て から、V` — 「做完～之後再～」 ／ 手（て）を洗（あら）っ**てから**、食（た）べます。
- [ ] `N1 は N2 が Adj` — 大主題＋小主語（象は鼻が長い型） ／ 京都（きょうと）は**お寺（てら）が多（おお）い**です。→ [專課](../compare/wa-ga.md)
- [ ] `どうやって／どの N` — 問方法・問哪一個 ／ 駅（えき）まで**どうやって**行（い）きますか。

## 第17課

- [ ] `ない形` — 各類變法 ／ 書（か）く → 書（か）**かない**、食（た）べる → 食（た）べ**ない**。→ [專課](../basics/conjugation-cheatsheet.md)
- [ ] `V ないで ください` — 請不要～ ／ ここで電話（でんわ）をし**ないで ください**。→ [專課](../basics/verb-conjugation.md)
- [ ] `V なければ なりません` — 必須～ ／ 明日（あした）は早（はや）く起（お）き**なければ なりません**。
- [ ] `V なくても いいです` — 不用～也可以 ／ 今日（きょう）は来（こ）**なくても いいです**。
- [ ] `N（受詞）は ～` — 把受詞提到句首當主題 ／ 荷物（にもつ）**は**ここに置（お）かないで ください。
- [ ] `N（時間）までに V` — 「在～之前完成」 ／ 金曜日（きんようび）**までに**レポートを出（だ）してください。

## 第18課

- [ ] `辞書形` — 動詞原形，各類辨認 ／ 食（た）べます → 食（た）べ**る**、書（か）きます → 書（か）**く**。→ [專課](../basics/verb-conjugation.md)
- [ ] `N が できます／V る ことが できます` — 「會～・能～」 ／ 私（わたし）は泳（およ）ぐ**ことが できます**。→ [專課](../basics/no-nominalization.md)
- [ ] `趣味（しゅみ）は V る ことです` — 「興趣是～」 ／ 私（わたし）の趣味（しゅみ）は映画（えいが）を見（み）る**ことです**。
- [ ] `V る まえに、V` — 「在做～之前」 ／ 寝（ね）る**まえに**、歯（は）を磨（みが）きます。
- [ ] `なかなか ～ません／ぜひ` — 「不太容易～」「務必」 ⚠待對照 ／ 日本語（にほんご）が**なかなか**上手（じょうず）になりません。

## 第19課

- [ ] `た形` — 各類變法（同て形，て → た） ／ 食（た）べる → 食（た）**べた**、読（よ）む → 読（よ）**んだ**。→ [專課](../basics/conjugation-cheatsheet.md)
- [ ] `V た ことが あります` — 「有過～的經驗」 ／ 富士山（ふじさん）に登（のぼ）っ**た ことが あります**。
- [ ] `V たり、V たり します` — 列舉動作「又～又～」 ／ 休（やす）みの日（ひ）は本（ほん）を読（よ）ん**だり**、散歩（さんぽ）し**たり**します。
- [ ] `い形容詞 く／な形容詞・N に なります` — 變化「變成～」 ／ 最近（さいきん）、寒（さむ）**く なりました**。→ [專課](../basics/adjective-conjugation.md)

## 第20課

- [ ] `丁寧体 と 普通体` — 敬體（です・ます）與常體（口語）的差別 ／ 行（い）きます → **行（い）く**。→ [專課](../basics/conjugation-cheatsheet.md)
- [ ] `普通形（動詞）` — 辞書形・ない形・た形・なかった形 ／ 食（た）べる／食（た）べない／食（た）べた／食（た）べなかった
- [ ] `普通形（形容詞・名詞）` — い：高い／高くない、な・N：静かだ／静かじゃない ／ きれい**だ**・学生（がくせい）**だ**。→ [專課](../basics/adjective-conjugation.md)
- [ ] `普通体の会話` — 朋友間省略 です／ます、疑問句省略 か ／ 明日（あした）、行（い）く？ ── うん、行（い）く。

## 第21課

- [ ] `普通形 と 思（おも）います` — 「我想～」 ／ 明日（あした）は雨（あめ）が降（ふ）る**と 思（おも）います**。
- [ ] `「～」／普通形 と 言（い）いました` — 引用「他說～」 ／ 先生（せんせい）は「明日（あした）は休（やす）みだ」**と 言（い）いました**。→ [專課](../basics/particles.md)
- [ ] `V る／V ない でしょう？` — 向對方確認「對吧？」 ／ 今日（きょう）は暑（あつ）い**でしょう？** → [專課](../compare/modality.md)
- [ ] `N（場所）で N が あります` — 事件・活動「在～舉行」 ⚠待對照 ／ 駅前（えきまえ）**で**祭（まつ）りが**あります**。
- [ ] `N でも V` — 「～之類的也行」提議 ⚠待對照 ／ お茶（ちゃ）**でも**飲（の）みませんか。

## 第22課

- [ ] `普通形 ＋ N（名詞修飾）` — 句子放在名詞前面當形容詞 ／ 昨日（きのう）**買（か）った**本（ほん）はおもしろいです。→ [專課](../basics/no-nominalization.md)
- [ ] `修飾節の中の主語は が` — 修飾句裡的主語用 が ／ **私（わたし）が**作（つく）った料理（りょうり）です。→ [專課](../compare/wa-ga.md)
- [ ] `V る 時間（じかん）／約束（やくそく）／用事（ようじ）` — 修飾「時間・約定・事情」 ／ 友達（ともだち）と**会（あ）う 約束（やくそく）**があります。
- [ ] `N1 は 普通形 N2 です` — 用修飾句說明「是怎樣的人／物」 ／ あの人（ひと）は**駅（えき）で会（あ）った**人（ひと）です。

## 第23課

- [ ] `V る／V た／Adj とき、～` — 「～的時候」 ／ 日本（にほん）へ**行（い）く とき**、パスポートが要（い）ります。
- [ ] `V る と、～` — 一做就必然發生（機械性・習慣） ／ このボタンを押（お）す**と**、ドアが開（あ）きます。→ [專課](../compare/conditional-forms.md)
- [ ] `な形容詞・N ＋ な／の とき` — 接續：`静かな とき`、`休みの とき` ／ 暇（ひま）**な とき**、遊（あそ）びに来（き）てください。
- [ ] `V る と 、～ が 見（み）えます／わかります…` — 發現型「一～就看到」 ⚠待對照 ／ 窓（まど）を開（あ）ける**と**、海（うみ）が見（み）えます。

## 第24課

- [ ] `くれます` — 別人給「我（方）」 ／ 友達（ともだち）が私（わたし）に地図（ちず）を**くれました**。→ [專課](../basics/juju-doushi.md)
- [ ] `V て あげます` — 為別人做某事（對象用 に） ／ 弟（おとうと）に宿題（しゅくだい）を教（おし）え**て あげました**。→ [專課](../basics/juju-doushi.md)
- [ ] `V て もらいます` — 請別人為我做某事 ／ 先輩（せんぱい）に駅（えき）まで送（おく）っ**て もらいました**。→ [專課](../basics/juju-doushi.md)
- [ ] `V て くれます` — 別人為我做某事（恩惠・感謝） ／ 隣（となり）の人（ひと）が荷物（にもつ）を持（も）っ**て くれました**。→ [專課](../basics/juju-doushi.md)
- [ ] `N（人）が V` — 「誰為我做～」主語標示 ⚠待對照 ／ 母（はは）**が**弁当（べんとう）を作（つく）ってくれました。

## 第25課

- [ ] `普通形過去 ＋ ら、～`（V たら） — 「如果～的話／～之後」 ／ 雨（あめ）が降（ふ）っ**たら**、行（い）きません。→ [專課](../compare/conditional-forms.md)
- [ ] `V ても、～` — 逆接「即使～也～」 ／ 雨（あめ）が降（ふ）っ**ても**、行（い）きます。→ [專課](../compare/conditional-forms.md)
- [ ] `もし／いくら` — 搭配 たら／ても 的副詞「假如」「再怎麼」 ／ **もし**時間（じかん）があっ**たら**、手伝（てつだ）ってください。
- [ ] `Adj・N ＋ たら／ても` — い：`高かったら／高くても`、な・N：`静かだったら／静かでも` ／ 安（やす）**かったら**買（か）います。
