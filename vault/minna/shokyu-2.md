# 初級 II（第26課〜第50課）

邊讀邊勾：`[x]` = 會用、`[ ]` = 還不熟。每點一句規則＋一句自編例句；細節去連結的專課看。回[總覽](index.md)。

> [!NOTE]
> 課次與文型依記憶整理，尚未對照課本目次；標 `⚠待對照` 的是我不確定落在哪一課。例句全是自編，不是課本原文。

## 第26課

- [ ] `普通形 ＋ んです／んですか` — 帶說明・追問原因的語氣 ／ 顔色（かおいろ）が悪（わる）いですね。どうしたん**ですか**。→ [專課](../basics/no-nominalization.md)
- [ ] `～んですが、～ V て いただけませんか` — 先說明狀況再提出請求 ⚠待對照 ／ 道（みち）がわからない**んですが**、教（おし）えて いただけませんか。
- [ ] `な形・N ＋ な んです` — な形容詞・名詞接 んです 要加 な ／ 今日（きょう）は休（やす）み**なんです**。→ [專課](../basics/no-nominalization.md)
- [ ] `～たいんですが` — 委婉表達想做某事 ⚠待對照 ／ ちょっと相談（そうだん）し**たいんですが**。

## 第27課

- [ ] `可能動詞` — 「能～」，各類變法 ／ 書（か）く → 書（か）**ける**、食（た）べる → 食（た）べ**られる**。→ [專課](../basics/verb-conjugation.md)
- [ ] `可能動詞の 助詞` — 受詞多用 が（を 也常見） ／ 私（わたし）は漢字（かんじ）**が**読（よ）めます。→ [專課](../basics/particles.md)
- [ ] `見（み）えます／聞（き）こえます` — 自然看得見・聽得見 ／ 窓（まど）から山（やま）が**見（み）えます**。
- [ ] `できます（完成・出現）` — 「建好了・做好了」的意思 ／ 駅前（えきまえ）に新（あたら）しい店（みせ）が**できました**。
- [ ] `しか ＋ 否定` — 「只有～」（帶不足感）／ 財布（さいふ）に百円（ひゃくえん）**しか** ありません。→ [專課](../compare/focus-particles.md)
- [ ] `は／も／が の 使い分け` — 否定・對比用 は、追加用 も ／ お酒（さけ）**は**飲（の）めますが、タバコは吸（す）えません。

## 第28課

- [ ] `V ます形 ながら V` — 「一邊～一邊～」（主要動作放後面） ／ 音楽（おんがく）を聞（き）き**ながら**勉強（べんきょう）します。→ [專課](../basics/te-compound.md)
- [ ] `V て います（習慣）` — 長期反覆的習慣 ／ 毎朝（まいあさ）ジョギングをし**ています**。
- [ ] `普通形 し、普通形 し、～` — 列舉理由「又～又～」 ／ この店（みせ）は安（やす）い**し**、おいしい**し**、よく来（き）ます。→ [專課](../compare/kara-node.md)
- [ ] `～は ～で、～` — 名詞文串接 ／ 兄（あに）は会社員（かいしゃいん）**で**、姉（あね）は先生（せんせい）です。
- [ ] `それに` — 追加「而且」 ⚠待對照 ／ 安（やす）いです。**それに**、おいしいです。

## 第29課

- [ ] `V て しまいました／しまいます` — 完成・遺憾「～掉了」 ／ 財布（さいふ）を落（お）として**しまいました**。→ [專課](../basics/te-compound.md)
- [ ] `自動詞 ＋ ています` — 「～著（狀態）」，如 開いている・消えている ／ 窓（まど）が**開（あ）いています**。→ [專課](../basics/jidoushi-tadoushi.md)
- [ ] `自動詞 ＋ ました（意外・發現）` — 「～了」描述發生的事 ／ 電車（でんしゃ）が**止（と）まりました**。→ [專課](../basics/jidoushi-tadoushi.md)
- [ ] `V て しまう（口語 ちゃう／じゃう）` — 縮約形 ／ 食（た）べ**ちゃった**。→ [專課](../basics/te-compound.md)

## 第30課

- [ ] `V て あります` — 他動詞的結果狀態（有人事先做好了） ／ 机（つくえ）の上（うえ）に地図（ちず）が**置（お）いて あります**。→ [專課](../basics/jidoushi-tadoushi.md)
- [ ] `V て おきます` — 事先準備・先做好 ／ 旅行（りょこう）の前（まえ）に、ホテルを予約（よやく）し**て おきます**。→ [專課](../basics/te-compound.md)
- [ ] `V て あります vs V て います` — 他動詞（有意圖）vs 自動詞（自然）的對比 ／ ドアが開（あ）けて**あります**／ドアが開（あ）いて**います**。→ [專課](../basics/jidoushi-tadoushi.md)

## 第31課

- [ ] `意向形（よう形）` — 「～吧」，各類變法 ／ 行（い）く → 行（い）**こう**、食（た）べる → 食（た）べ**よう**。→ [專課](../basics/conjugation-cheatsheet.md)
- [ ] `V よう と 思（おも）って います` — 打算做～（說話時已有的想法） ／ 来年（らいねん）、日本（にほん）へ留学（りゅうがく）し**ようと 思（おも）っています**。
- [ ] `V る／V ない つもりです` — 「打算～／不打算～」（較堅定） ／ 今年（ことし）は旅行（りょこう）に行（い）かない**つもりです**。
- [ ] `V る 予定（よてい）です` — 預定（行程・計畫） ／ 来週（らいしゅう）、出張（しゅっちょう）する**予定（よてい）です**。
- [ ] `まだ V て いません` — 還沒～ ／ 宿題（しゅくだい）は**まだ**終（お）わっていません。

## 第32課

- [ ] `V た ほうが いいです` — 「最好～」（建議） ／ 風邪（かぜ）なら、早（はや）く寝（ね）**た ほうが いいですよ**。
- [ ] `V ない ほうが いいです` — 「最好不要～」 ／ 夜（よる）は コーヒーを飲（の）ま**ない ほうが いいです**。
- [ ] `普通形 でしょう` — 推測「大概～吧」 ／ 明日（あした）は雨（あめ）が降（ふ）る**でしょう**。→ [專課](../compare/modality.md)
- [ ] `普通形 かもしれません` — 「也許～」（可能性低於 でしょう） ／ 彼（かれ）はもう帰（かえ）った**かもしれません**。→ [專課](../compare/modality.md)

## 第33課

- [ ] `命令形` — 命令「給我～」，各類變法 ／ 書（か）く → 書（か）**け**、食（た）べる → 食（た）べ**ろ**。→ [專課](../basics/conjugation-cheatsheet.md)
- [ ] `禁止形` — `V る ＋ な`「不准～」 ／ ここで走（はし）る**な**。→ [專課](../basics/verb-conjugation.md)
- [ ] `「～」と 書（か）いて あります／読（よ）みます` — 說明標示・看板寫了什麼 ／ あの看板（かんばん）には「止（と）まれ」**と 書（か）いて あります**。
- [ ] `～は ～と いう 意味（いみ）です` — 解釋詞義 ／ 「禁煙（きんえん）」は「タバコを吸（す）わないで」**という 意味（いみ）です**。
- [ ] `普通形 と 言（い）っていました` — 轉述「某人說～」 ⚠待對照 ／ 田中（たなか）さんは遅（おく）れる**と 言（い）っていました**。

## 第34課

- [ ] `V た とおりに V` — 「照著～做」 ／ 先生（せんせい）が言（い）っ**た とおりに**書（か）きました。
- [ ] `N の とおりに V` — 同上，接名詞用 の ／ 説明書（せつめいしょ）**の とおりに**組（く）み立（た）てます。
- [ ] `V た あとで／N の あとで` — 「～之後」 ／ 食事（しょくじ）**の あとで**、薬（くすり）を飲（の）みます。
- [ ] `V て／V ないで V` — 附帶狀況「～著做」「不～地做」 ／ 傘（かさ）を持（も）た**ないで**出（で）かけました。→ [專課](../basics/te-compound.md)
- [ ] `V ない まま` — 維持原狀「就那樣沒～」 ⚠待對照 ／ 電気（でんき）をつけた**まま**寝（ね）てしまいました。

## 第35課

- [ ] `V ば` — 動詞條件形：`え段 ＋ ば` ／ 急（いそ）げ**ば**、間（ま）に合（あ）います。→ [專課](../compare/conditional-forms.md)
- [ ] `い形容詞 ければ／な形容詞・N なら` — 形容詞・名詞的條件 ／ 安（やす）**ければ**買（か）います。→ [專課](../compare/conditional-forms.md)
- [ ] `N なら` — 「如果是～的話」承接對方話題 ／ 京都（きょうと）**なら**、秋（あき）がいいですよ。→ [專課](../compare/conditional-forms.md)
- [ ] `V ば V ほど` — 「越～越～」 ／ 練習（れんしゅう）す**れば**する**ほど**上手（じょうず）になります。
- [ ] `ば／と／たら／なら の 使い分け` — 四種條件的選擇 → [專課](../compare/conditional-forms.md)

## 第36課

- [ ] `V る ように、V` — 「為了能～」（目的・狀態變化） ／ よく聞（き）こえる**ように**、前（まえ）に座（すわ）りました。
- [ ] `V る ために／N の ために、V` — 「為了～」（有意志的目的） ⚠待對照 ／ 日本（にほん）で働（はたら）く**ために**、日本語（にほんご）を勉強（べんきょう）しています。
- [ ] `V る／V ない ように なります` — 「變得能～／變得不～」 ／ やっと泳（およ）げる**ように なりました**。
- [ ] `V る／V ない ように します` — 「努力做到～」 ／ 毎日（まいにち）野菜（やさい）を食（た）べる**ように して います**。
- [ ] `V る ように して ください` — 請設法做到 ⚠待對照 ／ 明日（あした）は遅（おく）れ**ない ように**してください。

## 第37課

- [ ] `受身形` — 「被～」，各類變法 ／ 書（か）く → 書（か）**かれる**、食（た）べる → 食（た）べ**られる**。→ [專課](../basics/verb-conjugation.md)
- [ ] `N1（人）に N2 を V れる` — 直接受身：被人做了某事 ／ 先生（せんせい）に名前（なまえ）を**呼（よ）ばれました**。
- [ ] `迷惑の受身` — 被動句表「被人搞得很困擾」 ／ 雨（あめ）に**降（ふ）られて**、びしょぬれになりました。
- [ ] `N が V れる（無生物主語）` — 事物當主語 ／ この本（ほん）は世界（せかい）中（じゅう）で**読（よ）まれています**。
- [ ] `N1 は N2 に V れる` — 動作者用 に（也有 から・によって） ⚠待對照 ／ この絵（え）はピカソに**よって**描（か）かれました。

## 第38課

- [ ] `V（普通形）の／こと` — 把動詞變成名詞 ／ 私（わたし）は歌（うた）を歌（うた）う**の**が好（す）きです。→ [專課](../basics/no-nominalization.md)
- [ ] `V の は Adj です` — 「做～很～」 ／ 朝（あさ）早（はや）く起（お）きる**の**は大変（たいへん）です。→ [專課](../basics/no-nominalization.md)
- [ ] `V の を 知（し）っていますか` — 對 の 的名詞句問「你知道～嗎」 ／ 彼（かれ）が結婚（けっこん）した**の**を知（し）っていますか。
- [ ] `の vs こと` — 能互換的場合與不能互換的場合 → [專課](../basics/no-nominalization.md)

## 第39課

- [ ] `V て／Adj くて／N で、～（原因）` — 以て形表原因 ／ 試験（しけん）に落（お）ち**て**、がっかりしました。→ [專課](../compare/kara-node.md)
- [ ] `V なくて、～` — 因為沒有／不～ ／ 道（みち）がわから**なくて**、困（こま）りました。
- [ ] `N で、～（原因）` — 名詞表原因 ／ 地震（じしん）**で**、電車（でんしゃ）が止（と）まりました。
- [ ] `普通形 ので、～` — 客觀說明理由 ／ 熱（ねつ）がある**ので**、今日（きょう）は休（やす）みます。→ [專課](../compare/kara-node.md)
- [ ] `V て（原因）的限制` — 後句不能接意志・命令・請求 ⚠待對照 ／ ✗ 熱（ねつ）があって、休（やす）んでください → ✓ 熱（ねつ）がある**ので**、休（やす）んでください。

## 第40課

- [ ] `普通形 か、～か どうか` — 把疑問句嵌入句子「是否～」 ／ あの店（みせ）が開（あ）いている**かどうか**、電話（でんわ）で聞（き）きます。→ [專課](../basics/no-nominalization.md)
- [ ] `疑問詞 ＋ 普通形 か、～` — 間接疑問「～是什麼／誰／何時」 ／ 彼（かれ）が**いつ**来（く）る**か**、知（し）りません。
- [ ] `V て みます` — 「試試看～」 ／ このソースを使（つか）っ**て みます**。→ [專課](../basics/te-compound.md)
- [ ] `Adj／N ＋ か どうか` — 名詞・形容詞也能接（名詞・な形省略 だ）⚠待對照 ／ 本当（ほんとう）かどうか確（たし）かめます。

## 第41課

- [ ] `いただきます／くださいます／やります` — もらう・くれる・あげる 的敬語／對下位用法 ／ 先生（せんせい）に本（ほん）を**いただきました**。→ [專課](../basics/juju-doushi.md)
- [ ] `V て いただきます` — 「承蒙～為我做了～」（もらう 的謙讓） ／ 部長（ぶちょう）に資料（しりょう）を見（み）**て いただきました**。→ [專課](../basics/juju-doushi.md)
- [ ] `V て くださいます` — 「～為我做了～」（くれる 的尊敬） ／ 先生（せんせい）が説明（せつめい）し**て くださいました**。→ [專課](../basics/juju-doushi.md)
- [ ] `V て やります` — 對晚輩・動植物「為～做～」 ／ 毎朝（まいあさ）犬（いぬ）に散歩（さんぽ）をし**て やります**。→ [專課](../basics/juju-doushi.md)

## 第42課

- [ ] `V る／N の ために、～` — 「為了～」（目的） ／ 家（いえ）を買（か）う**ために**、お金（かね）を貯（た）めています。
- [ ] `V る のに 使（つか）います／便利（べんり）です` — 「用來～」 ／ このはさみは紙（かみ）を切（き）る**のに** 使（つか）います。
- [ ] `数量詞 ＋ ぐらい かかります` — 花多少錢・時間 ⚠待對照 ／ 家（いえ）から会社（かいしゃ）まで四十分（よんじゅっぷん）**かかります**。
- [ ] `ために vs ように` — 有意志用 ために、無意志用 ように ⚠待對照 ／ 合格（ごうかく）する**ために**勉強（べんきょう）する。合格（ごうかく）できる**ように**勉強（べんきょう）する。

## 第43課

- [ ] `V ます形／Adj語幹 ＋ そうです（様態）` — 「看起來快要～」 ／ 雨（あめ）が降（ふ）り**そうです**。この料理（りょうり）はおいし**そうです**。→ [專課](../compare/modality.md)
- [ ] `V て きます` — 去～再回來；變化「逐漸～」 ／ ちょっとコンビニへ行（い）っ**て きます**。→ [專課](../basics/te-compound.md)
- [ ] `V すぎます` — 「太～・過度～」 ⚠待對照 ／ きのうは食（た）べ**すぎました**。
- [ ] `いい／ない ＋ そうです` — 特殊接續：よさそう／なさそう ⚠待對照 ／ このお店（みせ）は**よさそうです**。→ [專課](../compare/modality.md)
- [ ] `Adj／N ＋ そうです` — 外觀推測的各種接續 ／ 彼女（かのじょ）は元気（げんき）**そうです**。→ [專課](../compare/modality.md)

## 第44課

- [ ] `V ます形 ＋ すぎます` — 「～過頭」 ／ 昨夜（さくや）は飲（の）み**すぎました**。
- [ ] `V ます形 ＋ やすい／にくい` — 「容易～／不容易～」 ／ このペンは書（か）き**やすい**です。
- [ ] `Adj く／N に します` — 把某物「弄成～」（有意志的變化） ／ 音（おと）を**小（ちい）さく** します。→ [專課](../basics/adjective-conjugation.md)
- [ ] `N に します` — 選擇「決定要～」 ／ 私（わたし）はコーヒー**に** します。
- [ ] `なる vs する` — 自然變化 vs 人為改變 ／ 部屋（へや）が**暖（あたた）かく なりました**。→ [專課](../basics/jidoushi-tadoushi.md)

## 第45課

- [ ] `V る／V ない／V た 場合（ばあい）は、～` — 「萬一～的話」 ／ 地震（じしん）が起（お）きた**場合（ばあい）は**、すぐ外（そと）へ出（で）てください。
- [ ] `普通形 のに、～（逆接）` — 「明明～卻～」（帶意外・不滿） ／ 約束（やくそく）した**のに**、彼（かれ）は来（き）ませんでした。→ [專課](../basics/no-nominalization.md)
- [ ] `な形容詞・N ＋ な のに` — な形・名詞接 のに 要用 な ／ 日曜日（にちようび）**なのに**、仕事（しごと）です。
- [ ] `場合 の 接續` — `Nの場合`、`な形の場合` ⚠待對照 ／ 雨（あめ）**の 場合（ばあい）**は中止（ちゅうし）です。

## 第46課

- [ ] `V る／V て いる／V た ところです` — 「正要～／正在～／剛剛～」 ／ 今（いま）、出（で）かける**ところです**。
- [ ] `V た ばかりです` — 「剛～完」（主觀上覺得很近） ／ 日本（にほん）に来（き）た**ばかりです**。
- [ ] `V る はずです` — 「應該～」（有根據的推測） ／ 彼（かれ）は今日（きょう）来（く）る**はずです**。→ [專課](../compare/modality.md)

## 第47課

- [ ] `普通形 そうです（伝聞）` — 「聽說～」 ／ 天気予報（てんきよほう）によると、明日（あした）は雪（ゆき）だ**そうです**。→ [專課](../compare/modality.md)
- [ ] `普通形 ようです／みたいです` — 「好像～」（依感官的推斷） ／ 誰（だれ）かいる**ようです**。→ [專課](../compare/modality.md)
- [ ] `声（こえ）／におい／味（あじ）／音（おと）が します` — 感官上聽到・聞到 ／ 隣（となり）の部屋（へや）から**音（おと）が します**。
- [ ] `そうです 三兄弟` — 様態 そう vs 伝聞 そう vs 推量 ようだ → [專課](../compare/modality.md)
- [ ] `～らしい` — 「聽說似乎～」 ⚠待對照 ／ 新（あたら）しい店（みせ）ができる**らしい**。→ [專課](../compare/modality.md)

## 第48課

- [ ] `使役形（させ形）` — 「讓～做」，各類變法 ／ 書（か）く → 書（か）**かせる**、食（た）べる → 食（た）べ**させる**。→ [專課](../basics/causative.md)
- [ ] `N1（人）を／に V させます` — 助詞用法：自動詞用 を／に，他動詞用 に ／ 母（はは）は子供（こども）**に**野菜（やさい）を食（た）べ**させました**。→ [專課](../basics/causative.md)
- [ ] `V さ せて ください` — 「請讓我～」（請求許可） ／ 今日（きょう）は早（はや）く帰（かえ）ら**せて ください**。→ [專課](../basics/causative.md)
- [ ] `V さ せて いただけませんか` — 「能否讓我～」（更禮貌） ／ 資料（しりょう）を見（み）**させて いただけませんか**。→ [專課](../basics/causative.md)

## 第49課

- [ ] `尊敬語（特殊動詞）` — いらっしゃる・召（め）し上（あ）がる・おっしゃる… ／ 先生（せんせい）は明日（あした）**いらっしゃいます**。
- [ ] `お V ます形 に なります` — 尊敬語的規則形 ／ 社長（しゃちょう）は もう**お帰（かえ）りに なりました**。
- [ ] `V られます（尊敬）` — 受身形同形的尊敬用法 ／ 先生（せんせい）は何時（なんじ）に**来（こ）られますか**。→ [專課](../basics/verb-conjugation.md)
- [ ] `お V ます形 ください` — 「請您～」 ／ こちらで少（すこ）し**お待（ま）ち ください**。

## 第50課

- [ ] `謙譲語（特殊動詞）` — 参（まい）る・申（もう）す・いただく・拝見（はいけん）する… ／ 私（わたし）が**参（まい）ります**。
