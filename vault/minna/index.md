# 大家的日本語（みんなの日本語 第2版）教材追蹤

跟著《みんなの日本語》一課一課走，**只列每課的文型名稱**當自我檢查表，不是課文複習。目的：補 N5/N4 的洞，看哪些點「讀得懂但不會用」。

> [!NOTE]
> 所有清單都是**依記憶整理、待對照課本目次**。課次歸屬可能有誤，不確定的點標 `⚠待對照`；日文與例句一律是自編，不是課本原文。

## 怎麼用

1. 從[初級 I](shokyu-1.md) 第1課開始往下走，每個文型自問：「不看筆記，我能造一句嗎？」
2. 會用 → 把 `[ ]` 改成 `[x]`；還不熟 → 保持 `[ ]`。
3. 不熟的點告訴 agent：它會補進 [basics](../basics/grammar/particles.md) ／ [compare](../compare/wa-ga.md) 的對應專課（若是你自己造句錯的，再記一筆[錯題](../mistakes/my-pitfalls.md)），並把清單那一行連到專課。
4. 每一行 ` → [專課]` 就是該點的詳細說明；沒有連結代表目前還沒有專課。

## 規則

- 只放文型名稱與自編例句，不抄課文、會話、練習、單字表。
- 本體規則放 basics／compare 專課，這裡只留索引與勾選，避免同一規則散在多處。
